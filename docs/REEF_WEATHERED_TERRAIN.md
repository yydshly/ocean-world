# 不对称硬底肩部：表面契约与定向检查

日期：2026-10-03。此修订位于正式冻结构建之后，尚未经过本轮实际浏览器视觉复核，也不继承冻结版本的20分钟性能结论。没有改写原始扫描、已存报告、dist、World/UI或珊瑚几何。

## 改变了什么

旧主礁石保留高于沙床的椭球赤道，再将下半部延入沉积面，产生约半米至一米高的规则环墙和裙边。现在11块床脚支撑石的岩缘在局部沙床上方4.5–8.5cm，外肩使用一侧更明显的断裂斜面和错位层理，避免仅在对称圆柱上加微小噪声。第9块岩隙桥盖和19块辅助小石保留原形。

REEF_ROCKS的中心、尺度、米制单位与XZ椭圆足迹未变；没有新增随机抽样。半径不超过0.38的中心珊瑚支撑区保留原上表面，48个已存种子珊瑚位置与体型精确一致。外肩变化会改变其他路径的地形高度，模型仍按共享高度约束；没有宣称所有生态终态与历史版本相同。

这些断裂、层理、低岩缘和0.10m埋底深度是美术选择，不是地质测量或真实礁体形成过程。幅度、方向和层位按既有岩石坐标固定，不随帧或模拟时钟变化。

## 共享契约

`reefRockSurfaceY(rock,nx,ny,nz,bedSupported)`保留原签名。nx/nz是既有椭圆归一化XZ坐标；对修订主礁，ny选择上下表面，幅度从XZ导出，使模型、相机与渲染使用相同连续高度。`reefRockSurfacePoint`保留对应世界XZ并计算该高度，几何构建的上、下半部都调用它。`habitatHeight`调用同一上表面，World既有相机体积检查调用同一上下表面。

主礁采用64×40采样，桥盖／辅助石维持32×20。渲染三角面仍是连续场的插值近似。UV接缝和极点的重复顶点只平均法线，不改索引；静态BVH仍在几何完成后建树。曲线参数与层位数组在模块初始化时缓存，不在模拟的每次高度查询中创建层位数组。
