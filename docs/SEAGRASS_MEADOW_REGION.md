# 接续礁谷的海草草甸

本阶段把海草从零散点缀组织成一片完整生活空间：384 × 128 米共享海床，约394米观察主路，两条沙沟分叉，草核、渐薄草缘、沙地和少量不规则岩岛。西端与前一片礁谷的实际通行端口一致；主路东端停在草甸内部安全位置。世界仍可自由向外探索，这个观察终点不构成世界边界，也没有宣称已连接下一个礁谷的东端口。

打开 [草甸入口](https://yydshly.github.io/ocean-world/?demo=seagrass-meadow-region&seed=44)，或者 [导演入口](https://yydshly.github.io/ocean-world/?demo=director)。导演第二章从礁谷末端继续观察草甸200秒，同地衔接保留相机位置与朝向，并在开始6秒平缓转向草甸路径。支持原有变速、暂停和手动接管；加载不消耗观察时间。草甸复杂入口允许120秒有效加载等待，暂停与后台时间不计入；其他入口保留原有时限。导演共67章、61个动作、1994秒的1倍观察时间，加载与转场另计。

固定 `string42` 样本新增1067个实际根草描述符，其中907个核心、160个边缘，8个小型岩岛和4个岩面附着珊瑚。它们使用原有植物、岩石与珊瑚资产。草根只能落在实际软底；珊瑚和藻斑附着实际硬表面。植物描述符是景观，不代表经过标定的生物量。

动物沿用已有独立持久模型。草核、草缘、沙沟和上方水层各有不同类别上限；海龟、叶锚海马、乌贼、底栖觅食者和鱼群必须通过已有真实身体净空及支撑检查。类别缺席保持缺席，不强制出现所有物种。海龟摄食沿用实际叶尖接触与当地植物有机物库存；其他摄食继续使用各模型的现有资源代理。这次没有新增具名物种，也未实现完整捕食食物网。

新版本只在整组12个区块全部严格未访问时创建，先原子保存后公开。已有地形、动物、死亡、空类别、随机状态、时钟和食物账保持。每次最多9个活跃区块、25个公开支撑区块、每区20条动物记录（包括死亡）；礁谷与草甸共用最多97个私有预读记录，不能提前渲染未来区块。坐标生成每5组配置一个候选草甸，实际条件不满足时自然拒绝，不扩张旧存档。

旧存档已经探索过这12个区块时，入口会明确提示保留历史。可使用带 seed=44 的独立世界入口，或手动选择另一个未使用的世界种子演示新生成规则；选择种子不会自动清除或替换旧世界历史。已有44历史同样保留。

核验使用实际 Three CPU 网格、程序相机和持久生态。几何检查覆盖主支路点及中点的完整身体空间、软底根与保留宿主。动物检查记录实际出生、移动、摄食和冷恢复。浏览器/GPU画面、遮挡和帧率仍未验收，不能据这些技术检查宣称已经达到纪录片观感。

加载诊断表明主要耗时是地形、出生和支撑校验，磁盘读取占比很小。本轮试验的局部精确查询缓存收益不稳定，未加入生产代码；跨区加载停顿仍需后续单独处理。
