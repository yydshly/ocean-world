# 浅礁丰富群落：第一批

范围：在普通探索生成中扩展热带浅礁、草床边缘与沙地的生命组合。不是新增一块只供演示的世界；所有合适且尚未访问的浅海区域都使用同一规则。

## 看什么

- 浅海探索中的“丰富群落”按钮，直接进入正常生成海域，再按当地已提交的实际生物调整观察位置。
- [丰富群落入口](https://yydshly.github.io/ocean-world/?demo=biodiversity)。这会选择浅海生态海域，等待保存和加载完成；不重置种子或旧存档。
- 能力总览和导演中均有“丰富群落：礁缘”。导演仍按正常加载及镜头完成状态推进，不把入口坐标当成已出现生物的证明。
- 用 WASD、沿视线巡航、图鉴的附近活体观察继续探索。物种不会为镜头临时刷新，每个地点不必有整份名录。

## 新增内容与实际口径

| 内容 | 场景作用 | 当前行为与限制 |
|---|---|---|
| Porites lobata s.l. 团块滨珊瑚代表 | 实际硬底上的团块珊瑚斑块 | 固定景观；明确为复合种代表，数量不等于新增模拟生物量 |
| Caulerpa racemosa 葡萄蕨藻 | 岩面低矮绿藻斑块 | 固定景观；短芽尺度2–5厘米，生产库存仍是既有群体代理 |
| Diadema setosum 长刺海胆 | 藻覆硬底的刮食动物 | 低光缓移，只有接近实际藻覆宿主才消费当地表面食物代理 |
| Sabellastarte spectabilis 羽管虫 | 硬底附着的滤食生命 | 附着冠部摆动，消费当地悬浮食物代理 |
| Valenciennea strigata 沙地虾虎鱼 | 草床边缘与沉积开口的近底鱼 | 贴近可通行沙面移动；小型沉积动物食物用未解析代理表示 |
| Chlorurus spilurus 太平洋鹦嘴鱼 | 礁面刮食鱼类 | 在实际藻覆硬底附近游动摄食；不宣称专食本包具名葡萄藻 |
| Radianthus magnifica 壮丽海葵 | 适宜浅水硬底的附着宿主 | 固定附着、消费悬浮食物代理；共生光合能量未单独模拟 |
| Amphiprion percula 小丑鱼 | 实际海葵附近的共生鱼 | 仅在同区域真实宿主旁出生并短距活动；宿主死亡后不替换、不再在它旁摄食 |

同时把已有蓝倒吊和条纹蝴蝶鱼接入新探索群落。蝴蝶鱼消费既有代表珊瑚有机库存，不等同咬取新可见团块珊瑚。原定点共生蟹仍保留在旧场景；普通珊瑚宿主尚未逐一鉴定，未借通用珊瑚形状假造专属配对。

目录来源、接受名、体长口径、宿主和选定水深见 [来源说明](OCEAN_BIODIVERSITY_SOURCES.md)。浅海目录现有31个条目，包括固着景观、具名物种和已说明分类层级的代表；这个数不是同屏活体数。

## 如何生成和保存

相邻区域共享世界坐标上的缓变群落偏好，并以真实水深、底质、植物遮挡、岩体和身体足迹作为最终准入条件。珊瑚、海葵、小丑鱼等遵守各自选定水深；海葵的基部支撑与宽口盘净空分开检查。葡萄藻按实际岩面平面贴附，团块珊瑚的实际渲染三角也参与鱼和镜头净空。

新内容只在成功读取为明确未访问的区域出生一次。场景描述与动物记录先保存，再进入活动区和渲染。回访和冷恢复不补生、不恢复死亡、不回填库存。原命名空间、旧种子、旧身份和旧历史保持。当前活动区最多9个，每区总动物记录最多20个（死亡仍占记录名额）；新增动物最多6种，每区附着景观最多20处。景观与动物分别统计。

摄食真实扣除已有当地代理库存，并进入原有物质账本。群落密度、行为速率、日夜阈值和斑块比例未做野外校准。繁殖、幼体补充、迁徙和卸载后的生态演变尚未完成；本批仍是可持续探索的生态原型。

## 本批验收与后续

本批检查普通生成、实际运动/摄食、来源尺度、保存恢复、事务边界、实际几何、资源释放和原生入口。CPU和Native Three检查不代表浏览器整景、GPU性能或纪录片式画面验收。当前没有本批实际浏览器画面证据。

下一包按完整生境扩展：先补浅礁其余软体、甲壳和鱼类形态，再补温带巨藻林的底栖及水层组合，随后扩展深海软底和岩露头生命。每包先完成整体分布、可辨轮廓和一个实际生态功能，再统一验收；不进行无止境的单体材质、叶片或镜头微调。
