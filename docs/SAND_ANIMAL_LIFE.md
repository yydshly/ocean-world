# 沙底与动物活动

本轮补热带浅海的沙底整体显示与真实动物活动反馈。生产浅海开启 `sandHabitat`，沿用原有沙坪、沙沟、缓坡和草缘实际地形，增加粗细底质分区、裸沙纹理和波纹法线。实际岩体、草根和碎石控制显示遮罩，逻辑坐标在区块边缘与浮动原点变化时保持连续。借用原沙贴图及焦散，不增加纹理或地形绘制次数。波纹仅改变光照法线，海床高度、三角形、支撑和保存记录保持。

动物扰沙读取已有蓝斑条尾魟、点线羊鱼、白斑寄居蟹和黑海参的真实活动记录。只有实际沙底、实际近底净空，以及新的摄食时间或真实贴底位移通过检查时，才产生局部显示粒子。羊鱼只在新的实际摄食时触发。粒子随输入水流漂移并向实际海床沉降，固定256槽、每次最多32个、单一Points、零贴图。暂停和零模型推进不运动，不回放旧存档或加载跳时；不写动物、食物、库存、随机状态或存储。它是有限显示代理，不是标定的流体或沉积质量模拟。

沙地生物普通入口优先观察实际沙底羊鱼，接着使用原有魟与其他活体。入口不会强制出生、搬运个体、补充死亡或重建空类别。打开 [本地沙地动物入口](http://127.0.0.1:4175/ocean-world/?demo=benthic&seed=42)，或 [本地草甸](http://127.0.0.1:4175/ocean-world/?demo=seagrass-meadow-region&seed=44)。现有存档仍保留，具体群落依世界种子及历史而异。

草甸导演沿原安全路径巡游，只在前方或侧前方存在真实活群落时平缓偏转视线。最大偏转18度，原6秒章节衔接保留，短暂观察后自然回正。同一真实鱼群的新成员进入范围会加入观察；死亡与卸载立即清除目标。相机路径、动物坐标和生态时钟不变。

原生CPU核验中，新seed42的沙地入口中心有魟、羊鱼、虎斑宝贝和寄居蟹四个本包代表。更新入口距羊鱼摄食点约6.11米、寄居蟹约12.11米，两者中心点在CPU相机视锥内；2模型秒发生2次真实新摄食，触发13个显示粒子，显示调用前后完整活区生态记录一致。seed44同一入口实际只有本包硬底虎斑宝贝，未产生扬沙；这个否定结果保留，不能宣称所有种子有相同组合。

草甸首个真实九区窗口虽有120条活记录，16个已加载路径采样点仅选到一处海马。这明确说明沿线动物布局仍偏稀疏，镜头改进没有完成三层群落的宏观布局。下一阶段优先在未访问海区组织沙地、草缘及水层动物的连续生活带，再扩缺失动物类群。已有记录和死亡不得为了演示重建。

定向原生检查覆盖实际材质钩子、地形字节、遮罩、接缝、真实摄食、暂停、浮动原点、群落连续性、原生镜头调用与入口历史。生产构建已更新本地预览；云端完整回归与发布以GitHub Actions实际结果为准。CPU点投影不代表GPU遮挡、画面质量或帧率验收。

沙纹与波浪、水流和底床过程有关，参考 [USGS沙纹](https://www.usgs.gov/media/images/sand-ripples)；海草生活空间参考 [NOAA海草生境](https://www.fisheries.noaa.gov/southeast/habitat-conservation/why-submerged-aquatic-vegetation-designated-essential-fish-habitat)。本轮未据这些资料标定沙粒质量、流速阈值或真实种群密度。
