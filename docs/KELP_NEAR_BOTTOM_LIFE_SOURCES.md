# 蒙特雷巨藻林近底动物：来源与展示边界

2026-10-07查阅。本包选择 *Cancer productus*、*Sebastes carnatus*、*Heterodontus francisci* 与 *Urobatis halleri* 四个具名代表，延续当前蒙特雷／加州中部设定。它们分别使用岩砾支持面、近岩底水体和相邻软砂底；没有证据保证同一时间、同一巨藻区块四种共存。中文名称为描述性标识，科学身份以目录学名为准。

## 地域筛选

原拟南加州候选没有直接纳入蒙特雷核心。[Burton与Lea2019原始当地名录，p82](https://repository.library.noaa.gov/view/noaa/23850/noaa_23850_DS1.pdf)把羊头鱼当地1931／1958记录明确归为暖水事件；[Holthuis原FAO龙虾图鉴，p142](https://www.fao.org/4/t0411e/t0411e22.pdf)把刺龙虾的Monterey记录标为存疑。现代广域分布不能据此证明它们是当前冷水巨藻林普通常驻成员。羊头鱼的旧组合 *Semicossyphus pulcher* 在[CAS当前分类目录](https://researcharchive.calacademy.org/research/ichthyology/catalog/fishcatget.asp?spid=17186)接受为 *Bodianus pulcher*；本包不通过换名把它重新加入。

## 红岩蟹 *Cancer productus*

[DFO官方账户](https://www.dfo-mpo.gc.ca/species-especes/profiles-profils/red-rock-crab-tourteau-rouge-pac-eng.html)支持岩、砾和巨藻底栖生境、低潮间至至少90m参考深度及160mm甲宽；[Jester等原始Monterey研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7477862/)明确2004–2005年在Santa Cruz Wharf约8–10m捕获本种。10–14cm甲宽、3–20m完整动物水深是展示选择，不是当地尺寸或密度统计。

[NOAA西南区观测员手册的红岩蟹条目](https://www.fisheries.noaa.gov/s3/2021-07/Southwest-Region-Observer-Program-Field-Manual.pdf)描述宽甲、黑尖大螯及对蛤、螺、贻贝、藤壶和小蟹的捕食。本版仅采用床面动物营养部分，不把植物碎屑改称蟹的完整食物。甲宽CW不包括螯或足展。砖红宽甲、两螯和四对行走足区别于已有北方藻蟹；口在前部腹侧，螯尖不是取食口。

## 褐斑岩鱼 *Sebastes carnatus*

[Burton与Lea原名录p57](https://repository.library.noaa.gov/view/noaa/23850/noaa_23850_DS1.pdf)列Monterey原描述与Carmel等当地馆藏。[Loury等2015原始中加州食性研究](https://www.ccfrp.org/_files/ugd/daae59_27fc49392bc94222a6eaf5ffeb598c9f.pdf)实际个体全长16.7–32.9cm，食谱包括蟹、虾、糠虾、蛇尾等，不同地点分量不同。本版25–32cm全长TL不是标准长SL，选择未解析的床面动物分量，不借用自然密度或体重换算。

[Love等2021原作者名录p107](https://escholarship.org/content/qt26n4k816/qt26n4k816_noSplash_fe996ccfe7edd20d76837c6a59b8f3d3.pdf)给潮间至88m参考范围；其43cm后的英寸值有排版错误，不沿用。[PFMC2019具名评估](https://www.pcouncil.org/documents/2019/09/agenda-item-h-5-attachment-11-2.pdf/)支持岩礁近底、常见9–37m及单体领地行为。3–20m为完整身体的展示准入，不宣称Monterey当前频度峰值。[SIMoN账户](https://sanctuarysimon.org/dbtools/species-database/id/209/sebastes/carnatus/gopher-rockfish/)支持厚褐体、白粉不规则斑块的整体形态。本种不套用已有蓝岩鱼身份或竹荚鱼群游。

## 加州角鲨 *Heterodontus francisci*

[Burton与Lea原名录p27](https://repository.library.noaa.gov/view/noaa/23850/noaa_23850_DS1.pdf)列Monterey原描述与USNM112106当地馆藏。[Love等2021原作者名录p13](https://escholarship.org/content/qt26n4k816/qt26n4k816_noSplash_fe996ccfe7edd20d76837c6a59b8f3d3.pdf)明确至少121cm全长TL，广域潮间至201m；广传122cm来自约4英尺，不能当精确实测最大。本版选择65–85cm TL、3–18m完整身体水深。

[蒙特雷水族馆](https://www.montereybayaquarium.org/animals-the-ocean/animals-a-to-z/horn-shark)提供命名活体全形、巨藻底栖与甲壳类／海胆／软体动物／小鱼饮食。[太平洋水族馆报告](https://www.aquariumofpacific.org/reportcard/info/horn_shark)支持典型浅于20m与两枚背鳍前棘；[其自然史账户](https://www.aquariumofpacific.org/onlinelearningcenter/species/horn_shark)补夜间活动和近底生活。本版最多离底2m是显示限制；夜间偏好不是精确时钟校准。不沿用该自然史页误写臀鳍棘的句子，模型只设两枚背鳍前棘。钝头眉脊、宽胸鳍与异尾不能用豹鲨模型换斑纹代替。

## 哈氏圆魟 *Urobatis halleri*

[Burton与Lea原名录p33](https://repository.library.noaa.gov/view/noaa/23850/noaa_23850_DS1.pdf)列Elkhorn Slough三个馆藏与当地原发表，支持相邻软底身份，不能称普通巨藻林内常驻。[Jordan等2009原始研究](https://www.fau.edu/science/documents/jkg09a.pdf)在Catalina Harbor实际采集盘宽DW9.5–24cm个体，并描述腹面口靠底定位食物。本版选18–24cm DW，不把该区域尺寸统计写成Monterey调查。

[Love等2021原名录p27](https://escholarship.org/content/qt26n4k816/qt26n4k816_noSplash_fe996ccfe7edd20d76837c6a59b8f3d3.pdf)分别列33cm DW、58cm TL与0.3–91m广域深度，二者不作线性换算。3–15m为展示选择。[Smithsonian STRI具名账户](https://biogeodb.stri.si.edu/sftep/en/thefishes/species/231)支持近圆稍宽盘、较短尾与圆尾鳍及砂砾／礁边生境。[Valadez-González等2001原始胃含物](https://cienciasmarinas.com.mx/index.php/cmarinas/article/view/375)显示底栖甲壳类、多毛类等；采样为墨西哥Jalisco／Colima，不移用当地食物比例。完整尾和尾刺必须入包络，不能套用菱形长鞭尾魟。

## 量尺、完整形态与食物合同

目录为 `src/kelpNearBottomLifeSpecies.js`，导出深冻结的 `kelpNearBottomLifeSpeciesCatalog`／`kelpNearBottomLifeSpeciesById`。所有资产朝向+X、上方+Y、横向Z；蟹上方随实际支撑法线，其他动物保持世界上方。蟹CW和魟DW沿Z归一，鱼和鲨TL沿X归一。包络包含全部附属体与有限动画；其比例和食点位置是保守制作合同，不是扫描标本或精确自然捕食距离。

| ID | 完整归一包络X／Y／Z | 固定真实口部点 | 姿态与底质 |
|---|---|---|---|
| `red-rock-crab` | `[-.48,.86] / [0,.52] / ±.86` | `(.25,.12,0)` | 实际岩／底面支持，八足参考点位于局部Y=0 |
| `gopher-rockfish` | `±.55 / [-.30,.35] / ±.24` | `(.48,-.065,0)` | 近岩底游动，俯仰±.12rad |
| `horn-shark` | `±.55 / [-.18,.34] / ±.32` | `(.34,-.12,0)` | 岩沙交界近底，俯仰±.12rad，离底≤2m |
| `round-stingray` | `[-1.50,.55] / [-.10,.20] / ±.56` | `(.27,-.065,0)` | 原生软底面，俯仰0，离底≤2m，尾向−X |

新独立床食控制体使用 `region.kelpNearBottomLife.foodPatches[].amount`，每点的pool为`benthicAnimalFood`，绑定原生rock／floor食点的实际支持位置并加明确未校准的微小高度。初库存为零，`foodSupply`控制有上限的外部输入；存量、输入、实际接触摄入、输出分别记账。它是未解析的底栖动物营养选定部分，不能冒充已有可见动物的碳库存或个体捕杀。它不改写、转义、补充或移低旧`algae`、`detritus`与host水层`smallPrey`。旧历史、死亡、空类别卸载后不触发补生或库存重置。

温盐、溶氧与流速自然耐受、自然密度、年龄、行为与摄食速率等未核定项保留`null`。新候选姿态、转身和移动路径检测完整地形／巨藻及旧个体有限占位，不宣称旧控制器已形成全局全部动物的无碰撞证明。灯光和昼夜不生成食物。有限检查及普通入口的实际观察结果以集成后的收据为准，不预填通过数。
