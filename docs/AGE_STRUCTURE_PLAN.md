# 下一步：独立的阶段与出生队列教学模型

2026-10-03。已读 `src/ecology/PopulationExperiment.js`、其测试和 `LIFECYCLE_PLAN.md`。本文件是实施规格，不代表已有生命周期验收。

当前七池模型的 `recruitmentCByGroup` 仅把同化增量分成两个累计标签：补充和生长仍进入同一生物量池。没有幼体、成体、年龄、出生个体数或成熟延迟。它已有的有机碳账本与对照应保留；不能把这个标签改名为出生数。

## 最小范围

新增独立 `AgeStructuredExperiment`，先演示一个匿名消费者功能群，其食物有机碳和碎屑各为一个资源池。消费者分幼体与成体，保留出生队列、结构碳、储备碳和连续的预期个体密度。旧七池、实时个体、世界与 UI 本轮都不改。该模块验证后，可用明确的实际摄取碳接口连接其他食物网；当前不声称已经连接七池。

出生队列比两个总量池更适合第一版的严格年龄下限。单用 `成熟率×幼体生物量` 会使刚出生的部分立即成熟；队列则记录实际出生窗口，必须达到年龄和体型条件才转阶段。默认半天出生窗口用于控制计算规模，判断年龄采用窗口中最晚出生时间，因此不会提前成熟，可能比独立出生时刻延迟最多半天。

## 原始机制依据

以下来源支持机制思路，**不提供本项目匿名功能群的数值校准**。核验日期为 2026-10-03。

- [De Roos 等（2008），Theoretical Population Biology](https://pubmed.ncbi.nlm.nih.gov/18006030/)，DOI `10.1016/j.tpb.2007.09.004`：把食物依赖的体型增长和阶段资源利用／死亡差异连到种群模型；摘要同时指出阶段总量近似无法捕获某些由单一出生队列支配的动态。因此本版保留小队列，不把两个总量池当完整年龄分布。
- [Lika 与 Nisbet（2000），Journal of Mathematical Biology](https://link.springer.com/article/10.1007/s002850000049)，DOI `10.1007/s002850000049`：净生产与维持、增长、储备和繁殖相联系，繁殖使用储备；幼体摄食但不繁殖。本版借鉴收支原则，使用简化的有机碳通量，**不是完整 DEB 模型**。
- [Reichstein 等（2015），Nature Communications 原始实验全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4366502/)，DOI `10.1038/ncomms7441`：在同一实验种群的两个阶段间重新分配固定食物输入，可改变成熟／繁殖瓶颈和采收响应。实验对象为淡水小型胎生鱼；不能把其实验速率或体型直接用于本场珊瑚礁鱼。干预后所有阶段必须同向变化不是验收条件。

## 状态和单位

| 状态 | 单位 | 解释 |
| --- | --- | --- |
| `foodC / detritusC` | g 有机 C/m² | 外部食物与内部有机材料 |
| 每队列 `structureC / reserveC` | g 有机 C/m² | 身体结构与可支付维持／繁殖的储备，分别计账 |
| 每队列 `densityM2` | 预期个体/m² | 连续数密度，可以小数；不是整数动物清单 |
| `earliestBirthDay / latestBirthDay` | 模拟天 | 初始队列可在第 0 天以前出生 |
| `structureC/densityM2` | g 有机 C/模型个体 | 平均体型代理；没有长度—质量标定，不显示为厘米 |
| `stage` | `juvenile / adult` | 年龄和平均结构体型共同决定的教学阶段 |

生物量不能唯一决定个体数：同样 1 g C/m² 可以来自许多小个体或少量大个体。初始数密度和初始平均结构质量必须分别给出。出生碳用显式的 `newbornStructureGC` 换成预期出生密度；这个转换参数标记为未校准，不能应用到 3D 场景的具名动物。

## 每个固定步长的实现顺序

固定 `dt=0.05 模拟天`，默认出生窗口 `0.5 模拟天`。窗口为步长整数倍。同 seed 只随机化初始条件，运行过程中不因数组顺序消耗随机数。

1. 外部输入实际加入食物池；食物和碎屑的开放交换逐笔导出碳。无生产者光合的最小模块不凭空增加消费者碳。
2. 对每队列按死亡、上一步维持不足和阶段采收的合并风险算 `f=1-exp(-h×dt)`；数密度、结构和储备**同时按相同比例**移出，再按风险比例分到死亡回碎屑与采收出口。避免单独限流三个量而破坏每个存活个体的体型。
3. 阶段摄食请求为 `q_stage×structureC×F/(half+F)×access×dt`。共同食物供体不足时统一缩放实际摄取；实际碳分成同化入储备、排出入碎屑和摄食呼吸输出，三份和为摄取量。
4. 先从储备支付维持。只把实际支付量记为呼吸输出；不足部分是维持缺额诊断，不是已排出的碳。缺额增加下一步的饥饿死亡风险。第一版没有身体组织分解供维持，明确这一简化。
5. 储备按有界动员率释放。幼体只支付结构增长；成体在增长与繁殖间分配。增长效率不足的部分记呼吸；成人体型增长受显式最大结构质量约束，没花出去的储备仍留账。储备超过容量的部分回碎屑。
6. 成体实际支付 `C_cost` 时，`C_newborn=η_birth×C_cost` 从成人储备转到新生结构；`(1-η_birth)×C_cost` 为明确的繁殖成本输出；`birthDensity=C_newborn/newbornStructureGC`。幼体、零数密度和空储备不能支付出生。新生队列在步末加入，不能在同一轮继续繁殖。
7. 只有 `当前天-latestBirthDay >= minMaturityAgeDays` 且 `structureC/densityM2 >= maturityStructureGC` 才成熟。成熟只改变阶段标签，原结构、储备和数密度全部保留。累计成熟碳是内部诊断，不能再次加到总碳。

初始队列与出生队列分别保存，不把已有较大幼体和刚出生的小幼体混成同一队列。出生窗口内合并保留两端时间、总数与两种碳；它是平均体型近似，窗口内个体差异未解析。没有种群下限、最低出生数、灭绝自动补回、强制均衡或丢弃微小队列。

## 账本与最小 API

有机碳不变量为 `food + detritus + Σ(structure+reserve) = initial + externalInput - respirationOutput - exchangeOutput - harvestOutput`。同化、增长、出生、成熟和死亡回流都属于内部转移；每项累计数密度另用人口平衡校验。成熟不改变总数；出生增加、自然死亡和采收减少。

```js
const sim = new AgeStructuredExperiment({
  seed: 42, parameters: {}, initial: {}, environment: {}, sampleEveryDays: 1
});
sim.stepDays(90); // 明确模拟天；runMonths(1) 明确为 30 天
sim.setEnvironment({ foodInputMultiplier: 0 });
sim.stepDays(275);
sim.snapshot();   // 两阶段碳、两阶段预期密度、年龄/体型、两本误差
sim.exportCurve();
sim.exportData(); // 初值、参数单位、seed、干预、模型范围、源码版本/来源
runPairedAgeExperiment(42, 365, 90, { foodInputMultiplier: 0 });
```

计划新增 `src/ecology/AgeStructuredExperiment.js`、独立 tests、批量脚本与验证报告。`PopulationExperiment` 接口和行为不变。默认参数只取有界的教学数值，完整参数表在实现文档中保存，不挂具名物种。导出以 `expected individuals/m²` 标记数密度，`countsAreContinuous=true`，`mapsTo3DIndividuals=false`。

## 本轮交付验收

| 检查 | 通过条件 |
| --- | --- |
| 可重复 | 同 seed／参数／干预在不同调用批次下状态与曲线完全相同；reset 恢复初态 |
| 最小成熟年龄 | 新生队列不能提前成熟，达到体型但尚未达到年龄仍为幼体；低食物可推迟体型成熟 |
| 无免费出生 | 无食物且空储备时出生为零；成熟／出生的碳来源可追溯；零人口不自动重生 |
| 停食响应 | 同 seed 干预前严格相同；存量食物／储备可短期支持繁殖；足够长的停食观察窗应显示出生供碳衰退，以实际结果报告 |
| 死亡回流 | 同比例移出密度与两种碳；自然死亡回碎屑、采收出边界；不能把被捕食碳再完整回碎屑 |
| 数值和账本 | ≥5 seed、365 天逐步有限／非负；碳误差目标 <1e-7 g C/m²，人口误差 <1e-8 个体/m²；保存实际最大值 |
| 队列规模 | 默认半天窗口，365 天最多约 733 个初始／出生队列；不靠无账丢弃队列控规模 |
| 时间分辨率 | 独立半步长和半窗口敏感性对照，报告差异；不把非负供体限制当作准确性证明 |

要支持真实数量预测，还缺：物种、地点和季节对应的幼体出生结构碳、体型—碳量换算、成熟年龄／体型、摄食与同化、阶段死亡、繁殖投入和卵／仔鱼存活、迁移和野外初始年龄组成，以及校准与独立留出验证资料。当前可自主选未校准教学参数实现因果机制；不能据此输出鹿角珊瑚、倒吊或海带林具名动物的野外出生率、寿命和丰度预测。
