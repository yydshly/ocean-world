# 浅海样板 v1.0 · 本地冻结

冻结标识：`shallow-sample-v1.0-local-20261012`。用户明确要求最后一次有限收尾，验证完整 75 秒后停止默认推进。此决定覆盖历史记录中的后续资产升级建议。

本轮只处理支撑查询、启动计算和 GPU 资源准备，没有新增物种、替换资产、修改画面风格或改动持续探索存档。原有 293 只动物、38 个展示类别、体长、落点、海床和路线保持；类别数量不等于准确鉴定的物种数量。

## 实际修改

- 扫描礁体按三角形高度上界排列查询候选，已找到上层支撑后跳过不可能更高的三角形；保留原浮点顶点、边界容差及等高面的法线选择。
- 礁体到路线的距离计算先排除轴向距离已超过当前最近值的点，避免反复创建大数组和无用距离计算；落点结果保持精确一致。
- 播放前让现有渲染批次完成一次 GPU 上传，包括未入镜的动物及隐藏 LOD，然后恢复原可见性与剔除标志。编译失败或取消也会恢复标志。

最终构建通过。87 项浅海与公共岩面相关检查一次全部通过；最后的资源准备改动另有 2 项通过，合计 89 个不同检查，不冒称同一次 89 项运行。

收尾前后源码对照：布局和海床精确一致，151 个时间点的全部 293 只动物姿态及镜头位置精确一致。支撑、活动范围与镜头净空相关检查通过；实景抽查未见明显穿地或穿岩。这不等于所有动物之间、所有视角的动态碰撞证明。
