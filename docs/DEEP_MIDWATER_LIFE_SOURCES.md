# 离底中层水体群落：来源与展示边界

本包选取三条具名的蒙特雷／东北太平洋中层代表：`Periphylla periphylla`、`Vampyroteuthis infernalis`、`Neognathophausia ingens`。共同展示门限为**整套身体和附肢都在650–750米实际水深内**。这段水体离原约3500米海床很远；不把动物压到海床附近，不使用海床食物库存，也不以改地形来满足水深。三种地域与垂向证据相容，但不是一次同站共现调查或完整生态重建。

糠虾旧原论文常写 `Gnathophausia ingens`，目录使用接受组合 `Neognathophausia ingens` 并保留旧名。Monterey900米照片证明区域存在；San Clemente Basin提供加州同垂向带的原研究依据，两者分别标注。3–4英寸的MBARI照片说明没有注明量尺，不拿它转换CL。展示选择用DFO具名账户明确的含额角长度口径：额角尖至尾节尖；触角仍是额外附肢。此包只取非抱卵形态代表，不把深层抱卵雌体的阶段和摄食情况混入。

2012吸血乌贼PMC入口在本次读取中有验证码限制；公开索引提供原文采集段，MBARI同日原作者研究报道可完整读取。未绕过验证码，不把未读取的表格数值写入目录。

包络单位分别是该行的铃径、ML和含额角轴长。它们是**包含完整附肢与有限动画的作者保守净空**，不是野外扫描比例或自然最大展开形体。头足和糠虾的局部heading为+X、up为+Y，展示pitch限制±0.12弧度；水母保持+Y铃顶、pitch为零。根和捕获器官参考不由局部动画移动。

冠水母全体形依据[Lindsay等JAMSTEC原作者开放分类章节的Periphylla账户和Fig51.31](https://link.springer.com/chapter/10.1007/978-4-431-54865-2_51)：高而尖的铃、冠沟、16个铃缘瓣、4个感官结构和12条实心边缘触手。图中日本751米样本只提供形态，不能拿来冒充Monterey采样。[WHOI说明](https://www.whoi.edu/ocean-learning-hub/ocean-facts/helmet-jellyfish/)报道触手最长约50厘米；本包固定触手展示长为1.90个铃径，在最大选定铃径下为47.5厘米。这是可行姿态选择，不是某一自然个体铃径与触手长度的配对测量。没有四条海蜇式长口腕。

吸血乌贼完整保留外套、头和眼、成体两鳍、八腕、腕间蹼及**两条细长采食丝**，不添加十腕乌贼式两条粗棒状触手。MBARI原研究报道极展丝可长达身体八倍；本包选择双丝部分伸展的完整姿态，一条向前、一条回弯，不宣称已模拟最大伸展或剪掉不可见端点。丝尖接触收据表示所选颗粒捕获与扣账，未重现其后的收丝、刮取、黏液汇集和口转运，也不是这些过程的实测效率。

糠虾完整轮廓来自DFO具名侧／背视全体图、口器、附肢、尾扇和MBARI活体照片。保留额角、柄眼、细长触角、甲壳、腹节、胸足、腹足和尾节／尾肢；不用底栖螯蟹或十足目大螯造型代替。选择值没有利用CL—全长推算式，模型不模拟抱卵、蜕壳或自然垂向迁移。

## 所选食物组件与控制体

- 冠水母使用 `midwaterAnimalFood`：浮游动物中的未解析悬浮动物性部分，依据MBA具名食谱；不模拟具名活体猎物被杀或刺细胞过程。
- 吸血乌贼使用 `midwaterOrganicParticles`：海洋雪死有机残屑部分；不因名字把它写成主动猎食者，也不把偶然附着的小活体当主要配方。
- 巨型红糠虾使用 `midwaterOrganicParticles`：MBARI说明中的沉降碎屑／小型死亡动物有机部分。仅声明这一分量，不以同一个代理取代所有生命阶段和地域的完整食谱。

真实库存路径固定为 `region.deepMidwaterLife.channels[].parcels[].amount`。每个渠道的有类型库存独立，初始为零；实际有账外部输入、有限水体输运、真实捕获器官接触、扣减和离开控制体的输出。来源位置不跟游动动物瞬移。`foodSupply`和水流可控制展示输入／输运；这是有限局部食物代理，没有声称重建海洋雪通量、自然沉降速率、颗粒大小分布或完整氧最低带能量学。原生海床与岩附着库存、位置及账目不被借用、移低或补满。

## 未知项与范围

目录将自然密度、自然年龄、环境耐受温度／盐度／溶氧、自然游速、生态率和真实能量含量保持为`null`。论文中的实验温度不是野外耐受门限；氧最低带关联也不等于拥有已标定生理模型。所有展示数量、率、捕获距离、比例与状态阈值保持未校准标签。

三种来源均提到防御发光，但这不支持默认常亮自发光；本包不添加未经验证的持续发光着色。现有测试／账目能检验实现的净空、时钟、输运、库存和历史恢复，不能据此声称纪录片视觉质量已经验收。
