# 草甸动物生活带

本轮把已有真实动物沿草甸主路组织成连续生活带。此前草核、草缘和沙路的区块配额没有鱼群位置，动物候选也按整个64米区块排序，区块内有动物不代表走在主路上能遇见。

生产热带浅海开启 `meadowAnimalBelt`。仅整组12个区块严格未访问时，新草甸生态记录使用独立的 `route-neighborhood-v1` 出生规则。实际主路周边提供有限候选：近底羊鱼与其他适合实际底质的动物、真实草叶宿主的海马、符合水深与完整巡游净空的水层鱼群。全部复用已有模型、控制器和食物账；本轮没有增加具名物种。

动物在出生前检查真实底面、草根和岩体，鱼群还检查完整身体、同伴间距与巡游盘。沙底、草叶和岩面动物各自沿用原有支持条件。无法通过条件的候选仍然为空，不移动宿主或出生后的记录。每区最多20条全部动物记录，包含死亡与海龟；只公开当前9个活区与最多25个支撑来源，探索时继续按种子生成新区。

新规则随生态记录原子保存，冷恢复时重新验证。已访问的旧草甸、死亡和空类别保持，不升级或补货；损坏的标记与不完整组拒绝再生。保存失败不会公开新群落。食物仍是已有的相对营养代理，不宣称完整自然食物网或校准过的真实密度。

原生新种子45的目标草甸保存194条实际动物记录、22种已有代表和10个鱼群；三普通九区窗口各推进0.6模型秒，135个体移动、35个体摄食，其中鱼群62个体移动、20摄食。39个10米间隔采样站的14米近邻均有动物，去重121条近距记录。水层21站、草缘33站、近底38站；同站可能有多个层，不能相加成沿途长度。原镜头中心点视锥仍有6站为空，角度观察选择有17站为空；这些是实际记录的限制，不能宣称始终在视野中。

本地可用 [新世界草甸入口](http://127.0.0.1:4175/ocean-world/?demo=seagrass-meadow-region&seed=45)。种子45进入另一个持久世界，保留原来的44世界；已经访问过的45世界也会继续使用其历史。可自由移动观察，导演模式继续沿原路巡游并观察实际活群落。

原生验证记录实际路线上的近距动物与群组、完整支撑、运动、摄食、食物账、保存和冷恢复。沿途覆盖结果以 `output/validation/meadow-animal-belt-delivery.json` 的实际模型记录为准。CPU距离与视锥证据不代表GPU遮挡、整体观感或帧率验收。

本轮完成后继续扩展整片生境与缺失动物类群，避免转入单体或镜头细调。
