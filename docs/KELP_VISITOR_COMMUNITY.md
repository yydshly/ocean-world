# 海带海域的大型近底巡游动物

本轮按“先整体，不要过度细节优化”补一种更容易在正常观察距离辨认的大型动物：1.2～1.5米总长的豹鲨（Triakis semifasciata）。使用一次有限轮廓制作，保留原地貌、根群、叶面、材质、原动物造型和既有观察方式。豹鲨浅水近底活动及偶入巨藻林的方向依据[蒙特雷湾水族馆](https://www.montereybayaquarium.org/animals-the-ocean/animals-a-to-z/leopard-shark)与[NOAA蒙特雷湾海洋保护区](https://sanctuaries.noaa.gov/pgallery/pgmonterey/living/living_11.html)。密度、路线、速度与本场体长选择是展示参数，并非野外调查结果。

分布由带类型的种子与世界坐标决定，不随镜头生成。新版真实支持面上检查4～20米水深、开阔底床与藻株空间，适宜格中最多一只；无合适路线就留空。活体与死亡记录都计入原每格20个动物的上限，九格活区继续有界。已有蓝岩鱼跨格接收容量也包括新动物。

巡游限定本格内，16个有限路线点随真实底床高度安排。每个固定步完整XYZ位移不超过0.28米/秒×步长，转向不超过0.8弧度/秒×步长；检查身体的九个支持点、步内中间位置及邻株自己的地理时钟。水平半径0.58×体长+0.12米、垂直半高0.33×体长覆盖现有鱼体俯仰与尾摆；有限藻株包络不是完整动态叶片碰撞，也不是流体力学。离开活区冻结，没有后台演化。

本阶段只模拟巡游。豹鲨没有能量、摄食或繁殖字段，不消耗旧食物、不制造食物，不参与平均能量；界面与图鉴明确说明。原模型默认不开启新群落，实际海带海域显式启用。新增visitorAgents与一次性版本/初始时间三字段在完整提交后激活，保存失败不发布；死亡不补充，空格也不反复分配。旧版非原子存储不新增，关闭功能后保留并冻结已有新动物记录。v1地形只保留旧群落，不创建豹鲨标记；带新动物标记却声明旧支撑版本的记录拒绝激活，不重建旧人口。

最终单批212/212相关测试通过，26项新测试已包含；构建通过。独立执行冻结的原生态，比较完整旧记录/RNG/食物/正库存与口部摄食历史，覆盖提交失败、死亡/容量、非法保存、实际地貌支持、转向/位移、暂停、卸载/重开、旧造型完整网格/姿态、拾取与资源释放。第一批210/211的唯一失败是旧阶段对整个动物分派器的文件哈希不允许新增分支：保留两个原形态文件哈希和实际口部变换断言，新增测试比较全部旧动物网格/姿态，适配后最终完整批次通过。失败日志保留。独立审查发现并修复v1分配缺口，新增回归证明不分配且非法组合不激活。原11项历史子集外失败单独保留，未宣称全项目测试全绿。

93个源文件冻结，5个旧源变化、3个新增模块，85个旧源SHA保持。原生成器、宏观支持面、原林模型、所有旧动物造型、浅礁及深海实现均保持。存档升级时旧记录完整保留；新动物占用容量后可能影响以后蓝岩鱼的跨格接收，这是共用上限的预期行为，不宣称新旧长期轨迹永远相同。

实际浏览器从原位置恢复：暂停升级保留121个旧动物和九整区的全部公开字段，新增4只豹鲨。正常1×沿已有导航北行64米，进入真实豹鲨所在格；用已有观察入口在普通距离看见完整轮廓与周围海床。一次记录的65.6秒1×观察中，同一只活体净位移13.467米；全过程累计122.7模拟秒后暂停，未把净位移当成总路程。

新增第六个手记“开阔海床豹鲨”，原五个不改。通过已有远处手记前往2,0，真实卸载全部旧九区，再回访−5,−2；回访及暂停刷新保留101个动物与九整区的完整公开记录。800个有限公开核对包含身体支持参考，不是800种独立生态情形；隐藏状态与完整步进另由冻结源码测试承担。最终1×、暂停、无个体跟随、错误为空；浏览器是4173开发页面，生产构建另行验证，瞬时帧率不证明长期流畅。

整体仍是雏形：空地画面仍偏空，景观巨藻与模拟代表仍不同，普通静止镜头不能保证巡游动物一直入镜；本轮不扩食物网、不继续鱼体细雕或叶面/镜头迭代。下一轮按连片生活空间和可见群落组合继续评估，Goal状态单独保持。
