# 非椭圆礁石足迹：共享正向／反向映射

日期：2026-10-03。修订来自[实际全景复核](REEF_WEATHERED_VISUAL_REVIEW.md)：前版虽然通过接触检查，实际画面仍呈现重复圆裙与钟罩。本版改变XZ轮廓并去除闭环台阶；尚无修改后实际画面，不能宣称视觉通过。本任务未改World、材质、骨架源文件、冻结构建或历史报告。

## 表面合同

11块主礁用六个距离、方向不等的断面限定边缘，保持在原REEF_ROCKS米制椭圆包络内。桥盖和辅助小石保持原轮廓。中心规范半径0.38以内的XZ映射恒等，上表面保持原式；48个既有种子珊瑚位置与体型精确不变。外圈径向映射为`g(r)=r×[1−(1−k)×smoothstep(.38,1,r)]`，k为该方向的断面边界半径；下半部在最终世界XZ处取沉积高度。原环形层位函数移除，外肩只有单侧断裂斜面及横向受限的短凹口。

| API | 输入／返回 |
| --- | --- |
| `reefRockFootprintContains(rock,nx,nz,paddingNormalized=0)` | nx/nz为**世界XZ相对旧外椭圆**的归一化坐标；返回是否在实际断裂足迹内，padding也为归一化长度 |
| `reefRockCanonicalCoordinates(rock,nx,nz)` | 同样接受世界归一化XZ；返回inside、反解的规范nx/nz/radius、worldRadius与boundaryRadius；外部点的规范值为null |
| `reefRockSurfaceY(rock,nx,ny,nz,bedSupported)` | 接受世界归一化XZ；主礁ny只选择上下支，外核反解一次后计算高度；外部点返回有限沉积高度，但没有岩石区间，调用方须先检查contains |
| `reefRockSurfacePoint(rock,nx,ny,nz,bedSupported)` | 接受**规范网格**参数；同时正向映射世界XYZ，直接调用规范高度计算，不反解第二次 |

外核使用20次二分反解，中心无需二分。`habitatHeight`先检查实际足迹再查询上表面。旧椭圆仅可保留为相机的保守粗筛；实际进入判断和地形样本不能继续假定旧椭圆每处都有石头。World整合由Root负责，独立报告不冒充已完成相机接入。
