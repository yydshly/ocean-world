# 礁缘床面与水层群落

这轮改进实际动物分布。此前候选出生点主要围绕礁石，游泳动物也集中在低水层。新配方沿既有礁谷路径，在真实礁体附近增加床面和离实际支撑面约0.8米、1.8米的水层候选位置，体型偏移另计。每个区域最多增加32个候选中心；候选不是新增动物，最终仍检查完整身体、深度、底质、真实触点、植物与其他动物占位。

新动物配方为 reef-residents-v9，地形仍是原v8礁谷。36类已有居民共享自然余量，居民最多10只、全部动物记录最多20条每区，死亡及海龟也占位。完整十二区严格未保存时才生成，并原子保存后公开；历史配方1–8、死亡、时钟、资源和未来随机行为保留。

## 新版演示入口

[本地新版礁谷](http://127.0.0.1:4175/ocean-world/?demo=reef-valley-region&seed=55&world=habitat-layers)。它使用种子55的原地形、原连续观察路线和独立动物存档；原种子55的动物历史保留。普通入口仍使用原存档。刷新新版入口会恢复新版自己的历史，不持续补充动物。

这是独立动物存档入口。探索记忆、发现记录和全局环境仍属于同一种子，不是全部世界设置的副本。保存命名空间与出生随机命名空间分开，因此演示副本与普通新世界采用相同的地形和出生选择。

## 实际结果

同样的种子55、原地形、427.639米路径及238条动物记录下，当地实际目录类型由52增至56；居民仍79只，类型由26增至30。14只居民使用新增位置，其中4个床面位置、10个水层位置。上一批四种实际选中大梭鱼1、蓝鳍鲹1、东方胡椒鲷1、豹纹鹞鲼2，不是强制配置。

三个普通九区窗口合计9模型秒，75只居民移动、74只摄食。梭鱼、蓝鳍鲹及两只鹞鲼均移动和摄食；胡椒鲷在白天休息，0移动/0摄食。完整冷恢复、资源守恒及原非居民出生一致。独立新版入口首窗1秒另有122条动物移动、45条摄食；两项检查时间和数量不相加。

四类新动物在路径某处能进入14米CPU近邻：鹞鲼约183米，另外三类约377–388米，不能理解为入口立即同框。每10米出生采样仍有80/150/160/340/350/360米空站，与旧配方相同；本轮没有解决沿途覆盖空段。

55个唯一定向检查和一次生产构建通过。旧1–8配方完整32步输出逐字节一致。保持9活区、25公开支撑、97私有预读上限和导演67章/61动作/1994秒。冻结结果见 output/validation/reef-habitat-layers-delivery.json，区分早期完整数值报告与最终源码验收，保留初次失败诊断。

CPU生态、完整身体与存档已检查；GPU观感、遮挡和帧率尚未验收。目录仍是79个代表条目，食谱代理、自然密度和速率未野外校准。下一步优先补整片生活层和沿途空段，本轮不继续单体、材质或镜头细调。线上状态以对应提交的Actions发布结果为准。
