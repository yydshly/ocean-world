# 深海岩石附着群落

本包补充约3500米东北太平洋硬底的两种外形：长柄羽状冠的`Thalassocrinus alvinae`海百合，与弯曲主轴、交替回弯羽枝的`Alternatipathes alternata`黑珊瑚。它们是具名生境代表，不是一个实测站位的物种普查。原始来源、计量口径、鉴定局限和未知条件见[来源说明](DEEP_HARD_LIFE_SOURCES.md)。

目录为`src/deepHardLifeSpecies.js`，导出递归冻结的`deepHardLifeSpeciesCatalog`与`deepHardLifeSpeciesById`。海百合按单臂弧长选择12–15厘米，准入3400–3500米；黑珊瑚按全体高度选择25–30厘米，准入3400–3600米。完整体形另有包络，不能把海百合臂长当成整株高度。

新增动物采用实际原生岩石宿主，底座与岩面接触，完整身体和附属体需要净空。每区最多4条新增独立记录，允许分散在不同岩石上，允许自然缺失某类。已有软底动物和旧摄食库存保持各自来源与行为。

新食物控制体有`particulateOrganicFood`、`smallSuspendedAnimals`两种选定食物分量。初始库存为0，外部局部供给、有限粒子运输、真实食点接触、摄入与输出分别记账。海百合只摄入营养有机颗粒选定部分；黑珊瑚只摄入悬浮小动物选定部分。输入不是测得自然碳通量，也不宣称完整自然食谱。

固定食点和底座与可见资产一致，其余冠部或羽枝只能作有限姿态动画。灯光和昼夜不供能。动物时钟、能量、死亡状态、食物库存及控制体账都需要随完整历史保存，暂停不推进，冷恢复不能补生或补库存；未知或损坏历史应拒绝启用。

普通入口为`?demo=deep-hard-life`，观察按钮“岩附着群落”。实际入口`x=10019.58,z=515.40`在原生区`156,8`，同一真实岩宿主的两个不同位置各有一条新增记录，全区原有与新增动物合计14条。导演对应章节观察14秒；全导演路线为60章、54个已有动作、730秒观察时间，加载与转场另计。

`tests/deep-hard-life-ecology.test.mjs`的6项生产验证通过。两个普通九区窗口`156,8`与`160,8`各观察4秒，52条新增独立记录保持附着，52条都发生实际外源粒子摄入；海百合25条、黑珊瑚27条。各区动物总记录最多19条，低于20条上限。外部输入0.00832、摄入0.00416、输出0相对单位，剩余颗粒库存继续保存。新旧食物账、合并总账和条件账误差均小于`1e-8`。完整证据在`output/validation/deep-hard-life-model.json`，不是浏览器画面或视觉验收。

死亡个体、自然缺失类别、卸载重访和冷恢复保留完整历史；启用新包不会向旧存档补生。原子提交暂停或拒绝、未知读取以及14种直接/画外历史损坏场景均经过检查。这个有限验证不宣称所有岩石、深度或任意流速都具备两种动物，也不把显示数量当成自然密度。
