# 连续海带海域的整体地貌

本轮按“先整体，不要无限细化”交付连续底床起伏、连片岩底台地与低洼沉积通道；可用空隙稀疏生成成对低岩脊。沿用原有纪录片风格、物种和探索入口，没有继续叶片、个体或材质雕刻。

地形、绘制、根部、动物支持与航行避障共用真实三角形。原40米林区及触及其边界的三角形保持，外海地形偏移约−1.2～+5.8米。岩脊每组2条，约20～28米长、6～8米宽，中间保留10～14米通道；全旧岩石和根部保护，找不到空隙就不生成。固定1平方公里的三个种子样本产生4、6、4条新岩脊，未将该样本范围作为海洋边界。

森林覆盖继续使用原种子分布，台地权重与旧林区分布关联。植物X/Z、宿主、ID、数量与旧岩石形状不变，Y及水下长度按实际底床重算。新岩脊属于景观，不提供新的食物库存或动物密度。浅水岩质底床上的巨藻林方向依据[NOAA海带林介绍](https://montereybay.noaa.gov/science/characterization/kelp-forests.html)；本地高程、密度与通道尺寸都是示意参数，不是蒙特雷实测地形。

旧`kelp-ecology-v1`存档先使用精确旧版支持面校验，再进行一次`supportGeometryVersion:2`转换，完整保存后才启用。活体的支撑坐标、植物显示长度及附着点随新几何调整，既有生长增量、身份、死亡、时间、RNG、能量、资源与账本保留。旧摄食历史始终按原支持面验证，新摄食记录标记当前几何版本。读界面时不再把死附着动物的旧支持改写为活宿主的新支持。

独立测试执行冻结原生成器、原生态与原摄食代码，比较完整旧记录，只允许声明的支持字段改变，覆盖正库存、旧口部接触、死亡、已有生长、提交失败重试与卸载重开。历史镜头/颜色/侵入测试明确指定v1，保留原断言；新v2由真实地形和完整迁移测试验证。原失败日志保留。

最终单批186/186相关测试通过（24个新增项已包含），生产构建通过。90个源文件冻结，4个旧源变化、2个新增模块，84个旧源SHA保持；原林模型、真实物种形态、浅礁和深海源保持。未运行/宣称全项目测试全绿，原11项子集外历史失败单独保持。

实际浏览器：旧190米林缘位置9区、140动物恢复为v2，115个动物Y发生支持调整，其他声明外字段与九整区食物/时钟精确保持。正常1×从`-1,2`至`-1,-4`航行432.9504米，36.354实际记录秒，全部旧九区卸载，加载完成仍九区。末端林间空地57动物及九区完整公开记录暂停刷新后精确保持，五旧手记保留；资源汇总求和误差8.88e−16、逻辑镜头重基误差1.78e−15。公开DOM不能证明隐藏状态，其验证由独立冻结源码测试承担。收据与核验在`output/validation/kelp-macro-landscape-browser-verification.json`。

随后仅用既有邻格导航，从`-1,-4`经三个南西邻格与一个西邻格来到`-5,-1`，实际加载`-5,-2`的两条同组岩脊；公开formation计数2、group计数1，九区无错误。最后使用既有“观察林缘群落”留在同格的林中整体视图，121动物、九区、无个体跟随、暂停1×。`kelp-macro-landscape-browser-outcrop-window.json`和`kelp-macro-landscape-browser-final.json`记录实际状态；最终整体截图不是与旧190米位置的同镜头对比，也不作为两条岩脊都入镜的证明。

整体仍是雏形：普通水层远处可能只见水雾，新增岩脊稀疏，当前190米林缘窗口没有岩脊，不能把未入镜的结构算作画面效果。未新增动物或完善食物网；未加载区仍冻结，未证明长期帧率。历史死植物仍有活依赖动物的特殊记录可能继续读取旧宿主显示锚点；当前模型不会自然产生该组合，生命史支持应在以后整体生命周期阶段处理，不借此开启新死亡/枝叶细调。本轮不继续镜头或地貌造型迭代。
