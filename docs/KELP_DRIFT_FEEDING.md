# 巨藻脱落藻料与紫海胆摄食

本轮补温带巨藻林的生产者／消费者链。此前代表巨藻的 `kelpTissue` 有光合输入和0.01/模拟日的自然脱落流，紫海胆只摄取岩面 `algae`。现在在持续海带林中，将可达宿主的这股既有脱落流转到同岩林底藻料库存，既有海胆接近后才能实际摄食。

[蒙特雷湾水族馆的紫海胆资料](https://www.montereybayaquarium.org/animals-the-ocean/animals-a-to-z/purple-sea-urchin)记载藻类食性、管足将食物传到腹面口部，以及漂来藻料和摄取巨藻的自然关系。本版只实现局部落料与摄食代理，未重建某一调查样方的密度或速率。

库存使用原模型的相对有机代理单位。脱落来源必须从现有组织移出；同一份不能重复进入原碎屑池。海胆所得来自实际落料库存，既有总食物账与独立落料过程账分别核对。没有凭空追加初始落料或环境输入。显示的少量薄叶段是落料点的代表形状，面积不表示克数、碳、热量或真实叶片数量。

默认原林模型保持原始状态与行为；持续海带林一次零库存兼容保存后启用，旧动物、宿主、资源、时钟和随机流保持。旧存储接口不能共同保存时保留原局部模型。新过程只推进已加载、未锁定的当地所有者，离开后冻结。

植物形态与附叶钟螺的共享叶面继续原模型。相对组织指数不能直接缩放整株，故本轮不制造叶片消失、整株倒伏或秒级海胆荒漠；也不模拟漂浮藻片从冠层到林底的完整水动力路径、风暴、死亡、再生或离屏演化。

实现范围：`kelpDriftEcology.js` 管理每个代表宿主最多一个收集点，沿用原宿主的第一块同岩资源点。每点库存上限1相对单位，溢出仍进入原碎屑池；失去活宿主的已有落料返回原碎屑池。两个去向共享一次组织扣减，内部转移不增加总账的输入。

海胆保留0.0006 m/s爬速，完整XYZ步长与有限沿途支持检查约束同岩移动。最近可触及食物与旧岩面藻膜共同决定局部选择；0.004 m接触范围内、原8秒摄食间隔允许时才扣库存，每次最多0.0009相对单位。当前天然脱落量远小于该上限。口点来自既有海胆模型归一化后的腹面参考，不改变旧动物几何。口部够不到薄落料点的大个体继续旧岩面摄食。上述阈值、偏好、能量系数为展示近似。

可见薄叶片的七个顶点与模型食物参考相同，各点采样真实岩面；有限三角形内部探针拒绝埋入岩面的落点。形状固定，并非食物单位到面积的换算。独立渲染器不随机放置、不增加食物、不推进时钟，零库存、宿主死亡或卸载时释放自有几何，复用材质。它不作为新动物或额外景观数量。

总食物账同时计入五个旧资源池和新落料库存。独立 `driftLedger` 记组织转入、海胆摄入、退回碎屑，保存每点最后一次转移和每海胆最后一次实际摄食的有限历史。历史包括真实海胆姿态、岩面支持、食物顶点、口距、扣量和能量实际增量。正库存恢复后即参与总账；共同保存接口缺失时保留该库存及历史、冻结新过程，旧局部模型继续运行。兼容升级只追加零库存元数据，保存成功后才激活。

验证已完成。最终相关单批165/165通过（57.832秒），包含10项新生态与9项新渲染测试，不累计重叠复验。完整默认三个种子的初始与10秒状态、Map、RNG、食物、账本和指标精确保留。独立普通生成回放明确运行600模拟秒，原海胆速度、同岩支持、沿途XYZ预算、组织扣出、库存和两套食物账均通过；最初90秒未摄入的日志保留，到达实际最近约0.163米落料点至少需要272秒，未为通过测试改出生点或速率。

独立检查修复了两个实际缺口：直接喂食缺少真实根部支持约束、历史口点未绑定真实海胆姿态；恢复正库存后原生指标遗漏落料库存。归一化口部参考还由原渲染器实际顶点核对。新测试现在覆盖这些反事实、损坏记录、锁定、保存失败、默认旧存储回退、暂停及完整隐藏存档保持。首轮相关162/165的三项失败来自旧测试用当前新库存伪造旧几何／旧水层档案；两份测试改为真实旧五池记录或先提交零库存落料再仅撤水层，保持原保存失败与逐字段断言，最终单批全通过。初轮与第二轮失败日志保留。
