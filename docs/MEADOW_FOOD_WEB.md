# 草甸捕食者的食物循环

本批修复草甸海马、礁乌贼漏接现有动物性营养补给的问题。新入口：<http://127.0.0.1:4175/ocean-world/?demo=seagrass-meadow-region&seed=56&world=meadow-food-web>。历史入口刷新后，顶部“最新海域”会保留入口与种子，切到新的独立动物历史。

## 查明的问题

上一批56号目标海区的十二个所属区域中，十个区域的原动物性营养初始为零；其中九个有海马或乌贼，却没有章鱼或蟹参与原补给循环。原`tickReefGuildPool`只计入原礁类消费者与后来加入的礁居民，没有计入草甸捕食者。因此，物理上成功到达也不等于当地有食物可取。

原生初始诊断保存于`output/validation/meadow-food-web-diagnostic.json`，同时冻结了原生v1完整出生记录。这个诊断说明了漏接及许多owner的空库存，不把所有乌贼未摄食都归因于同一个原因；未到达、夜间或其他消费者竞争仍可能导致没有摄食。

## 本批实现

仅新建`meadowLifeForagingVersion=2`的记录，将实际存活、版本匹配的海马与乌贼加入原有补给消费者，最多两个。不增加动物记录、物种或初始食物，不为演示强行填充库存。海鳃继续取悬浮营养，蜘蛛螺继续取藻类，不计入动物性食物消费者。

沿用原模型的“有机碎屑支持未分辨的小型底栖动物营养”近似：每次补给真实扣除当地`resources.detritus`，增加`reefGuild.preyOrganicUnits`，并记录原食物账的内部转出。原系数和库存上限保持，每个新增消费者每模型秒最多转化0.000025相对单位，目标库存上限0.018相对单位。系数不是实测动物数量、质量或生长速率。

食物的产生是模型内营养转移，不是直接让海马或乌贼吃碎屑。已有有机收支涵盖摄入、体内保留、摄食碎屑和输出；没有食物时不提高摄食量或体况。碎屑为零、没有新版本存活消费者或已有营养达到上限时，没有这部分补给。

乌贼仍必须在日间实际到达合格近底目标，完整身体与路径通过物理门槛后才能扣粮。海马仍抓附实际静态草叶。动作使用所属生态时钟，镜头运动和渲染墙钟不能补粮或推进生态。

## 存档与范围

旧`meadowLifeForagingVersion=1`与更早记录保持原食物方程和未来行为，不迁移、补出生或补粮。普通/导演未访问的新owner启用v2；显式`world=meadow-foraging`仍产生原v1配方，旧礁演示亦保持。`world=meadow-food-web`有独立动物历史，同种子地形、出生随机键保持；环境、探索和发现仍共享。

浅海目录仍94条代表；礁居民仍v19/51候选。原20全部记录含死亡与海龟、九活动owner、25公开支撑、97私有预读及十二区全null/原子保存规则保持。本批没有增加小型猎物的可见个体、空间猎物斑块、真实捕杀、繁殖或完整天然食谱，也没有解决蜘蛛螺在56号目标海区自然缺席的问题。

本批有限验证结果与收口在下文及忽略目录`output/validation/meadow-food-web-delivery.json`。本地源码、生态、几何与构建检查不等同于浏览器整体画面、遮挡和帧率验收。本阶段没有暂存、提交、推送或部署。
