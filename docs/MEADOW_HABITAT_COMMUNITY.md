# 草甸与沙地群落组合

这轮扩展整片草甸的动物生活层。旧配方每区最多容纳两类草甸特色动物，并优先生成同一种鱼群；新配方让海马、礁乌贼、棒状海鳃和蜘蛛螺各自按真实生境参与选择。总动物预算仍为20条，草甸特色层最多4条，鱼群在适合的水层形成5个真实成员。已有近底羊鱼、寄居蟹、蓝斑魟、虎斑宝贝及海龟继续使用原配方。

这是已有动物的生境组合扩展，浅海目录仍为75个代表条目，没有增加动物模型。鱼群不再总是优先乌尾鮗，使用种子决定的选择顺序，完整身体和巡游净空仍决定最终能否出生。三种候选鱼不是每片草甸都同时出现。

新规则仅作用于整组12个区块严格未访问的草甸。规则与完整群落先原子保存，再公开；所有区块必须保存同一版规则。原v1存档、死亡、资源、时钟和后续随机行为保持，不升级或补货。礁谷v7、海带林和深海规则保持。

海马仍抓住实际草叶，乌贼必须邻近实际礁体或稳定碎石，海鳃必须以柄部埋入软底，蜘蛛螺仍要求实际岩石全壳和足支持。水深、全身体、植物、相邻动物和支持面的检查没有放宽。海鳃按当地自然昼夜活动，白天收缩，夜间展开后才摄食。

固定新种子56的394.323米草甸主路对应12个区块，保存182条动物记录、21类当地代表，原配方同种子也是182条、20类。新配方实际有10只海马、10只礁乌贼、11个海鳃、12只羊鱼、12只寄居蟹、3只蓝斑魟、4只虎斑宝贝与1只海龟。10个鱼群由25只乌尾鮗和25只大眼鲹组成。蜘蛛螺与银带鲱未通过当地选择，不换种子或强行加入。目录和记录数均不等于同时可见数量。

三个普通九区窗口各推进0.6模型秒，合计121个目标动物实际移动、28个摄食；鱼群50个成员移动、11个摄食。完整保存、冷恢复及旧v1死亡和随机继续一致。新旧同种子地形、路线、所有原非草甸/非鱼群动物与海龟出生完整一致，旧v1整个出生记录的前后JSON一致。

活动后的39个10米间隔站中，10米和20米两站没有14米内的目标动物。独立完整出生位置对照的空站均为0、10、20米，新旧一致；两种采样时刻不同。这轮改善群落组成，不能称沿路覆盖改善或完整自然食物网。CPU近距和中心点视锥不代表GPU遮挡、整体观感或帧率验收；密度、食物代理和速率未作野外校准。
