## 下一轮的具体顺序

1. 先处理全景最显眼的第0、1、3块主礁。使用4–6个宽断面组成偏长、缺角的非椭圆XZ边缘，限制在原椭圆包络内；不要用密集小波纹替代大轮廓变化。可暂保留中心珊瑚锚点的原高度与低坡度，外肩采用单调径向映射，保持单一上下表面区间。
2. 同时提供共享足迹判定和反向坐标函数，让网格、`habitatHeight`、珊瑚初始化及相机使用同一世界XZ定义。上、下半部在最终变换后的XZ处查询沉积面；不能只改显示边缘而保留旧椭圆接触体。相机的旧椭圆可作保守粗筛，精确进入判断必须使用新足迹。
3. 去掉全周的层理分段，在每块岩石的一侧保留一条较宽断裂斜面或短台阶。三块示范石使用不同长短轴、切角和斜面方向，然后回到同一实际机位复核；无需先扩展到全部小石。
4. 材质单独处理极向拉伸，按世界位置与表面法线混合投影，保持米制纹理尺度和相机移动时的稳定性。这一步由Root负责，不修改骨架扫描的源UV或贴图。
