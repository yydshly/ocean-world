# 活跃生态校验与跨区巡游：本地阶段

继续使用[生命巡游](http://127.0.0.1:4175/ocean-world/?demo=life-expedition&seed=55&world=whole-seabed)。刷新页面后点击生命巡游；本次只更新本地，未提交、推送或部署。

原生测量发现，固定地形上的生境候选排序占完整历史校验约四分之三的CPU时间。本次将这项只读计算交给生态准备Worker，并在完整、已验证的不可变地形上下文中复用。每个上下文最多保留12份排序，完整上下文最多四组；匹配整个地形内容、owner、配方及完整珊瑚支撑描述。改变地形或支撑会重新计算，新增外部场景支撑后回到完整现场计算。

排序只决定原有生境候选先后，不代表动物记录有效。活跃动物在Worker返回后仍逐项检查当前位置、身体支撑、出生坐标、时钟、能量、事件和食物账；后台等待期间的动物变化不会被旧快照的结论覆盖。离线历史依然完整验证，未缓存历史有效性，未改出生、食物、数量、运动或已提交海床。
