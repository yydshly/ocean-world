# 礁缘中大型动物

本批加入大梭鱼、蓝鳍鲹、东方胡椒鲷和印度太平洋豹纹鹞鲼 Aetobatus ocellatus。浅海目录由75增至79个代表条目，每种有独立完整造型、鳍尾动画、体型尺度、生态活动和当地库存摄食。它们不是新增的静态摆件。

梭鱼为细长体、突出下颌和两枚分开的背鳍；蓝鳍鲹为侧扁纺锤体、蓝鳍与深叉尾；成体胡椒鲷有厚唇、横纹和截尾，白天休息、低光活动；鹞鲼有菱形盘、鸭嘴、腹面口及五对鳃裂，整条长鞭尾进入空间检查。鹞鲼的记录尺寸是盘宽，不能当全长。

生物依据为 [Museums Victoria](https://fishesofaustralia.net.au/home/species/2034)、[Australian Museum](https://australian.museum/learn/animals/fishes/great-barracuda-sphyraena-barracuda/)、FAO Maldives物种账户及CSIRO CAAB。各物种数据保留具体链接。程序体形、出生密度与速率没有野外校准；摄食扣既有营养代理，尚未实现可见追猎或鹞鲼挖沙取食。

## 新世界与历史

生产浅海开启 reefVisitors，依赖既有礁谷群落选项。地形仍是v8礁谷，新的动物配方是 reef-residents-v8。36类居民共用生境证据排序和自然余量，每区居民最多10、全部动物记录最多20（死亡与海龟也占位）。完整身体深度、宿主、底质、触点、净空与占位检查保持。

只在完整12区严格未保存时创建新配方，保存成功后才公开。所有区必须同版。历史配方1–7和草甸配方不迁移，死亡不补货；已有存档不会因为刷新页面而自动多出新动物。

## 实际检查

固定种子57的原地形不能生成安全礁谷路径，原生诊断保留；没有改地形或寻找更多种子。生产对照复用此前已验证的固定种子55。

种子55新礁谷有238条动物记录、52类目录代表，其中居民79只、26类。新类群实际选中两条大梭鱼，起点最近约6.52米；蓝鳍鲹、胡椒鲷和鹞鲼在这组缺席。三个普通九区窗口共9模型秒，两条梭鱼移动、一条摄食；居民合计73只移动、72只摄食。完整冷恢复与原非居民出生、地形、食物库存保持一致。每10米出生采样的空段仍是80/150/160/340/350/360米，新旧相同。

另一个固定57的开阔礁缘水层单元生境通过完整出生门槛选出四种，四种都有实际移动与库存摄食；该单元结果不冒充种子55的实际群落。所有模型的完整网格与24个动画时刻均在本身净空包络内，实际显示调度、区域时钟、卸载与资源释放通过检查。

46个唯一定向检查通过，生产构建通过。旧1–7配方32步完整记录冻结一致。保持9活区、25公开支撑来源、97私有预读上限及原导演67章/61动作/1994秒。仅有CPU/Three与存档证据，GPU观感、遮挡和帧率尚未验收。
