# 浅海羽星与金口海鞘生活层

本批增加两个缺失动物类群：浅海羽星 Comatulida 的形态代表、金口海鞘 Polycarpa aurata。浅海目录85→87个代表条目，v14居民候选42→44。羽星条目明确为类群代表，不能称为一个具名物种或两种新增具名物种。

羽星有独立中央体盘、40条带成对羽枝的腕和底部卷枝，成体没有海百合式长柄；采用五个合并扇区，避免为每根羽枝分配网格。24–36厘米为选取的展开扇径，完整身体5–25米为演示水深，均不是该目所有物种的天然范围。只展示硬底停栖展臂阶段：成体羽星能够移栖，但本版未实现爬移或游泳，不能把它称为永久固着生物。[Mekhova与Britayev 2015原始研究](https://lkcnhm.nus.edu.sg/app/uploads/2017/04/63rbz438-445.pdf)区分岩石、珊瑚等硬底及某些软底羽星；[西澳博物馆](https://museum.wa.gov.au/explore/marine-life-dampier-archipelago/explore-marine-life/echinoderms)说明卷枝停栖、腕/羽枝摄食和移动能力。

金口海鞘有独立皮革状外被、顶部入水管和侧部出水管，两个有凹陷开口的水管分别有界收缩。6.5–9.5厘米为选取的身体高度，完整身体5–20米依据[Kimbe Bay原始研究的采样水深](https://pmc.ncbi.nlm.nih.gov/articles/PMC4370848/)，不是完整天然分布范围。[2025原始研究](https://www.int-res.com/articles/esr2025/57/n057p431.pdf)讨论其入水滤食，并明确真实滤水量仍未知；[澳大利亚博物馆历史目录](https://museum-publications.australian.museum/media/dd/documents/Recno49565_Herdman_1899_lowres.91157d9.pdf)记载外被、附着与两水管（包括历史变型）。本模型不声称精确复刻全部解剖或色型。

两类都必须通过真实稳定硬面、六个实际基底支撑采样、坡度、整个腕/羽枝/水管包络、水深、地形净空及动物占位检查。采样点是几何支撑证据，不是六只步足。动画使用所属动物的生态时钟，在完整包络内变化，共享不可变几何，各实例保持独立姿态并完整释放资源。死亡动画冻结，死亡记录不补货。

摄食实际扣当地 resources.plankton 营养库存并保持账平；不新建食物，不模拟测量滤水量、粒径选择、喷水流体、食物沿腕运输、共生虾或繁殖。数量、速率和环境耐受范围未野外校准。
