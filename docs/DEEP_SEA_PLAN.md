# 深海软底首版：来源、形态准入与接口方案

核查日期：2026-10-03（Asia/Shanghai）。状态：研究与实施方案；本文件没有接入任何场景或修改生态参数。

2026-10-04实施补充：持续探索的海蜘蛛属代表已经完成稀疏分配、真实触手／吻端接触、独立体况转移及旧档兼容保存。菜单共4项，原近距离三类／16代表体默认状态保持。有限实际正常速度、卸载回访、刷新、120项相关测试与构建通过，见[DEEP_PREDATOR_INTERACTION.md](DEEP_PREDATOR_INTERACTION.md)。下方“三项首版准入”与第二阶段安排保留为原方案的历史范围，不表示海蜘蛛仍全部暂缓；冠状海参与肠鳃类尚未接入。

## 1. 场景定位与准入结论

采用 **“东北太平洋深海软底示意”**。显示水深选择 **3500 m**，属于作者选定参数；不使用精确经纬度，不称为某次 Monterey 或 Station M 调查的重建。Station M 的若干资料来自约 4000 m，而 Monterey 海蜘蛛—海葵报道包含约 2894 m 的观测，不能混成一份 3500 m 样方。后者连同温盐氧值是特定照片的记录，不能直接填入本场环境。[MBARI：Station M 肠鳃类实例](https://www.mbari.org/news/a-bountiful-harvest-of-deep-sea-acorn-worms/)、[MBARI：海蜘蛛与绒球海葵](https://www.mbari.org/news/sea-spiders-and-pom-pom-anemones/)

首版只准入三项：**Scotoplanes 属海猪代理、Macrouridae 科鼠尾鳕代理、Liponema brevicorne 绒球海葵**。三项来源的汇总深度范围都包含 3500 m；这证明候选深度相容，**没有证明三者在同一个野外样方共现或具备指定密度**。不接入热液喷口、冷泉、鲸落、深海珊瑚林、巨藻或热带礁鱼；这些需要各自独立的环境与名录。

### Peniagone 的证据边界

本轮真实读取了 MBARI 的 Station M 摄食与群落变化报道，明确该属在那里与新鲜碎屑相关。该报道的研究时间跨度为多年；种群变化可能涉及繁殖与迁入，报道没有支持“增加海雪后几分钟内立即繁殖出成群海参”。[MBARI：深海摄食与种群变化](https://www.mbari.org/news/deep-sea-feasts-tied-to-sea-cucumber-population-booms/)

实际读取的 Gebruk 2008 原始分类论文是 **北大西洋**材料。其不同 Peniagone 种的背部帷膜（velum）和自由乳突不同，管足排列也不同；论文能支持“不能用一种固定轮廓概括全属”，不能证明这些种是 Monterey 候选。固定液保存后的颜色也不能直接视为活体颜色。[原始论文，DOI 10.1080/17451000701842898](https://inpn.mnhn.fr/docs-web/docs/download/123801)

Barnes 等 1976 的原始研究摘要记载，`Peniagone diaphana` 在南加州约 2000 m 有原位游泳和摄食观测。它支持该具名种的行为实例，不支持“所有 Peniagone 都在 3500 m 同样游泳”。[原始研究摘要，DOI 10.1126/science.194.4269.1083](https://pubmed.ncbi.nlm.nih.gov/17840307/)

因此暂保留 `morphologyReadiness: requires-reference-images`。后续准入需至少拿到一组有地点、深度和分类标签的本地正侧面影像，确定腹面、口端、帷膜、自由乳突、管足和后端之间的关系；先建立一种明确的参考形态，再决定它仅能标属代理还是可标命名物种。不要把海猪的支柱足直接搬给冠状海参，也不要给它添加海葵式口冠或鱼类鳍。

### 当前无法可靠重建的内容

- Peniagone 的本地具体形态、实时游泳比例、速度与触发条件。
- Enteropneusta 的所选本地个体颜色、细节比例及命名种身份；已有实例不自动改变现有纲代理身份。
- Macrouridae 代理的精确种身份、具体猎物关系、鳍条数与生长速率。
- 六项候选的共同野外密度、真实能量预算和当前 3500 m 场地的温盐氧、底流、颗粒输入量。
- 本名录的个体发光能力。当前资料没有给出这六项全部会发光的证据，不把深海身份当作发光许可证。

## 3. 环境与现象

3500 m 位于无太阳光的范围。自然光、阳光焦散、海面投射光束与现场光合作用设为零；温度、盐度、溶氧和底流若没有场地测量，仍记为 `null / uncalibrated`。[NOAA：海洋光照分层](https://oceanservice.noaa.gov/facts/light_travel.html)

地形采用低起伏的灰褐软泥与小尺度沉积纹理，留大面积空地；不把浅礁巨石和白沙复制过来。食物来自上层沉降的有机物；海雪在下沉过程中会被摄取、转化，只有一部分到达深海。把“水中可见粒子”与“到达床面的有机物质量”拆开记录，亮粒子的数目不能等同摄食量。[MBARI：海雪生态](https://www.mbari.org/project/ecology-of-marine-snow/)

建议先实现三种可解释的观察：局部碎屑斑块与海猪摄食；海葵触手对流经食物的捕获；鼠尾鳕停留、近底巡视与有限食物池的探索。它们是来源支持功能的简化机制，不是已校准物种速率。

沉积摄食轨迹随个体经过逐步留下，不用开场铺满完美螺旋；轨迹作为后续肠鳃类准入时的专门功能。泥云仅响应明确底床扰动事件，悬浮、沉降和扩散参数标为显示参数，不能与供食实验混为一套效果开关。

## 4. 三类首版模型与可信尺度

| 类别 | 几何与尺度 | 动作联系 | 简化边界 |
|---|---|---|---|
| 海猪属代理 | 0.08–0.16 m 体长；柔软半透明体、口部摄食触手、长支柱足与接泥点；细节按确定参考形态制作 | 支撑足交替调整，身体随支撑而移动；摄食触手接触有限碎屑斑块，停顿和觅食与事件一致 | 不宣称固定管足数属于全属；不做通体霓虹透明或高速游泳。 |
| 鼠尾鳕科代理 | 0.35–0.75 m 全体长；较大头眼、渐细延长的尾部与相连鳍膜；尾部纳入尺寸，不能只是普通礁鱼加一根线 | 连续身体尾部波动；近底低速巡游、停留、短距转向；感知食物与遮挡，不依赖灯锥 | 颏须只属代表形态；不虚构具名种或假设必然捕食同场海猪/海葵。 |
| 绒球海葵 | 0.12–0.28 m 展开直径；柔软主体及密集触手组成的团簇，保留接底区 | 默认附底，触手随流且可收缩；捕食事件改变局部触手状态；滚动保留为后续稀少事件 | 不作为气球持续升空、不整体随机旋转；滚动寻找更佳供食点的功能解释仍保留推测性质。 |

以上显示尺度均低于各自已读来源上限；它们是本原型的取样选择。来源没有提供对应个体的实测步速或尾摆频率，开发时必须给渲染动画参数单独标记，不能写成科学测量。

共享几何以正确的尺寸度量归一：海猪/鱼为全体长，海葵为展开直径。根节点再按显示米尺寸缩放；不靠随相机距离改变尺寸获得“可见性”。近景观察由相机完成。

## 5. 机制与渲染接口建议

### 地形和支持面

```js
deepFloorHeight(x, z) // m，模型与网格使用同一高度函数
sampleDeepSupportPose(x, z, heading)
// => { position: {x,y,z}, normal: {x,y,z}, tangent: {x,y,z} }
```

海猪足端、附底海葵和行为模型共用支持面。观察相机自由移动；海床生物不跟随相机浮起。地形和网格不得各自生成不同的随机噪声。

### 资源与事件

```js
deepFood.sampleSurface(x, z) // 可用沉积碎屑功能池
deepFood.consumeSurface(x, z, requestedMass) // 返回实际摄入量
deepFood.sampleSuspended(position) // 悬浮动物性食物功能池
deepFood.consumeSuspended(position, requestedMass)
deepFood.sampleBackgroundPrey(position) // 鼠尾鳕的有限小动物/腐肉代理池
deepFood.consumeBackgroundPrey(position, requestedMass)
```

三类功能池用明确单位、有限供给和账本分开维护。若首版还没有可视小型猎物，只能显示为“功能池代理”，不能宣称已经模拟完整食物网，也不能硬连 `鼠尾鳕 → 海猪` 作为事实。区分输入、沉积、再悬浮、消耗和损失，事件保存 `foodPool / requestedMass / actualIntake / agentId / timeSec`，`lastFeedAt` 初始为 `null`，实际摄入发生后才更新。

```js
DeepSimulation.step(dt)
DeepSimulation.setEnvironment({ currentMps, organicInput, suspendedFoodInput })
DeepSimulation.getAgent(id)
DeepSimulation.getMetrics()
```

`timeSec` 来自模拟时钟；暂停和时间速度同生态、动画一致。温盐氧等未校准值不因接口需要而填成假测量。供食与水流实验先检验局部资源/摄入/捕获响应，不预设长期种群必然增减。

### 形态和生命周期

```js
createDeepOrganism(species) // THREE.Group，保留 identityLevel 与来源
animateDeepOrganism(group, timeSec, agent, environment)
disposeDeepOrganism(group)
```

`agent` 提供行为状态、支持面、摄食事件或活动强度；模型仅表达这些状态。共享几何、材质与纹理使用引用计数，动态触手或软体顶点使用实例自有缓冲；销毁一份不能影响同种其他模型。足端/触手需要共享接触位置时，从行为状态传入，避免各自另起一套摆动公式。

### 观察照明

设置显式 `observerLight`，与自然光独立：观察器照明开启时，有限距离的白色灯锥照出泥面、生物和少量后向散射；灯外趋于黑暗。关闭后自然场景保持黑暗，界面与图鉴仍可操作。近景放大不增加自然光，曝光辅助模式应明确显示“观察器辅助”。灯锥尺寸、散射和曝光属于画面参数，不填成实测水体值。

首版不把灯照亮视为提供食物，不因调灯提高海葵光合作用；名录没有被核实的个体发光时，不添加生物自发光。镜头可带有明确标注为工具的尺度尺，不能冒用原影像中约 29 cm 间隔的激光点作为本场的测量依据。

## 6. 下一步最小可实现范围与验收

1. 一块作者设计的软泥小场域，先只接入上面三类；不承诺填满六类。
2. 首先完成 ROV 风格总体镜头、海猪接泥近景、鼠尾鳕侧面轮廓、海葵触手近景四项视觉目标，确认比例和可辨认结构后再扩场。
3. 光关闭测试：自然光贡献为零；无焦散、巨藻和未经核查的个体发光。光开启测试：只有观察器照明作用域内能清楚观察。
4. 共用支持面测试：海猪的支撑端与海葵接底区贴合地形；摄食、停留、巡游有状态与事件证据。
5. 三个固定种子分别改变碎屑输入、悬浮食物输入、水流；报告实际摄入和资源变化，同时保留无变化或反方向结果。
6. 持续运行 20 分钟及生境切换验证：无数值异常、缓存增长或共享资源误释放。截图与性能数据需来自实际浏览器。
7. 后续优先补本地 Peniagone 参考形态与分类标签，再决定准入；海蜘蛛与肠鳃类分别补其微生境、接触动作和影像依据，不能仅为凑数量加入。
