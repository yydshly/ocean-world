# 原生支撑查询性能

2026-10-07 的有限优化只改变候选物筛选。每个查询 owner 的九区原生石头、珊瑚、地貌和沉底杂物被索引到 4 米空间格，随后仍调用原生 Float32 三角面或原椭圆支撑函数。动物完整身体、魟鱼尾部、转身和路径中点检查、0.1 秒生态步长均保留。

每个缓存 owner 最多 256 格，支撑缓存仍最多 25 个 owner，沿用原提交、私有生成视图切换、重置及卸载的清理边界。只有元素及其 scale 都冻结的原生描述符被空间筛选；自定义可变或非法描述符保留为全格候选，以维持原位置更新和错误可见性。
