# 连续草床的绿海龟代表 · 2026-10-05

本轮补充浅海草床的较大游泳动物，使现有海草、沙地、岩体、底栖动物与水层鱼群具有更多生活型组合。绿海龟沿真实生成的草床巡游，上浮、短暂停留呼吸，然后返回原水层；不继续单株、甲壳、材质或镜头细调。整体画面仍是程序化雏形。

## 生境与模型边界

[NOAA Fisheries](https://www.fisheries.noaa.gov/species/green-turtle)支持绿海龟使用近岸海草等生境、成体草食倾向及必须上浮呼吸；[大堡礁海洋公园](https://www.gbrmpa.gov.au/learn/animals/marine-turtles)提供草床与礁区背景。模型总长1.25～1.5米、0.22米/秒、0.7弧度/秒转向、120～180秒呼吸间隔和8秒停留均为未校准的展示参数。

分布由独立种子与坐标决定，每格至多一个代表，必须找到真实草株群及安全的16点局部路径。位置检查使用实际海床、岩/珊瑚/地貌支撑与有限海草冠层；整体鳍肢和身体使用保守水平0.64倍体长、垂直半高0.25倍体长包络。上浮列柱保持无俯仰，刚性鼻端参考点达到名义水面Y=8米。未模拟逐叶碰撞、波面接触、流体受力、氧气生理、摄食、代谢、繁殖或远洋迁徙；景观海草没有可扣减的食物库存。

## 保存与兼容

新增`turtleCommunityVersion`、`turtleInitializedAtSec`、`turtleAgents`三个独立区域字段；默认关闭，实际浅海世界显式启用。完整记录提交成功后公开，不覆盖旧动物，不补填已经初始化的空数组或死亡个体，卸载时保存并冻结。旧个体和海龟含死亡记录合计每格最多20个，原蝠鲼及完整鱼群的跨区抵达也检查此容量。现有食物、账本、RNG和原生行为保留，平均能量仅计入具有能量字段的活体。

损坏的新身份、草源、几何、阶段关系和速度拒绝恢复，避免静默重新生成旧群落。呼吸阶段四种合法记录可完整恢复；上浮时目标错误、活体声明死亡、异常超长停留、超速以及巡游时鼻端已经到水面的损坏记录被拒绝。保留首次测试返回值误判与第二次发现超速存档问题的日志，不将失败证据覆盖。
