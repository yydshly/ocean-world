# 巨藻林林下与附着群落

本包补整片巨藻林的低层轮廓：木质直柄和宽叶的加州翼柄藻、粉色宽翼分节珊瑚藻簇、岩面的橙球海绵和细柄海鞘。四条来源具名记录中含两植物、两动物。翼柄藻已有独立旧林下景观，本次为其来源具名化并新增自然空余岩根；不称四种首次新增物种。巨藻场景目录现有24条代表记录，含21动物和3植物，不是当地24种普查。

普通入口为`?demo=kelp-understory-life`，按钮“林下附着群落”，原生owner`58,-4`、`x=3744,z=-224`；导演包括“巨藻林：林下附着群落”16秒段。此owner自然有10株新景观（4翼柄藻与6宽翼分节珊瑚藻）、4只独立滤食动物，原16加新4共20条动物记录。景观株数不计入动物预算；相邻owner自然缺类或完整为空，不强制填满。

两种植物是独立持久化景观描述符，最多12株／owner，在真实原生岩面成簇分布，根固定、远端叶／柔关节局部摆动。它们避开所有既有植株与占位，不替换旧景观，也不实现植物生物量、光合或增长。海绵和海鞘是最多4条独立动物记录，只使用全部既有记录后的自然预算余量，总动物记录上限仍为20；未强制每一区块同时拥有所有类别。

海绵球体外径、两藻类完整高度和海鞘带柄总高度分别计量。完整叶、节枝、球体、细柄和两个虹吸均参与实际岩支持与净空。海绵从真实表面入水小孔滤食，另有出水孔；海鞘从下弯入水虹吸滤食，另有上向出水虹吸。固定入水参考不随局部动画移动，不用形体中心或出水口替代。

动物采用一个独立零初库存的悬浮有机营养控制体，有限外部输入、真实局部运输、器官接触摄入与输出均记账。只选择微藻／微型浮游／微小有机颗粒的未解析营养分量，不转义旧食物、不移低旧host食点、不添加可见猎物杀伤。完整新景观、动物、自然空类别、死亡、时钟与食物账随owner保存；历史开关不会自动补生，首次原子提交成功前不公开。
