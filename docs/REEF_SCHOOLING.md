# 礁缘真实小鱼群（本地v18）

2026-10-09 本批把已有双线乌尾鮗与蓝带笛鲷接成有限小群，补充动物之间的共同活动。目录仍94个物种/属/类群代表，礁谷候选仍51类。每群3–5条真实存档个体，每个owner最多一群；所有鱼共用原10居民/20全部记录额度，死亡及龟也占额度。腾给同种鱼群的名额可能减少当地不同类型，未增加整体人口上限。

双线乌尾鮗在沿岸、潟湖和外礁聚群的依据是[Museums Victoria图鉴](https://fishesofaustralia.net.au/home/species/543)；蓝带笛鲷日间在珊瑚礁体和洞穴附近聚群的依据是[同机构图鉴](https://fishesofaustralia.net.au/home/species/559)。当前只展示礁缘开阔水层的小群协调，不实现真实洞穴、天然大群规模、混种大群或夜间集散。3–5条、间距与周期均为有限演示参数，未按野外密度或运动速率校准。

原有候选点是为独居动物分散布置的，水层点之间常隔数米。新配方在每类聚群鱼最多8个已有礁缘候选周围加入32个以内的小群候选位置；候选是确定的实际坐标，不能授权出生。原有生境排序保留，每条鱼仍独立通过整身地形/水深/宿主邻近/区域边界/植物及其他动物占位检查。没有足够名额或3个合格近邻位置时不生成鱼群；若只能放单条则维持单条代表。旧v1–17不增加候选、不升级、不补货。

鱼群每步读取共同的步前位置快照，按共同巡游方向、群体位置及近邻间距生成目标。每条鱼继续独立转身、以自身速度移动、检查完整轨迹和摄食。没有独立于生态的装饰复制鱼。双线乌尾鮗扣owner浮游营养；蓝带笛鲷扣owner未解析动物营养。死亡成员留在存档名单，卸载区域停钟，冷恢复保留实际成员、死亡、库存与未来决定；不会自动补齐队形。

[本地小鱼群入口](http://127.0.0.1:4175/ocean-world/?demo=reef-valley-region&seed=55&world=reef-schooling)使用独立动物历史，地形与出生随机命名空间沿用同55；全局环境、探索、发现仍共享。普通/导演尚未访问的新海区使用v18，有记录的海区维持历史配方。原reef-mobile-benthos链接仍v15，需要新入口看本批。

本轮查出并修复两处既有集成问题。上一轮全局替换误把原黄尾乌尾鮗的四处群游/跨区识别写成了新双线种，现已恢复原身份并验证原群游流程。此前URL读取与生态存档已接新预览，但ReefWorld构造器白名单遗漏reef-grazers/reef-color-fish，使它们仍被清成普通世界；现在构造器保留这些参数，连同reef-schooling向实际生态选项传递，旧动物数据没有迁移。
