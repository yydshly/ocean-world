# 蒙特雷林下与岩附着群落：来源和制作合同

本包选取当前蒙特雷／加州中部巨藻林的四条具名代表记录。两条藻类是持久化景观，另外两条是独立滤食动物；不把这个组合当作同一现场的物种普查。加州翼柄藻已在旧林下景观以`pterygophora-californica-scenery`存在，本次是来源具名化和独立新岩根，不称首次新增物种，也不映射、重置或替换旧景观。

| ID / 科学身份 | 本版量尺和选择 | 完整形体选定水深 | 形态及底质 |
| --- | --- | --- | --- |
| `pterygophora-californica` / *Pterygophora californica* | 1–1.5m直立完整藻体高，不是柄长 | 7–20m | 真实硬岩根、木质不分枝柄、末端叶和上部相对侧叶 |
| `calliarthron-cheilosporioides` / *Calliarthron cheilosporioides* | 8–14cm直立分枝藻体高，制作选择 | 7–25m | 岩生低分枝、薄扁宽翼顶节和窄柔关节 |
| `orange-puffball-sponge` / *Tethya californiana* | 6–8cm完整球体外径 | 3–20m | 橙金细凸表面、固定岩附着、分开的入水孔与出水孔 |
| `monterey-stalked-tunicate` / *Styela montereyensis* | 12–22cm带柄完整直立高度 | 3–20m | 岩附着细柄、纵棱柱状体、独立的下弯入水和上向出水虹吸 |

所选尺寸、水深门槛和展示数量不是野外分布频率或年龄估计。水深检查包含全部附属体和有界局部动作，不能用海床深度代替最高叶尖／完整动物的水深。尺寸之间不换算；`Calliarthron`的自然尺寸数值范围仍为`null`。

## 加州翼柄藻

[UBC E-Flora具名账户](https://linnet.geog.ubc.ca/Atlas/Atlas.aspx?noTransfer=0&sciname=Pterygophora+californica)分别给完整藻体高度至2.3m和木质柄长至1.5m，形态为单末端叶、上部相对叶列与短固着器。本版1–1.5m是完整高度选择，不能把1.5m柄长误说成来源的完整体高。

[NOAA蒙特雷保护区2015报告](https://sanctuaries.noaa.gov/science/condition/monterey-bay-2015/mbnms-cr-2015-lowres.pdf)记录蒙特雷与Point Lobos长期巨藻监测中的具名林下藻。[Stillwater Cove原研究](https://www.calstate.edu/impact-of-the-csu/research/coast/students/Documents/Cooper%20V3.pdf)在Pebble Beach约8.5m标记研究植株；[原蒙特雷林冠移除实验](https://www.sciencedirect.com/science/article/pii/002209819290039D)另支持林下生境。未把实验增长、密度或冠层干预参数搬入模拟。

[USGS具名原生横断记录](https://www.usgs.gov/media/videos/3ms18-l1-west-transect-2008)给10.9m，但地点为Washington，不冒称蒙特雷样方，也未下载或观察其视频。7–20m是浅水林下展示选择，不宣称这些文献实测了完整分布端点。最初候选*Dictyoneurum californicum*的可靠浅水记录不足以支持当前常见林下水深，故不采用。

## 宽翼分节珊瑚藻

[Gabrielson等2011原分类／形态论文](https://www3.botany.ubc.ca/martone/Gabrielson%20et%20al%202011%20Calliarthron%20morphometrics.pdf)的Table1明确两份*C. cheilosporioides*具名标本UBC A87297／A87298于2008年6月1日在Monterey County、Pacific Grove、Hopkins Marine Station岩上27.62m采集。另两份19m与25m标本来自Catalina，不把这些地点混称蒙特雷样方。7–25m是本版完整形体展示选择，不是已测连续分布或自然密度范围。

同文Fig3为*C. cheilosporioides*本种lectotype的完整藻体及1cm标尺；8–14cm是有限制作高度，不是根据图测得的自然上下限，`referenceSizeM`保持`null`。本种顶端节段较薄、较宽翼，区别于*C. tuberculosum*厚顶节窄翼；不能只改学名复用另一种诊断形态。最初*C. tuberculosum*可靠3／10／13m资料不足以支持本轮深岩窗，故替换为有直接Monterey深岩标本的本种，而没有扩大原候选深度。钙化节段与柔关节用于形体区别，本版不模拟钙化速率、光合或碳库存。

## 加州橙球海绵

[Stanford Hopkins SeaNet](https://seanet.stanford.edu/Demospongiae)给具名橙球海绵6–8cm外径、近球形橙黄凸面和巨藻林岩生形态。[Sipkema与Blanch原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC3873019/)为2009年在线、2010卷期发表，方法记载2006年5月24日在Monastery Beach约8m采集两只*T. californiana*；采集时间与出版时间分开。该文研究组织相关微生物，不把组织中的菌／叶绿体比例当作野外食谱或摄食比例。

[保护区SIMoN具名账户](https://sanctuarysimon.org/dbtools/species-database/species-info-ajax.php?sID=42)另给广域岩生与深度信息；其广域0–440m不当作这片巨藻林的自然密度或耐受校准。[Guillas2025原论文库摘要](https://scholarworks.sjsu.edu/etd_theses/5648/)研究本种入水孔、出水孔及体部收缩，并报告微藻富集相关响应。全文封存至2028年8月6日，未读全文，也不从摘要推算自然滤水量。

本版选未解析悬浮微藻／微小有机颗粒营养分量。摄入参考是实际表面**入水小孔**，不是顶部**出水孔**，更不是嘴。没有模拟整个DOM谱、所有细菌营养、孔内流场或真实全体收缩；命名作者年份在现有来源存在差异，`scientificAuthor`保留`null`。

## 蒙特雷柄海鞘

[Stanford Hopkins SeaNet](https://seanet.stanford.edu/Urochordata)提供具名蒙特雷岩生形态与长至25cm的参考。[Oregon Coast Aquarium账户](https://aquarium.org/animals/stalked-tunicate/)区分下弯入水虹吸与上向出水虹吸，并记录岩礁附着、浮游营养和低潮至100feet的广域生境。其约12英寸是完整长度参考；本版12–22cm带柄高度为制作选择，未作标本比例校准。

[California WaterBoards原调查附录](https://www.waterboards.ca.gov/water_issues/programs/ocean/docs/asbs/mba_app_2011jan.pdf)列1979年4月1日蒙特雷ASBS19岩质潮下带的具名记录。**19是ASBS编号，不是19m水深**。[Ritter与Forsyth1917原描述](https://www.vliz.be/imisdocs/publications/ocrd/408087.pdf)支持细长柄、纵棱体、两个四瓣孔及回弯入水端；南加州形态参考与蒙特雷身份记录分开。[Young与Braithwaite1980原流向研究](https://doi.org/10.2307/1541105)仅作流向来源追溯，未移植定量流速或泵率。

本版只选未解析微型浮游／有机颗粒营养。固定接触点位于真实入水虹吸端，另保留完整出水虹吸，不能从出水口记摄入，也不把滤食动物的孔口叫鱼嘴。

## 完整形体与固定孔位

`src/kelpUnderstoryLifeSpecies.js`导出递归冻结的`kelpUnderstoryLifeSpeciesCatalog`／`kelpUnderstoryLifeSpeciesById`，来源项统一为`{url,label}`。两藻类使用程序植物分类`kind:kelp`，这不把珊瑚红藻的自然分类改成褐藻。动物分别为`sponge`／`tunicate`。

根为真实岩附着基部的局部零点，+Y为实际支撑面法线，+X为表面切线。表中单位是各自量尺，不共享“全长”：

| 加州翼柄藻，完整高度=1 | ±.72 / [0,1.08] / ±.58 | .12 | 无 |

这些比例和有界动作包络是保守制作合同，不是扫描标本。海绵球心(0,.5,0)、半径.5；所选孔点恰在球面。固定根与摄入孔不随渲染局部动作漂移。翼柄藻保持不分枝木柄、单末端叶和上部相对叶，不复用旧六冠扇形原型。珊瑚藻只在远端柔关节作小幅摆动，钙化节段不被揉成细羽毛。

## 独立营养账与未校准能力

两植物是新持久化景观描述符，最多12株／owner；不是藻类生物量、光合、钙化或成长模拟。两动物只利用全部既有动物记录后的自然余量，最多4条新记录、总动物记录不超过20；不预留、删除旧个体或补货，不强制每一区都有全部类别。

动物仅接触独立、零初库存的`suspendedOrganicFood`，实际库存为`region.kelpUnderstoryLife.foodParcels[].amount`；公开只通过`understoryLife.resources.suspendedOrganicFood`表示其总和，不向旧`sim.resources`增键。有限局部上游控制体通过环境`foodSupply`获得有账外部输入，真实运输到固定摄入孔附近，接触才摄入，库存、输入、摄入与输出闭合。原生藻、碎屑、host水层`smallPrey`及上一包床食保持原位置与含义；不把旧食物挪到孔边强喂。食物单位和相对能量不是克碳或自然生物量。

自然密度、年龄、温盐／溶氧／流速耐受、自然泵率、生态速率未知项保留`null`。未实现完整微生物网、过滤粒径谱、种群增长、钙化／光合、真实水动力、器官内部流场或全局全动物碰撞证明。
