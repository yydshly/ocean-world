# 深浅生活层的群落分配

本批调整整片礁谷的出生分配，未增加物种、模型或动物预算。原三处空站所在区域已接近容量上限：208,4区有20条动物记录、5只居民；209,4区有19条记录、10只居民。旧配方先用浅侧生境消耗名额，能够生活在更深沙床的类型往往排在后面。沿途沙床约17.85–21.13米，不能直接追加动物或放宽全部物种的水深限制。

新 reef-residents-v12 仍使用原40类居民和83条浅海目录。它从实际候选位置、床面与所选身体垂直范围计算浅层、过渡层和坡缘层的可能性，让具有当地较深生境的类型优先参与分配。12米和18米仅为本模拟的排序分界，不代表普遍自然分带。相同层内保留原生境角色顺序，没有物种名单特例、保留名额或强制出现。

候选中心只用于排序，出生仍检查完整身体、水深、真实沙床或礁体、六处底栖支撑点、坡度、植物与动物占位。每区最多10居民、20全部记录，死亡与海龟仍占位。v12保留v11的所选体长与出生朝向随机盐；地形、原非居民出生与资源不改变。只有十二区全部未保存才能原子出生，旧1–11存档、死亡、时钟和随机未来不迁移、不补货。

## 当前效果和限制

[本地深浅生活层入口](http://127.0.0.1:4175/ocean-world/?demo=reef-valley-region&seed=55&world=depth-community)使用原种子55地形与独立动物存档。普通世界和旧三个演示历史保留，刷新恢复本入口自己的状态；全局环境、探索记忆与发现仍共享同一种子。

固定55原427.639米路线、238条动物记录和79只居民保持。每10米采样、统计14米出生近邻，空站从340/350/360米三处减为350米一处：340米附近最近为千斑沙鲈，约8.40米；360米附近最近为环带狗母鱼，约9.99米。350米仍空，不声称已解决所有沿途空段或证明屏幕可见。

本批重新分配有限余量，当地全部类型从57降为54、居民类型31降为28；目录仍83。覆盖更深生活层与每处种类数量之间存在取舍，没有以增加预算掩盖这一结果。四种坡缘鱼本组共19条：兵鲷4、大眼鲷3、狗母鱼5、沙鲈7。其他地区及旧群落保持自身历史。

三个普通九区窗口合计9模型秒（日间、日间、夜间），52只居民移动、54只摄食。兵鲷3移动/3摄食，大眼鲷2/2，狗母鱼1/3，沙鲈3/3。摄食扣当地现有营养代理，未实现物种级猎物捕杀或完整自然食物网。

29个唯一定向检查通过，一次生产构建5.19秒。真实地形、非居民出生、初始资源、完整cold active/disk和原世界存档逐条一致；新预览与普通新配方的同种子出生一致。旧1–11全部32步输出2,834,188字节逐字节相同。保持9活区、25公开支撑、97私有预读上限，导演67章/61动作/1994秒保持。冻结证据见 output/validation/reef-depth-delivery.json。

本轮按整体生活层交付，不继续单体、材质或镜头细调。GPU观感、遮挡、帧率和野外密度/运动/摄食速率未验收。下一阶段优先跨生境的生态丰富度与生活层连贯性，不把填满每个采样点作为真实海底的要求。线上状态以对应提交的Actions实际结果为准。
