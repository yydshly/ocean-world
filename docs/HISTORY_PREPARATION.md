# 历史海区准备：重复传输减少，整体体验仍未通过

本地候选 `history-preparation-candidate-20261012`，分支 `fix/history-preparation-20261012`，基于 `a38b541`。本轮按用户“继续”授权，只处理历史海区准备的重复工作。场景、资产、物种、路线、原存档和生态规则保持冻结；不推送部署。

## 实现与边界

- 完整12块地形仍先经过原生校验。后台返回只属于本次 Worker 生命周期的地形凭据，随后栖息地与历史校验复用该不可变地形，减少重复传输、克隆和序列化。
- 缓存命中时跳过候选栖息点生成，缓存未命中仍使用原来的全部候选点和排序计算。
- 缓存上限仍为4个完整上下文。退出缓存、改变种子/地形配置、重启 Worker 都会使旧凭据失效；不会转为重新生成历史人口。
- 动物、时间、出生证据、资源与食物记录每次完整复核，主模型保留原请求检查、存档保存与发布流程。外部场景支撑仍使用原来的完整校验。
- 第一轮额外查询缓存没有稳定收益，已经撤掉；没有增加缓存容量，也没有采用历史校验结果缓存。
