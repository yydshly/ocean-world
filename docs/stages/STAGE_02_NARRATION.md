## 观看方式

- 开启讲解会从头观看；关闭讲解后继续当前巡游。
- 暂停、拖动进度、跳章和0.5–2倍速与语音同步。倍速保留音高，字幕使用生成服务返回的段落时间戳。
- 接管探索时暂停讲解；返回镜头的3秒衔接期间继续暂停，回到路线后接续。
- 页面后台暂停音频。音量滑杆和字幕开关独立控制；浏览器拒绝播放时有“重试讲解”。
- 语音加载失败不阻塞场景；不会逐帧重试。网页不调用生成服务。

## 生成与凭据

本次按用户指定的本机外部`.env.minimax`配置生成，使用MiniMax `speech-2.8-hd`、系统音色`Chinese (Mandarin)_Gentleman`、语速1.05。MP3为32kHz/128kbps/单声道，六段合计1,733,112字节。无需新增网页依赖。

生成脚本：`scripts/generate-shallow-narration.mjs`。文案：`scripts/narration/shallow-journey.zh-CN.json`。成品：`public/audio/shallow-journey/`，页面清单：`src/data/shallowJourneyNarration.json`。只发布成品和不含凭据的元数据；密钥、环境文件与授权头均不进入前端。

可在项目目录运行：

```powershell
node scripts/generate-shallow-narration.mjs F:/codex_project/.env.minimax
```

脚本校验既有音频哈希，命中文案/模型设置缓存时不重复生成；修改文案会发生新的服务调用。失败请求不自动重试。字幕下载失败保留已生成音频与全文回退字幕，避免因此重复调用语音生成。

API依据：[同步语音合成文档](https://platform.minimax.cn/docs/api-reference/speech-t2a-http)、[官方音色列表](https://platform.minimax.cn/docs/faq/system-voice-id)。使用系统音色，无声音克隆；页面标注“AI合成旁白”。生成语音不代表新增第三方3D素材，也不改变已有模型许可。
