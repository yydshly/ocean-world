1. 完整1×240秒巡游；检查三种生境、六段群落的可见性与转场连续性。
2. 记录实际初始化、帧间隔、分辨率及控制台；检查明显穿模与多秒卡死，不用构建成功代替实景验收。
3. 检查暂停/继续、章节访问、探索移动、回到镜头、从头播放，以及窄窗口布局。
4. 一次集中修复后复验受影响体验并归档；未解决问题列入限制，不自动开启第二轮。只在本地展示，不部署。
