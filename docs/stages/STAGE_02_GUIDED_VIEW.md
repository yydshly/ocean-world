# 阶段02增补：边看边听与专注观看

本次是中文讲解的一轮有限交互收尾。沿用原240秒浅海路线、动物、礁体和六段MiniMax音频，只调整观看与讲解操作。本地入口：<http://127.0.0.1:4175/ocean-world/?demo=shallow-journey&seed=55>。

## 怎么体验

1. 打开后默认“专注观看”，保留画面、当前生境与时间、暂停、讲解按钮。点“开启讲解”会从当前位置接上，不会返回起点；暂停时开启也不会擅自恢复巡游。
2. 点“展开控制”或按Escape，显示全部章节、进度、速度、音量和字幕。想完整听开场，点“从头讲解”；想再听当前章节，点“重听本段”。
3. “接管探索”会展开移动控件并暂停讲解。返回巡游后，镜头归位再接续。移动端探索时收起暂停字幕，保证方向按钮可见。
4. 无旁白的段落显示“留白观察”和下一段名称；最后一段结束后明确提示安静观察，240秒结束后提示可以重听。

## 这轮的可见变化

390×844响应式视口、开场同一字幕下，底部控制区由约351像素缩为178像素，减少约49%。这不是场景或模型升级；它让已有的海床和动物少被控件遮挡。探索模式另验方向区和面板之间约14像素间隔，没有重叠。

保留默认静音选择。用户在留白或暂停时开启讲解，会对同一个媒体元素作静音预备播放，以提高后续自动接续成功率；失败仍有明确的重试按钮，不无限重试。此机制不是所有浏览器的自动播放保证。
