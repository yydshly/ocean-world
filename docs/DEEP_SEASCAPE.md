# 深海平原—缓坡—稀疏岩露头

2026-10-06。本包补完整的宏观深海组合，复用原东北太平洋软底动物、食物模型和岩石资源。

适宜且四个相邻区域全部未访问时，生成共享的128米海床：保留一个完整低坡沉积平原，另一些区域形成连续缓坡，并在原硬底倾向区域加入一至两块宽岩露头。外16米原床带、原岩石及其保护范围保持；这是一种有限程序化地貌组合，探索仍可持续向外生成，128米不是世界边界。

地形计划、四区实际出生、食物库存及能量账共同保存成功后，才公开新床面并刷新显示。任一旧区域阻止整组替换；保存失败不显示未保存的计划。已保存组合缺失或损坏成员时拒绝重建。离屏成员冻结，死亡、身份、历史、时钟和库存保留。

## 元素与生态

现有海猪分类代理消费表层碎屑，鼠尾鳕科代理消费底栖动物食物，绒球海葵消费悬浮猎物；符合原条件时，海蜘蛛代理使用原捕食模型。海猪的软泥底碎屑摄食依据[MBARI海猪资料](https://www.mbari.org/animal/sea-pig/)；绒球海葵可生活于泥底及岩露头，不能把全部海葵强行附到石头上，参见[MBARI绒球海葵资料](https://www.mbari.org/animal/pom-pom-anemone/)。海蜘蛛与海葵的关系参考[MBARI观察记录](https://annualreport.mbari.org/2019/story/giant-sea-spider-hunches-over-a-pom-pom-anemone)。这里不表示野外密度或所有类别必须共同出现。

新海床的实际三角面同时用于显示、床面查询、生境准入和动物支撑；新岩石使用原两种几何和三种材质。九区显示窗口、最多20动物/区、36次场景绘制上限保留；新地形注册表上限25区，当前准入读取最多16区。

已访问的路线点保留旧存档，因此不会为演示改造旧地形或补生。换种子时入口坐标由该种子的适宜组合确定，条件不足可以没有新组合。

## 验证与边界

本机与CI使用同一332项整合检查集合，本机构建通过一次。示例字符串种子42、四区-6,-10至-5,-9有37条动物记录（20海猪代理、8鼠尾鳕代理、9海葵），12块岩石中2块为新增宽岩；共享床最大抬升约0.981米，连续变化内部接缝23米。整个九区窗口另有一条原条件产生的海蜘蛛，合计81条动物记录。

三秒CPU模拟中，整个九区窗口23个动物位移、54次摄食、消费0.0344相对单位；三类食物均有实际消费。食物收支误差不超过5.56e-17，原生/捕食者能量误差不超过1.34e-15。完整旧记录、死亡、原子保存失败、离屏冻结、全九区卸载/回访/冷恢复、损坏组拒绝及有界远移通过。有限真实Three三角面检查的海床误差约4e-15米，岩帽约2.64e-7米。
