# 深海海蜘蛛与海葵接触摄食

本轮增加深海持续探索中的第四类动物：巨型海蜘蛛属代表 *Colossendeis* spp.。默认近距离观察点仍为原来的海猪属、鼠尾鳕科与 *Liponema brevicorne* 三类、16个代表体。新类别增加的是缓慢近底活动与已有海葵之间的摄食关系；不改变原海葵形态，也不把物种数量视作完整海洋的验收标准。

## 资料与适用边界

MBARI 的[巨型海蜘蛛资料](https://www.mbari.org/animal/giant-sea-spider/)记载该属代表的八条细长关节足、极小躯干、长吻管，参考深度2200–4000米，足跨距上限51厘米。模型显示20–40厘米的**足跨距**，不是躯干长度；身份为属代理，未辨认到物种。

[MBARI 的海蜘蛛与绒球海葵观测](https://www.mbari.org/news/sea-spiders-and-pom-pom-anemones/)支持吻管接触触手并吸食体液，较大的海葵常能在攻击后继续生存。报道中的Monterey照片约2894米，部分观察与鲸落、漂木或蛤床相关；它不能证明本原型3500米普通沉积平原的指定密度、同一调查样方共现或模型速率。本场仍是东北太平洋深海软底示意。原图已在浏览器查看，未下载或作为可分发资产使用。

## 模型链路

- 分区使用独立坐标种子决定0或1只海蜘蛛，需要已有适合的活海葵。海蜘蛛与原三类记录分开；死亡记录也占每格最多20个位置。
- 首次追加元数据在激活前保存，旧动物、随机流、时钟、三类食物斑块与账本保持。已经检查过的空位或死亡个体不补回。不能共同保存的旧存储接口继续原局部三类模型。
- 足跨距、八足端、小体和吻端使用共享、只绕竖直轴旋转的参考几何。实际支撑及有限沿途参考约束完整XYZ移动，缓慢抬起的根位置也计入距离预算。
- 海蜘蛛寻找已有海葵的16个低侧实际触手顶点参考。参考跟随原海葵渲染器的水流、时钟与摄食变形；感知距离和足跨距都不能代替吻端接触。
- 接触、饥饿和摄食间隔同时允许后，才减少海葵条件能量。双方保留身份，海葵保持最低体况；不模拟整只吞食、触手损伤、再生或据此产生新生物。
- 海葵原能量账本新增实际发生时才出现的 `predationTransferredOut`。海蜘蛛独立记录转入、代谢与同化损失；三类有机食物资源不会凭空增加，也不将转移记为维护消耗。
- 只有已加载、未锁定的当地所有者推进。海蜘蛛本轮不跨格迁移，未加载时冻结。观察灯和时刻不供能。
