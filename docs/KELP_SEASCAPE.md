# 巨藻整景

2026-10-06。本轮在原巨藻海域中组织一段384×128米的完整生境样段：高冠巨藻群、原生岩底、林下植物、沉积空隙和开放林缘，配合实际生态记录中的动物。这个范围是十二个相邻区域的首个整景组合，外围仍随探索持续生成。

普通观察切换到巨藻海域，点击“探索海带林”后进入“巨藻整景”，再通过“整景岩底 / 整景林间沙地 / 整景开放林缘”实际航行，或使用WASD自由探索。能力总览有四个观察点，导演的巨藻开场进入同一整景起点，四段移动观察随后展示整体生境。旧“巨藻林带 / 林缘空地”入口保留。

## 真实组成

固定首包所有者为`6,-2`起的6×2区域。字符串种子`"42"`的原海床自然形成密林、岩底与较低植被覆盖的外侧区域；保留原床面、252处巨藻根和268块岩体，再在12个原生宿主上追加49处通过准入的巨藻根。总计301处景观巨藻根，沿用原实例几何和水流摆动。景观根不等同于模拟生物量或实际动物数。

每处追加根读取原岩体的实际三角面高度，要求有限固着盘周围8点仍属同一岩体、与所有已有根至少间隔0.7米、水深5–25米、顶部低于水面和每区10米边距；每区72根上限保持。原岩体、床面、所有宿主、原根的身份和顺序均保留。没有追加岩体或把床面颜色当成硬底。

岩底观察点使用附近7块实际原岩体。林间开口有16×8米的有限沉积底调查，45个位置各检查中心与8个半径0.6米的身体探针；外侧空地另有6×6米、16个位置的同样调查。没有移除植物开路，调查不等同于整个384米样段处处畅通或无障碍。普通航行沿用原加载和避障规则。

其他种子使用其自身实际准入计划生成观察点；若固定样段的自然条件不足，允许不生成这一整景。未访问区域继续沿用原随机地形与四区林带机制。

## 生物与保存

十二区实际生命与初始库存通过原管线共同生成和保存：海胆、帽贝、顶螺、海星、巨藻鱼、岩鱼和近底访客仍使用原适宜条件，不强制补齐每种动物。示例十二区有152条实际动物记录（7类现有动物）、25个模拟巨藻宿主和141处林下植物；整个九区活动窗口的2秒CPU模拟中有88个动物实际位移，并从原库存摄食0.02976相对单位。每区最多3个模拟巨藻宿主和20条动物记录，死亡也占容量。低冠植物、藻体脱落食物与水层动物沿用现有模型，景观根不会直接添加无账本食物。

只有全部十二区确认未访问，完整计划、实际出生与初始库存才一次保存后公开。任何旧记录使本包保持原貌；旧死亡、历史、库存和时钟不重建。保存失败、缺失成员、被剥离计划或标记的记录、损坏的离屏食物账本均拒绝公开整景。所有标记都被外部删除时，无法从无记录处推断历史。

离屏新组员保存时钟保持0，进入活动窗口才模拟；卸载区域冻结，回访与冷恢复读取原状态。旧四区v1林带合同和原支撑实现保留。完整首包与原对齐读窗口合计最多24个所有者；公开来源仍最多25区、活动生态最多9区。渲染复用原批次，不提高81次景观绘制、4个共享几何和3个材质预算。
