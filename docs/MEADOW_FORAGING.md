# 草甸与礁缘动物活动

本批为已有礁乌贼、蜘蛛螺补上“接近实际合适位置—停留—有限摄食”。海马保留实际静态草叶抓附，棒状海鳃保留软底支撑和昼夜伸缩。仍使用94条浅海代表目录，不增加新物种或动物额度。

本地入口：<http://127.0.0.1:4175/ocean-world/?demo=seagrass-meadow-region&seed=56&world=meadow-foraging>。旧演示刷新后，顶部“最新海域”会保留原入口和种子，切到这个独立动物历史。

## 行为与边界

- 乌贼在日间缓慢接近实际礁缘近底位置，保持完整外套膜、鳍、头、腕与触腕的净空，抵达后悬停；夜间停栖，不摄食。
- 蜘蛛螺在原有真实岩石宿主三角面上选择短程目标，沿全壳、足及指突支持面移动，抵达后停留摄食。仍是有限硬底阶段，不是完整天然生境或实测足盖推进方式。
- 每次最多六个候选及一个原位置回退。目标高度使用完整身体采样；原速度、转向、home范围、途中采样、坡度、水深、占位及20全部记录含死亡和海龟的上限不降低。
- 摄食只在真实到达与整身合格后扣原有owner库存。乌贼仍使用未分辨动物营养，蜘蛛螺仍使用藻类营养。目标不是可见猎物、空间红藻斑块或新增食物；没有实现可见捕杀、繁殖、招募、跨owner迁移或完整自然食谱。
- 运动、悬停高度、昼夜时段和摄食量都是展示参数，未经野外校准。显示速度来自原控制器；镜头或渲染墙钟不能推进生态。

## 历史与集成

`meadowLifeVersion=1`保持原结构和所有既有历史保护。仅首次新建记录增加`meadowLifeForagingVersion=1`；个体与所属记录必须一致。旧记录缺少这个标记，继续原控制器，不迁移、补动物或补粮。新摄食记录保存当时目标和身体姿态，恢复时核验静态物理支撑及实际到达；旧成功摄食记录保持原结构。

普通和导演模式的未访问新海区启用本批；既有`world=reef-foraging`及更早显式演示的配方保持。`world=meadow-foraging`有独立动物历史，同种子地形、出生随机键保持，环境、探索和发现仍共享。UI入口、实际ReefWorld构造器、生态选项、reset和存档键有定向检查。

## 资料依据

[FAO头足类指南，印刷页92](https://www.fao.org/4/a0150e/a0150e10.pdf)记载旧属组合Sepia latimanus的浅珊瑚礁生境、日间活动及鱼/甲壳动物食性。这是活动方向的定性依据，不是本场秒级速率、悬停高度或具体觅食路径的实测依据。目录继续使用接受属组合Ascarosepion latimanus。

[FAO肯尼亚鉴定指南，印刷页37](https://www.fao.org/4/i2741e/i2741e05.pdf)记载Lambis lambis与礁坪、珊瑚碎石及细红藻摄食的关联。程序仍只消费原有相对藻类库存，没有将真实草叶作为食物，也没有宣称整个岩面实际长有细红藻。

本地验证结果见本文件末尾的收口记录及`output/validation/meadow-foraging-delivery.json`。CPU源代码、几何、生态与构建检查不代表GPU画面观感、遮挡或帧率验收。本阶段暂不提交、推送或部署。
