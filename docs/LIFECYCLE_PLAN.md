# v0.2：独立的长期生态实验与出生队列

本页主体说明`PopulationExperiment`七池模型，用于解释食物、光照、捕食和开放水体交换怎样共同改变功能群生物量。它是教学用的简化模型，参数未用具名物种或真实珊瑚礁观测校准；曲线不能作为野外种群预测。七池工作台已接入，并实际操作过365／730／180天对照及JSON导出。

另一个独立的`AgeStructuredExperiment`已实现匿名消费者的幼体／成体、储备付碳出生与出生队列，详见[AGE_STRUCTURE_MODEL.md](AGE_STRUCTURE_MODEL.md)。它没有把七池补充生物量改名为出生数，也没有连接当前三维个体。出生队列模型、Worker界面与数据接口已有检查；实际新面板操作、导出和窄屏浏览器复核仍待完成。

## 时间与实时场景的边界

- `ReefSimulation`、`KelpSimulation`与`DeepSimulation`继续使用模拟秒，观察游动、摄食、躲避和短时环境响应。
- `PopulationExperiment` 独立使用**模拟天**；`runMonths(1)` 明确等于 **30 个模拟天**，不是日历月。模型年季节周期为 365 天。
- `AgeStructuredExperiment`也独立使用模拟天，保留自身参数、队列和碳／阶段人口账目；其`runMonths(1)`同样明确为30个模拟天。
- 三种实时模型、七池实验与出生队列模型互不导入，也不把实时场景的几分钟暗中转换为几个月。长期实验显示自身时间轴、模式和单位。
- 不能把长期功能群生物量直接换成当前场景的 78 个具名个体；更不能从曲线虚构物种的出生数或寿命。

## 模型对象和原始依据

以下七池模型的面积固定为一个概念性的、充分混合的礁区。所有状态都是单位面积的有机碳生物量或碎屑存量，单位`g C/m²`；该模型没有位置、年龄、性别或个体数。独立出生队列模型的连续预期密度与年龄在文末另述，不适用于本页七池公式。

| 池 | 代码名 | 模型食物关系 |
| --- | --- | --- |
| 附着生产者 | `benthicProducers` | 光合输入，被草食群摄取 |
| 浮游生产者 | `planktonProducers` | 光合与外部输入，被浮游摄食群摄取 |
| 草食群 | `grazers` | 摄取附着生产者，被捕食群摄取 |
| 浮游摄食群 | `planktivores` | 摄取浮游生产者，被捕食群摄取 |
| 捕食群 | `predators` | 按草食群和浮游摄食群的相对生物量分配摄食 |
| 碎屑 | `detritus` | 接收死亡与未同化排出，被分解群利用，可流出 |
| 分解群 | `decomposers` | 利用碎屑，同化、呼吸和死亡 |

这里的浮游摄食群指能消费模型中浮游初级生产者的泛化功能群。它不等于实时场景中以浮游动物为食的蓝倒吊或绿光鳃雀鲷。若要描述这些鱼的长期食物链，需要额外建立浮游动物池，并重新取得参数依据。

模型形式借鉴三篇原始研究，**来源支持机制形式，不支持本模块的数值参数**：

1. [Holling（1959），Some Characteristics of Simple Types of Predation and Parasitism](https://www.cambridge.org/core/journals/canadian-entomologist/article/abs/some-characteristics-of-simple-types-of-predation-and-parasitism1/9E1E7D2CCC314766A424680444F4EA9F)，DOI `10.4039/Ent91385-7`：捕食摄食率随食物密度变化，饱和响应能表达处理时间带来的摄食上限。原文实验对象包括陆生动物，并非珊瑚礁校准。
2. [Rosenzweig 与 MacArthur（1963），Graphical Representation and Stability Conditions of Predator-Prey Interactions](https://www.journals.uchicago.edu/doi/abs/10.1086/282272)，DOI `10.1086/282272`：资源限制与捕食者—猎物反馈会影响稳定性；反馈不意味着任何设定都应恢复同一个平衡。
3. [Monod（1949），The Growth of Bacterial Cultures，原论文 PDF](https://garcialab.berkeley.edu/courses/papers/Monod1949.pdf)，[出版社记录](https://www.annualreviews.org/content/journals/10.1146/annurev.mi.03.100149.002103)，DOI `10.1146/annurev.mi.03.100149.002103`：资源浓度与微生物生长率可用饱和关系描述。这里用该形式作碎屑利用的教学代理；碎屑有机碳不等于原论文的特定限制底物。

## 每一步怎样改变生物量

设生产者生物量为 `P`、消费者为 `B`、食物为 `F`、碎屑为 `D`；所有通量单位均为 `g C/m²/day`。

- 光合输入为 `r × L × P`。密度反馈 `r × L × P²/K` 与自然死亡流入碎屑；基础呼吸从有机碳系统流出。因此生产者的光合与密度项合起来具有 logistic 形式。`L = lightMultiplier × exp(-1.5 × turbidityIndex) × [1 + seasonalAmplitude × sin(2πt/365)]`。衰减系数、季节幅度与相位都是教学选择，不代表测得的水下辐射或特定纬度。
- 摄食量为 `q × B × F/(h+F)`。`q` 是每单位消费者生物量的最大摄食率，`h` 是半饱和食物生物量。捕食群用草食与浮游摄食群合计作为食物，按各自占比分配捕食；分解群用 `D/(h+D)` 表达底物限制。
- 摄入碳分为同化、排出到碎屑和呼吸流出三部分，比例合计为 1。同化碳增加消费者生物量。
- 消费者死亡为 `m × B + c × B²/K`，转入碎屑；基础呼吸为 `a × B`，流出系统。`K` 是密度反馈的参考尺度，**不是禁止超过的硬上限**。例如分解群可能超过默认参考尺度 8；代码不会把它压回 8。
- 同化增量内部按 `recruitmentFraction/(1+B/K)` 分配为“补充生物量代理”，其余记为体生长。两者都留在同一生物量池。这体现密度对补充份额的反馈，但尚无成熟延迟、幼体阶段、卵、出生数量或年龄结构。
- 外部浮游生产者与碎屑输入、浮游生产者与碎屑交换流出、捕食群移除均有单独账目。交换项只表示局部开放水体的简化输入输出，不是水动力解。

没有强制恢复平衡、最低生物量保底或自动补回消费者。初始为零的消费者会保持缺失；黑暗、资源不足或移除可引起衰退。默认 seed 只改变初始存量（参考值上下约 12%），演化过程没有额外随机噪声。

## 参数单位与默认值

完整数值保存在 `DEFAULT_POPULATION_PARAMETERS`，导出时随数据保留。以下是读图所需的主要参数。

| 参数类别 | 单位 | 默认示例 |
| --- | --- | --- |
| 生产者光合增长系数 `*GrowthPerDay` | `/day` | 附着 0.06；浮游 0.25 |
| 密度参考尺度 `*CapacityGCM2` | `g C/m²` | 附着 85；浮游 25；草食 12；浮游摄食 10；捕食 4；分解 8 |
| 最大摄食率 `*MaxIntakePerDay` | `g 食物 C / (g 消费者 C × day)` | 草食 0.35；浮游摄食 0.45；捕食 0.25；分解 0.5 |
| 半饱和食物量 `*HalfSaturationGCM2` | `g C/m²` | 草食 15；浮游摄食 5；捕食 3；分解 3 |
| 同化、排出、补充分配比例 `*Fraction` | 无量纲 | 草食同化 0.35；其余同化 0.3–0.35；排出 0.2；补充分配上限 0.25 |
| 自然死亡、呼吸、拥挤系数 `*PerDay` | `/day` | 草食自然死亡 0.01；呼吸 0.018；拥挤 0.012 |
| 外部有机碳输入 `*InputGCM2Day` | `g C/m²/day` | 浮游 0.12；碎屑 0.08 |
| 水体交换率 `*ExchangePerDay` | `/day` | 浮游 0.045；碎屑 0.04 |
| 捕食群移除 `predatorHarvestPerDay` | `/day` | 默认 0；允许 0–0.1 |
| 环境比例和混浊指数 | 无量纲 | 光照倍率 1；混浊 0.15；输入倍率 1；交换倍率 1 |

环境范围用于排除错误输入，不是自然环境的已验证取值区间。速率参数均为非负；同化比例加排出比例不能超过 1；半饱和量和密度参考尺度必须大于零。

## 账本、数值方法与已验证范围

有机碳预算为：

```text
当前 7 池总有机碳
= 初始有机碳 + 累计光合固定碳 + 累计外部有机碳输入
  - 累计呼吸流出 - 累计交换流出 - 累计移除流出
```

内部摄食、同化、死亡和分解在池之间转移，不创造总有机碳。光合固定的无机碳与呼吸生成的无机碳放在边界之外；模型没有溶解营养盐、氧气或无机碳状态，**有机碳账本闭合不等于完整海洋碳循环或营养盐闭合**。

固定步长为 `0.05 day`（1.2 个模拟小时）。每一步先从同一旧状态计算所有需求；若某个供体的总转出超过存量，对该供体的所有路径同时等比例缩减，保证非负且保留通量分配与账本。仅将负的浮点残差置零，没有生物量上限截断。少于一步的时间保存为 `pendingDays`，以后累加；导出同时提供已模拟时间和余量。

新测试覆盖：

- 5 个 seed（1、9、42、77、2026）各运行 1825 个模拟天：采样均为有限非负值，总有机碳处于 0–300 `g C/m²`，账本误差小于 `1e-7 g C/m²`。
- 相同 seed、参数与初始条件在不同调用批次下得到相同曲线；重置可复现。
- 同 seed 的基线与干预组在干预前曲线一致；增大混浊降低累计光合输入；捕食群移除留下外流账目并改变食物链。
- 无光合、输入、交换和呼吸的设置保持总有机碳；消费者缺失不会被补回；黑暗导致生产者衰退；高初始拥挤仍保持非负与账本闭合。

上述边界是这些测试配置的结果，不是所有任意参数的理论上界。供体限制使过激设置也能保持非负，却不能保证其生态真实性或时间分辨率足够。调参时应检查通量是否反复受限，并按需要缩短步长和做收敛分析。

验证命令：`node --test tests/population-experiment.test.mjs`。首版通过 9/9 测试；这里的 5 年是模型计算时间，不是浏览器运行了 5 年。

## 调用与导出接口

```js
import { PopulationExperiment, runPairedExperiment } from './src/ecology/PopulationExperiment.js';

const experiment = new PopulationExperiment({ seed: 42, sampleEveryDays: 1 });
experiment.runDays(90);
experiment.setEnvironment({ turbidityIndex: 0.85 });
experiment.runMonths(6); // 明确推进 180 个模拟天
const snapshot = experiment.snapshot();
const table = experiment.exportCurve(); // columns + rows，适合绘图与 CSV
const bundle = experiment.exportData(); // 参数、单位、干预记录、曲线、当前账本和来源

const comparison = runPairedExperiment({
  seed: 42,
  durationDays: 365,
  interventionDay: 90,
  intervention: { turbidityIndex: 0.85 },
});
// comparison.baseline / comparison.perturbed 是独立可导出的数据包。
```

`reset(seed)` 保留构造参数与构造环境，并重新生成该 seed 的初始状态。`stepDays`、`runDays`、`runMonths` 均明确单位；没有通用 `step(seconds)` 别名。`setEnvironment` 原子校验后记录干预时间。批量对照的干预时间必须落在 `0.05 day` 网格上。

## 保存的 365 天批量对照

运行 `node scripts/run-population-experiments.mjs`，会重建 `output/validation/population-experiments.json`。报告包含 seed 1、9、42、77、2026 的 5 组基线与 15 组干预，共 20 次运行。每次推进 365 个模拟天，干预在第 90 天施加并保持至结束：

- 高混浊：`turbidityIndex` 从 0.15 改为 0.85。
- 减少外部浮游生产者输入：`planktonInputMultiplier` 从 1 改为 0.2。
- 持续移除捕食群：`predatorHarvestPerDay` 从 0 改为 0.08 `/day`。

每个运行保存初始条件、完整终态账本、逐日曲线（366 个点）、每 `0.05 day` 检查的生物量极值与最大账本误差。配对以逐步状态和完整累计账本的 SHA-256，以及逐日曲线和初始条件，确认第 0–90 天相同。报告还保存模型源码 SHA-256、参数、环境、单位、原始来源和限制说明。

首轮保存结果：20/20 次运行有限非负；15/15 配对的干预前记录相同；0 个数值违规；最大碳账本误差 `3.5904e-11 g C/m²`。这批运行每一步总有机碳范围为 `8.5540–120.4390 g C/m²`，是观测到的数值范围，没有用于截断模型。

## 已实现的独立出生队列范围

`AgeStructuredExperiment`仅含通用食物、碎屑与一个匿名消费者，两阶段均保存结构碳和储备碳（`g C/m²`）、连续预期数密度（预期模型个体/m²）与出生时间。成体实际储备支付新生结构及繁殖成本；成熟同时要求年龄下限20天和队列平均结构碳达到门槛。默认0.5天出生窗口的年龄判断可能产生保守延迟，低食物下身体增长会继续推迟成熟，不能将20天描述为固定成熟时间。

出生、成熟、自然死亡与采收各有数密度账目；出生和成熟的碳是内部转移，自然死亡回碎屑，采收离开系统。没有自动补回灭绝群体、人口下限或无碳出生。七池与出生队列尚未连接，碎屑也没有在最小出生队列模型内再成为食物；没有卵／胚胎、孕期、性别配对、繁殖季、幼体扩散定居或具名物种校准。
