# 本地阶段：按生境组织动物群落

2026-10-10。按用户“动物是核心、整体先于细节”的方向，本批调整实际动物配置和群游覆盖，不增加单体造型细节。

[直接体验生命巡游](http://127.0.0.1:4175/ocean-world/?demo=life-expedition&seed=55&world=animal-communities)。支持暂停与0.5–4倍速，经过礁区、沙沟、草床边缘和外坡。已接入“最新海域”和“生命巡游”按钮；远端未部署本批。

## 本批变化

新v20仅作用于十二格严格全部未访问的礁谷海区：按真实生境给水层鱼群、底栖动物、草床动物及原生类群分配出生位置。适合群游的双线乌尾鮗和蓝带笛鲷先获得排队机会，并按坐标种子轮换；身体、岩体、底质、深度、占位检查决定最终出生，候选排序不能授权出生。

每格仍最多20条全部动物记录，包括死亡与海龟；居民最多10条，礁旁群3–5条真实个体，水层群沿用原群游模型。每条都有独立身份、位置、时钟、摄食与食物扣账，没有装饰鱼副本。原草床、沙床和不规则礁石保留，本批未改变地形生成或新增物种，代表目录仍106类。
