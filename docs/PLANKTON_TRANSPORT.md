# 浅礁海流与食物链 · 有限里程碑

2026-10-04继续授权后，本轮补齐“海流 → 邻格浮游食物 → 当地动物摄食”。范围为浅礁已加载窗口，沿用既有动物、景观和连续水况，不增加物种、鱼体细节或完整水动力模型。海带林和深海另有自己的局部食物模型，本轮不推广到它们。

[NOAA 浮游生物资料](https://oceanservice.noaa.gov/facts/plankton.html)支持浮游生物随潮汐和海流移动。这是自然史依据；下述离散格面规则、参考库存、速率和通路门槛是开发近似，未经野外通量校准。

## 模型与保存

- 每格64米，是等面积、等参考容量的计算单元。不同水深不等于相同真实水体积；食物量不是实测浓度、颗粒数或生物量。
- 同一共享格面只读取一个面中点的连续海流法向分量。上游已有库存的请求量为`库存 × |法向速度| × 0.1秒 / 64米 × 开放比例`，来自全体区域完成本地行为后的共同快照。汇总同一来源的请求后限制总流出，再同时应用；本步新到货不能再次流往下一格。
- 格面5个横向样本，各检查面中心及法向两侧0.25米的实际支撑，共15次有限查询；海床、岩体、成组礁体和珊瑚使用共享支撑。共同水柱超过1.5米的样本才开放。它不是全三维孔隙率或测得的有效水力面积。静态面缓存最多96项，目标窗口集合最多9个ID。
- 本地`.0008/秒`浮游背景损失继续计出口；已启用格面的区域移除旧的`流速 × .003/秒`直接消失项，由真实格面流出替代。原外部输入公式保持，仍是未校准代理输入。藻膜与碎屑未作跨格输运。
- 内部流入／流出独立记录`ledger.transferredIn/Out`；原`input`只记录外部输入，`exported`记录背景损失、真正窗口外流出和容量溢出。区域预算为`initial + input + transferredIn - transferredOut - ingested - exported - 当前库存 = 0`。当前窗口内部新增流入与新增流出相等。
- 锁定保存中的区域及目标窗口内正在加载／读取失败的缺口关闭交换。真正窗口外下游计为出口，不修改冻结区域；未知上游不制造食物。加载失败即使把重试中心清空，独立目标集合仍保留，避免错误出口。
- 元数据兼容保存先于启用，旧动物、资源、时钟、RNG、历史和整个旧账本对象保持。缺省转移计数视为零，首次非零实际交换才追加键。死亡个体及群落分配规则保持。
- 既有全活区原子checkpoint／卸载保存资源双方；失败不提交一半。旧接口缺少`saveMany`时保持原本地食物交换和历史转移记录，关闭跨格输运。未加载海域仍暂停演化。
- 窗口累计值是当前加载区域各自存档历史之和，换窗口会改变，不能称整个海洋的累计总量。页面主要显示当前地图格最近0.1模拟秒的流入、邻格流出和窗口出口，暂停仍显示最近一步。
