# 巨藻林生活带

2026-10-06。这一包补充宏观场景组合：在普通探索中，把高巨藻、原有岩底、林下低冠、天然沉积空隙与现有动物组织在四个相邻区块中。没有新增物种或独立装饰动物层。

普通巨藻海域开启此功能，探索继续按坐标生成；128米是一个组合单元的宽度，不是海洋边界。巨藻海域的“巨藻林带”和“林缘空地”按钮沿海床前往。能力总览可直达两个观察点，导演以移动镜头依次观察，两章加入原巡游，共38章、1×观察时间448秒，加载另计。

## 一次完整组合

四个64米区块须全部未访问，并且原生森林覆盖存在足够的林内—林缘—开放区域变化，才会提交完整组合。最多在两个林地所有者的现有岩体上追加16株高巨藻；必须满足原岩体实际三角面支撑、有限固着盘采样、与原根的距离、水深、水面和区块边距约束。任何原岩体、植物、床面、ID和顺序均保留。

天然空隙从原沉积底候选中选择，采用中心与周围8点、3米半径的有限支撑采样，并避开原巨藻根；不删除植物形成开口。这是有限净空采样，不能宣称整片连续空间处处无障碍。

字符串种子`"42"`的路线示例为组合`-6,-2`，角色分别为开放区`-6,-2`、原生区`-5,-2`、林内`-6,-1`、林缘`-5,-1`。追加16株高巨藻，在5个原生岩体宿主上成组；当地原规则自然生成31株低冠植物。实际数量、动物与食物验收读数见[模型记录](../output/validation/kelp-forest-belt-model.json)。其他种子或不适宜区域可以合法不生成该组合。

## 实际生命与保存

新根进入原有巨藻宿主选择与出生管线，每区仍最多3个模拟巨藻代表、20条动物记录，死亡也占容量。原海胆、帽贝、顶螺、海星、巨藻鱼等根据原宿主与沉积底规则分布；水层鱼与豹纹鲨仍遵循原有适宜条件，允许自然为空。林下植物是实际场景描述符，不单独增加食物或模拟生物量。

完整四区计划、真实出生记录和初始库存共同保存成功后，才公开生成描述符并更新渲染。离屏组员先保存、时钟保持0；进入活动窗口才运行。任一已有记录使整个组合保持原生配置。已有完整林带读回四区一致计划；失败读写、缺失成员或损坏计划拒绝公开，保留已有状态。卸载回访和冷恢复读取完整个体、死亡、库存、时钟与历史，不补生、不补满。

同一位置的渲染也响应成功提交后的计划版本，避免相机未跨区时看不到追加植物。加载窗口仍为9区，保存前读取最多16个所有者，源计划注册上限25；远行替换有界注册表，不积累全部已探索区域。

## 模型范围与验证

巨藻附着硬底、林冠与林下生境支持鱼类和无脊椎动物的方向，依据[NOAA巨藻林生境说明](https://www.fisheries.noaa.gov/west-coast/habitat-conservation/kelp-forest-habitat-west-coast)与[NOAA蒙特雷巨藻林介绍](https://montereybay.noaa.gov/science/characterization/kelp-forests.html)。生成阈值、根数和距离是未校准的场景模型参数，不是当地实测分布。

本轮复用原巨藻食物模型：岩面藻、叶面生物膜、巨藻组织、有限小型动物食物、碎屑与脱落藻食物；摄食消费真实库存并记账。没有加入新的完整捕食、繁殖或动物体物质循环，也不将林下描述符数量当作生态库存。

验收包括真实CPU模拟、原Three实例与支撑、原默认生成和行为回归、保存失败不公开、旧死亡与完整状态、离屏冻结、全窗口卸载/回访/冷恢复、普通导航和导演入口。检查与构建记录分别见[检查日志](../output/validation/kelp-forest-belt-checks.log)和[构建日志](../output/validation/kelp-forest-belt-build.log)，发布状态见[交付记录](../output/validation/kelp-forest-belt-delivery.json)。

本轮没有新增浏览器观看、完整WebGL播放或纪录片式视觉验收；此前工具拒绝浏览器URL访问，未绕过该限制。有限功能包交付后继续整体海域与生态组合，不在这一处植物、个体或镜头上循环细调。
