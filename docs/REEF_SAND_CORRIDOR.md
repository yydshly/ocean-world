# 沙沟动物生活层

上一轮仍有六处沿途空站。实际检查发现：沙沟底质是真实沙地，但最近礁体相距约24–35米；旧居民的统一礁体近邻要求使沙地动物也无法在那里出生。部分区域已有20条记录，直接追加动物也不符合容量约束。

本轮采用新 reef-residents-v10 群落配方。已有六类软底居民及大梭鱼、蓝鳍鲹、豹纹鹞鲼可选择真实沙底参考位置，附着宿主明确为null；没有创建替代礁石。岩面、珊瑚和其他礁缘动物保留原宿主要求。候选沿已有地形沙沟分布，每区最多32个新增可能位置，选择时考虑现有真实动物的位置，避免全部集中在一端。

这些中心仅参与选择；最终仍检查实际沙底、完整身体、全形水深、全部真实触点、海床坡度、植物与动物占位。实际活动继续受原速度和活动范围约束，摄食扣当地已有库存。自然余量、每区10居民/20全部动物记录上限保持，死亡和海龟仍占位。只有十二区全部未保存才能原子生成，旧配方1–9和已有死亡、时钟、资源、随机未来不迁移。

## 演示和实际结果

[本地沙沟群落](http://127.0.0.1:4175/ocean-world/?demo=reef-valley-region&seed=55&world=sand-corridor)复用种子55原地形及连续礁谷路线，使用独立动物存档。原世界以及 world=habitat-layers 的上一轮演示历史保留；全局环境、发现和探索记忆仍使用同一种子。刷新会恢复自身历史，不补货。

固定55的实际群落仍有238条动物记录、79只居民，当地目录类型56→58、居民类型30→32；目录本身仍79个代表条目，本轮未新增具名物种。10只居民使用无礁石宿主的沙地位置：海星2、海参1、鲆鱼2、芋螺1、海兔2、梭鱼2，合计8个底栖位置与2个水层位置。其他符合沙地规则的类型不保证在该组出现。

按主路每10米采样、统计14米内出生动物，空站从80/150/160/340/350/360米六处减至340/350/360米三处。该结果是CPU距离检查，不等于实际屏幕可见。剩余三处参考底深约17.85/19.45/21.13米，全形、坡面和空间条件继续生效，没有放宽水深或增加动物预算来填满。

三个普通九区窗口合计9模型秒，72只居民移动、70只摄食。梭鱼3只移动/2只摄食，蓝鳍鲹2只移动/2只摄食；胡椒鲷2只白天休息，豹纹鹞鲼在本组缺席。完整冷恢复、原地形、所有原非居民出生与初始资源保持一致。新版独立存档与同种子普通新配方出生逐条相同，所有原世界存档行完整保留。

29个唯一定向检查和一次4.25秒生产构建通过；旧1–9完整32步原始记录逐字节一致。保持9活区、25公开支撑、97私有预读上限及导演67章/61动作/1994秒。冻结证据见 output/validation/reef-sand-corridor-delivery.json。
