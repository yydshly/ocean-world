# 蓝岩鱼群的已加载海域巡游

本轮把海带林既有蓝岩鱼（Sebastes mystinus）水层小组延展到相邻已加载海域。没有增加动物类别、修改默认 KelpSimulation、地形、巨藻、鱼体或材质。目标是补齐第二片海域的连续活动，并以有限实际观察和保存检查交付，继续遵循整体优先于细节。

## 行为、时间和资源

一次性的 waterRoamingVersion=1 元数据保存成功后才激活。所有原有字段保持，增加出生海域、个体时钟和较大的定性路线参考；路线从原小范围巡游的目标相位接续，动物位置不会被重新安排。数量、80–96 米路线半径、3200–3600 秒周期、0.18 米／秒日间速度和低光规则均未按野外数据校准，也不代表季节迁徙。

每个固定步先捕获整个九格加载窗口中的同组鱼姿态，再推进所有当地植物模型，最后推进鱼并提交归属变化。鱼携带自己的时间与摄食历史；每株植物使用所在地时钟、环境与实际代表宿主的锚点。邻近未加载植物使用保守包络，不推演离屏植物。无原子保存能力的旧适配器维持局部巡游，空间预测同样使用地理植物时钟。

每一步验证完整 XYZ 位移预算、海床九点支撑、水面高度、四个有限沿途参考、四藻柄与冠层参考及短时预测。实际经过或进入的区域必须已加载、未锁定且有容量；二十条容量包含死亡与原附底动物。受阻时只尝试有限局部方向或缩短步骤；历史动态侵入只在普通预算内改善，不瞬移，也不保证脱困。这不是完整鱼体／藻叶碰撞或流体求解。

摄食仍须接近当前地理所有者的真实动态 smallPrey 参考，并实际扣减食物和更新账本。跨区候选在整个固定步结束后发布，因此离开步属于来源，抵达后的下一步属于目的。归属变化保持原 ID、群组和渲染对象；永久历史占用标记防止游出后再次补群。检查点与卸载共同原子保存整个活区归属集合，失败保留状态并允许重试。未加载海域保持保存快照并暂停演化。

## 实际页面证据

真实字符串种子“42”的九格旧群落在暂停时包含129条动物记录、26条蓝岩鱼、5个小组。升级前后逐个原公开字段及区域保存摘要一致，未替换旧动物或安排新位置。

通过既有“观察林缘鱼群”入口跟随原 0,0 小组的一号鱼。1倍速运行187.4模拟秒后，六个原 ID 均进入1,-1，各自保留群组、出生格、时钟和越界历史；选中身份与 following 保持。三条鱼新增成功摄食记录。因邻格容量与植物参考影响，实际经过接缝并有局部返回，不解释为单向整群迁徙。

暂停后六鱼完整公开记录与所属区域时钟、资源、账本、计数、记录数保持。标记“蓝岩鱼跨区观察点”，通过原“岩底林缘”地点到268米处，六鱼真正从加载窗口消失；回返后记录精确一致。刷新产生新运行，再手动继续上次探索，六鱼与所属保存字段仍精确一致，页面保持暂停。原三个地点保留。最后恢复1倍速跟随。

浏览器诊断不包含隐藏随机状态、植物专有记录或完整食物斑块，不能据此宣称整个 IndexedDB 字节相同；这些保存路径由模型测试覆盖。源码重放使用实际公开个体、区域时钟和资源总量，隐藏 RNG／斑块分布按种子重建，明确不是字节级旧状态重放。

最终核对器通过16份实际DOM收据、410次静态水层参考、144份区域账本和最终全部16尾活水层鱼的动态参考。最终源码刷新后，原六鱼完整公开记录和2,-1所属保存摘要保持；恢复原组五号鱼跟随，1×继续37.4个体秒且六鱼均活动，页面／当前控制台错误为空。75份生产源冻结，四份变更与前轮哈希精确核对。

保留一个已核实的参考变化案例：观察器从邻近植物3,1所在加载窗口离开，同一旧位置的真实活动藻柄间隙原为+0.704530米，未知离屏相位的保守包络改成-2.939336米。15.4秒后剩-0.229913米，独立重放下一步18毫米普通预算改善到-0.212315米，未更新摄食或重置位置；最终37.4秒收据全水层参考均合法，最小间隙+0.256832米。记录为 `kelp-roaming-dynamic-diagnosis.json`，中间收据名为 `conservative-neighbor-recovery-running`。这证明该次保守包络切换的有限恢复，不能解释为可见叶片真实穿透，或推论每次都会脱离。
