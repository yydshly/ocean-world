# 深海岩石附着群落来源

本包只选两个具名代表：`Thalassocrinus alvinae`海百合与`Alternatipathes alternata`黑珊瑚。现有深海软底动物目录没有这两种。参考地区为东北太平洋深海硬底，显示水深约3500米；不是某一个实测站位或全部当地物种的重建。

## 海百合：身份、岩底、尺度

[Roux（2002）原始分类论文](https://www.jstage.jst.go.jp/article/specdiv/7/2/7_KJ00003893337/_pdf/-char/en)将Gorda Ridge材料定为`Thalassocrinus alvinae`。正模来自3100米；副模USNM E36052来自Alvin dive1405、3500米；Figure4展示同次潜航3500米活体。完整单臂长达12或15厘米，双侧有长羽枝，最长羽枝38毫米。其柄不完整，不能推算整株高度上限。

[Carey等（1987）Gorda Ridge原始调查](https://pubs.oregon.gov/dogami/ofr/O-87-05.pdf)记载岩质海百合组合与当时的`Thalassocrinus`新种；岩底悬浮摄食群落的记录与Roux后续定名构成生境依据。不能把整个混合岩泥群落都当作裸岩样方，也不复制报告中的自然密度。

[Messing、Ausich与Meyer（2021）作者Treatise](https://journals.ku.edu/treatiseonline/article/download/15390/13797/34864)说明五臂Hyocrinidae形态、外部流带来颗粒，以及臂、羽枝和管足的接触摄食机制。海百合类群食物包括有机碎屑等颗粒，也包含动物性食物；本种胃含物、粒径选择和食谱比例未核定。

目录选择`arm-length`0.12–0.15米，沿一条臂中心线计量，不含羽枝、杯体或柄。展示准入3400–3500米，位于两个原采样深度之间；两点不是连续完整自然范围。细柄长度、冠姿、底座、颜色和完整包络是作者展示选择。保留五条简单臂，不增加十臂或游离海百合的cirri。

## 黑珊瑚：身份、地区、深度与完整体形

[Everett等（2022）NOAA西海岸名录，v2021](https://repository.library.noaa.gov/view/noaa/17609/noaa_17609_DS13.pdf)记录`Alternatipathes alternata`在Oregon Province的412–4881米汇编范围。这个生物地理区由温哥华岛北部延至Point Arguello/Point Conception，包括北中加州；不是仅指俄勒冈州。

[Lima等（2019）作者分类处理](https://zenodo.org/records/5688370)引述Molodtsova与Opresko（2017）的真种诊断及2670–5089米范围。主轴上部向一侧弯至近水平，两个交替侧列的简单羽枝向下回弯，下部较长，成熟体呈风筒状。不能用另一种直立、羽枝近等长的黑珊瑚替代。最长羽枝约10–12厘米，不能把它当作全群体高度。

[DFO（2021）不列颠哥伦比亚珊瑚指南，p82](https://publications.gc.ca/collections/collection_2021/mpo-dfo/Fs97-6-3433-eng.pdf)保留`Alternatipathes cf. alternata`的比较鉴定，给出高度至30厘米、黑色骨骼与桃色至白色珊瑚虫。[Graiff等（2025）北中加州原始调查](https://repository.library.noaa.gov/view/noaa/71007/noaa_71007_DS1.pdf)有具名代表的3296–3313米直接观测及25–35厘米高度；这些观测并非3500米。

[Molodtsova等（2022）原始分类研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC8833236/)指出历史`Bathypathes alternata`存在误鉴。因此目录用真`A. alternata`形态作具名代表，另列鉴定局限；不借用`B. pseudoalternata`或`A. venusta`的数据。展示准入3400–3600米在真种报告范围之内，未使用NOAA汇编的浅端来扩大本版范围，未声称和海百合同站共现。

[Warner（2005）原始黑珊瑚调查](https://archivo.revistas.ucr.ac.cr/index.php/rbt/article/download/26620/26825/70777)的目级功能描述支持硬底holdfast、六条触手与动物性悬浮摄食。[Wagner、Luck与Toonen（2012）作者综述](https://doi.org/10.1016/B978-0-12-394282-1.00002-8)支持刺细胞、黏液与动物性浮游食物。这里只移用目级功能机制；没有转移加勒比或夏威夷的深度、自然密度、速率和寿命。本种胃含物与食物比例未知。

目录选择`colony-height`0.25–0.30米，指底座到完整展开体最高点，不能用弯曲轴的弧长替代。实际实现需保留近水平弯轴、左右羽枝及回弯末端。

## 几何、接触与食物合同

每条动物是独立记录，固定底座局部原点`(0,0,0)`；`+Y`沿实际岩面法线，`+X`为岩面切线。必须在原生岩石三角形上支持完整底座，并检测包括柄、冠、羽枝和所有附属体的完整净空。底座半径和净空是工程选择，不是标本测量。

表内单位乘各个体的选择尺寸。海百合一条臂的中心线长归一为1，珊瑚展开体高度归一为1。包络包含有限动画。固定食点和底座不得被动画偏移，其余姿态可以有限变化。食点只是明确的模型接触代理，不把一个点冒称整个真实过滤面积。

新独立食物控制体初始库存为0，以实际局部外部输入产生有限流动粒子，分别记载输入、摄入、输出和存量。`particulateOrganicFood`只供海百合的营养有机颗粒选定部分；`smallSuspendedAnimals`只供黑珊瑚的动物性悬浮食物选定部分。没有修改旧`sim.suspendedPatches`或将旧动物性食物改称海绵的细菌/DOM。粒子沿固定Y、+X方向运动，撞击支撑体停止并转入控制体输出；只有实际食点接近才扣对应库存。各动物能量账与这份控制体账分别保存。

这些相对食物单位不是克碳，流速和速率未经实测校准。温度、盐度、氧耐受、自然密度、年龄、增长和繁殖率保留`null`。昼夜和观察灯不增加食物或能量；两类均无已核定发光，不增加发光效果。

## 本轮保留的缺口

不加入玻璃海绵：本轮找到的具名硬底材料没有同时满足东北太平洋、约3500米与全体型条件。`Bathyalcyon robustum`虽然有明确原始石附着形态，但东北太平洋深度汇编与主要西太平洋原分类材料还需独立核对，暂不拼接成第三条。这个有限包改善硬底群落的整体形象，不以增加目录条数替代生境和摄食证据。
