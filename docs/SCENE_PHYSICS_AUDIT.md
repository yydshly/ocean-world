# 场景物理与生境一致性审查 · 2026-10-04

用户要求三片海域统一排查，继续遵循先整体再细节。本轮核查底质、支持面、植物附着、水面范围、运动预算、水流与食物输运、光照与生态能量；不新增物种或雕刻细节。

## 科学依据与统一规则

巨藻 Macrocystis pyrifera 是大型褐藻，固着器抓附岩石等硬底，不是扎入土壤的吸收根；气囊帮助藻体在水中向光展开。因此海带长在岩石上合理。海草是开花植物，根与地下茎在沉积物中固定；不能把二者混为一种种植逻辑。造礁珊瑚使用适宜硬底。这里的具体密度、株数、速度和支持探针是展示模型的选择。

- [NOAA Fisheries：Kelp Forest Habitat](https://www.fisheries.noaa.gov/west-coast/habitat-conservation/kelp-forest-habitat-west-coast)：岩礁、固着器、气囊与浅水温带生境。
- [NOAA Florida Keys：Seagrass Meadow](https://floridakeys.noaa.gov/plants/seagrass.html)：沉积物内的根和地下茎。
- [NOAA Florida Keys：Coral Reefs](https://floridakeys.noaa.gov/corals/coralreefs.html)：幼体定居硬底。
- [MBARI：Sea pig](https://www.mbari.org/animal/sea-pig/)与[Pom-pom anemone](https://www.mbari.org/animal/pom-pom-anemone/)：深海软底生活与食物方式；海葵不应被错误限制为只有岩底。

| 对象 | 场景规则 | 本轮处理 |
| --- | --- | --- |
| 巨藻 | 固着真实硬底，底部不随流漂移，冠层保持在水中 | 保留已有岩石／锚点／长度；景观弯曲沿世界海流方向，不随实例朝向旋转 |
| 海草 | 最终根坐标位于适宜沉积底，不能被岩石掩埋 | 在随机偏移之后重查底质、深度及真实岩面占据 |
| 礁珊瑚／岩面藻 | 使用共享硬底支持 | 保留已有硬面三角支持；岩石下缘补接海床，不把整岩下移埋住附着点 |
| 海床动物 | 支持点与可见海床一致，爬坡也花费三维移动距离 | 礁与海带使用实际 Float32 海床三角；普通移动缩短或停止，原观察区同步约束 |
| 游泳动物 | 保持水面／海床净空，不能瞬移到岩顶 | 支持投影同样消耗 XYZ 距离；有限步内采样，速度由最终实际位移计算 |
| 附叶蜗牛 | 宿主锚点、叶面、环境和时钟一致 | 每个可见蜗牛均有真实宿主；近景最多9格×3株，离开范围时成对隐藏 |
| 深海悬浮食物 | 水平平流不能沿岩坡凭空升高 | 保持世界Y，沿整步检查支持面，接触后退出悬浮通道并记出口 |
| 光照／生态资源 | 观察灯和显示颗粒不产生生态食物 | 深海仍无阳光／光合；三池与个体摄入、出口真实闭合 |

## 已复现的问题与修复证据

1. 海带林原2米海床网格和解析支持面最大相差23.0毫米，超过爬行动物3毫米离底量。现在生成器、渲染、法线和实际支持共用相同网格；有界顶点／邻格缓存保留。
2. 浅礁3个种子×81格中，12,694株草有1株偏移到硬底分类、8株根部被实际岩石埋入超过3厘米，最大0.848米。相同扫描修复后12,650株，错误底质／掩埋均为0。只移除不合法景观根，未删除生态个体。
3. 浅礁150,300次普通动物固定步中，原11,368步超出速度加残余流动的完整XYZ预算，最大89.45倍。修复后同一有限扫描超预算0，最大比值1.000000000127为浮点余量。原礁与原海带观察点的游泳／爬行也同步使用有限三维预算；礁底栖速度改由最终XYZ位移计算。
4. 海带旧近景宿主任意限制为3株，即使附近有更多附叶蜗牛，也会显示在不同的低精度景观叶面上。现在可见蜗牛必须拥有对应真实叶面，旧低精度景观宿主被隐藏，避免重复显示。
5. 深海真实岩肩案例只横移6毫米却把悬浮食物抬高51.68毫米；修复后世界Y变化为0，遇到岩体时资源从该通道出口扣除。满256条记录且某通道空时也不会对null输入：有限输入同时记出口，不扩容量、不生成免费食物。
6. 最后严格比较暂停与刷新时，实际海带分区从1829.6秒退回1822.7秒，丢失6.9秒最近演化。原10秒自动保存与页面退出时排队的异步保存不能保证刷新前提交完成。现在暂停立即冻结模拟，并等待最新原子checkpoint完成后才向界面确认；保存失败仍保持暂停并提示重试，不把失败写入当成成功。中间复核已不再回退，但刷新默认运行仍让一格在手动暂停前前进0.1秒；现用独立`tidal-observation-paused-v1`界面偏好使已暂停页面刷新后直接冻结，不改观察点或群落记录。最终实际海带刷新九格的全部动物、时钟、资源、账本和计数精确一致，页面仍暂停；两段中间失败证据均保留。

浅礁证据：`output/validation/reef-physics-before.json`、`reef-physics-after.json`。海带共享网格、基座和迁移：`tests/kelp-physics-support.test.mjs`。深海平流／碰撞／旧档：`tests/deep-simulation.test.mjs`、`deep-ocean-ecology.test.mjs`。原观察区预算／速度：`tests/supported-motion.test.mjs`。最终测试与浏览器收据见PROGRESS最新记录。

## 有限审查结论与验证范围

科学上的问题是把不同底质、支持面和运动规则混用，而不是巨藻长在石头上。本轮已统一处理可见海床、附着支持、实际XYZ位移、宿主显示与食物输运；记录可复现缺陷和保存边界后收束，不再把本次排查延伸为叶片、动物造型或材质优化。

最终406/406项相关回归通过；独立暂停偏好接入后重复运行受影响的19项暂停／World测试也通过，这19项与406项重叠，不累计成425项。最终生产构建通过。17份实际浏览器快照保留在`output/validation/scene-physics-browser-receipts.json`，其中两段中间刷新偏差为缺陷证据，不算最终成功验证。三片海域分别九活格的暂停状态精确保持；最终海带暂停后刷新九格记录与时钟精确一致。

独立验证器复核17个相机中心、92个浅礁底栖支持、525个海带底栖支持、216个附叶蜗牛参考、1,320个深海足端、73个深海海葵锚点和153份资源账本，全部通过；实际近景包含5株对应宿主。最终汇总与75份源码冻结为`output/validation/scene-physics-validation.json`及`scene-physics-source-hashes.json`。这些是有限位置、参考支持与记录检查，不能推论完整身体／叶片碰撞、所有坐标或无限耐久。

完整探索性测试共509项，最初493通过、16失败；其中5项本轮支持契约／测试夹具问题已修复并包含于最终406项相关回归。另11项历史失败已单独复现与归因：9项旧岩体圆整数组契约、1项旧珊瑚外观源码范围契约、1项断裂岩面反算探针的微小数值残差（最大0.0769毫米）。相关因果源码与上一轮冻结哈希一致，上一轮382项子集没有覆盖这些检查；这不证明旧完整套件曾通过。本轮没有删除或跳过这些测试，也不宣称完整套件全绿。证据为`output/validation/scene-physics-historical-baseline.json`及`scene-physics-historical-tests.tap`。

## 存档与实际范围

沿用原typed-seed命名空间。浅礁 `floorSurfaceVersion=1`、海带 `supportGeometryVersion=1` 只在必要时校正支持Y与相应法线／食物点；身份、XY、时间、RNG、资源量、死亡、体能和摄食历史保留。修正先提交再激活，保存失败保留旧记录并阻止该错误支持区域发布。深海 `heightM` 更新为世界Y相对当前实际底床的高度，旧格式仍合法，刷新不会重建资源和动物。

仍是定性模拟：海带／深海当前用全局+X流作为边界条件，浅礁为连续坐标场；未求解真实流场、波浪载荷、压强、岩石稳定性或所有身体／叶片的碰撞。海带原观察点球岩的解析接触与低模三角差最大固着点5.07毫米／附岩动物5.48毫米；本轮记录这一有限几何近似，不开展微形态循环。植物曲线表现固着与向上展开，未计算完整藻体浮力和弹性。深海退出悬浮通道不是已模拟沉降到另一资源池。代表动物和景观株数不等于完整生态系统或实测密度。
