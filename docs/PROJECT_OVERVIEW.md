# 海洋世界的当前能力与扩展方向

更新于2026-10-14。项目希望让没有见过大海的人，也能通过连续画面、观察和讲解理解海洋的尺度、环境差异与其中的生命。长期方向是可持续扩展的海洋世界，以及可以复用的场景、物种和行为能力。

**当前已归档到阶段07：7分30秒的“第一次认识海洋”总览已经公开，原4分钟浅海、60秒鱼群协同、75秒样板与研究探索模块继续保留。** 当前成果适合观看、科普展示和后续开发复用；纪录片级真实感、完整海岸到深海、天气系统及持续实时生态仍是后续目标。

## 如何进入观察与探索

首次观看从产品首页的7分30秒海洋总览开始，以1倍速度播放并开启讲解。先理解海面、水体与海床的关系，再观察浅海、鲸豚和深海的差别。发现感兴趣的画面可以暂停或选章，自由观察后再返回导览。

想深入浅海时进入4分钟路线；想专看群体行为时进入60秒鱼群协同。研究入口用于了解更多生境、功能和持续探索的范围，需同时查看对应的限制，不把它们等同已验收的主线体验。

## 已验证的结果与仍存在的差距

阶段07远端以正常1倍速度完整播放450模型秒、450.0421实秒，16段讲解有实际媒体播放记录，没有操作中断、页面或控制台错误。该次桌面实播最大帧间隔141.8毫秒，没有超过250毫秒的长帧；导航至画面就绪17.679秒，首次加载仍是主要差距。

这次运行使用RTX4070 Laptop、DPR1.5、原渲染比例，窗口由1280×720变为780×871.33；缓存和网络未受控。它证明这次完整桌面播放可以完成，不能作为手机、固定视口性能对比、5秒加载或人耳试听的保证。完整条件见[发布验收](validation/stage-07-publication-20261014.json)。

整体上仍需改善海面规律波纹、简化海岸、动物模型感、局部裁切与加载。当前没有完整天气循环、沙滩到入水过程，也没有全球海洋连续调查、所有物种的自然运动和完整食物网。旧研究入口的已知问题另有历史说明，阶段07主线发布没有将它们全部修复。

项目不设一个没有依据的“全海洋完成百分比”。当前的完成点是一个已发布、可复看、可恢复的海洋总览阶段；下一阶段从明确范围中选择一个完整片段，完成后再扩大范围。

## 后续可以扩展哪些空间场景

以下是后续候选清单。已有礁谷、沙道、草床、温带藻林、开阔水域和深海模块可作为起点；清单中的完整场景与衔接尚未全部实现。

| 空间场景 | 需要形成的整体效果 | 对应生命与观察方向 |
| --- | --- | --- |
| 沙滩海岸 | 沙滩、潮线、岸浪、沙丘或陆地参照，与海域尺度相连 | 岸边生物与漂积物；观察浪与岸的关系 |
| 岩岸与潮间带 | 岩台、潮池、潮沟、露出与淹没过程 | 附着、躲藏与潮池群落；按海域选择代表 |
| 浪区与浅水入海 | 破浪、水线、折射、近岸浑浊、由空气入水的变化 | 近岸小鱼、游泳与底栖动物分层 |
| 浅海活礁谷 | 连续活礁、沟槽、洞隙与庇护空间 | 礁鱼群、附着动物、捕食者与躲藏联系 |
| 沙道与沙坡 | 沙纹、不规则地形、礁沙边缘、活动痕迹 | 沙地摄食、停留、埋藏等行为候选 |
| 海草甸 | 草床核心、边缘、裸沙及与礁区的过渡 | 草间居民、草上水层与访客联系 |
| 温带藻林与岩底 | 岩底、林下、藻间、冠层与林外水体 | 底栖动物、岩鱼、软体动物及穿林运动 |
| 开阔海洋 | 大尺度海面与水柱、远近参照、较稀疏群落 | 大型动物、不同水层鱼群、跟随与呼吸 |
| 中层水体 | 光照梯度、稀疏海雪、开放的立体空间 | 适合深度的游泳、漂浮和垂直运动代表 |
| 深海泥底与岩缘 | 观察灯、软泥、坡面、岩露头与海床结构 | 贴底摄食、附着与离底游泳代表 |
| 洞穴与海山 | 入口、遮蔽空间、岩壁、坡面与水流条件 | 特定栖息地的居民与访客；另做共现和运动检查 |
| 热液、冷泉与极地 | 各自独立的地质、环境、照明与生命条件 | 专题资料支持的群落；获得合规资产和可靠依据后再选入 |

自然邻接的环境可以连续观察；热带浅海、温带藻林、极地和不同深海站点不能随意拼成同一真实地点。跨海域与长距离移动采用明确的航行、换乘或时间压缩，让观众理解为何环境发生变化。

## 天气海况与不同风格如何扩展

| 维度 | 可列入后续的状态 | 需要一起变化的内容 |
| --- | --- | --- |
| 天气 | 晴天、阴天、海雾、降雨、较强风浪 | 天空、云、可见距离、光照、海面反射及相应视听效果 |
| 时间 | 清晨、日间、黄昏、月夜 | 日月位置、色温、可见性，以及有依据的动物活动变化 |
| 海况 | 平静、风浪、涌浪、近岸破浪 | 波形、方向、尺度、岸边浪花和观察运动 |
| 水体 | 清澈、近岸较浑浊、不同海域水色 | 光吸收与散射、悬浮物和底部可见程度 |
| 潮汐与海流 | 潮线变化、潮池淹没、局部流动 | 地形接触、植物与动物响应；独立于天空换色 |
| 场景气质 | 热带浅海、温带岩岸、开阔大洋、深海、极地 | 统一尺度、材质、运动和光照原则，保留各环境特征 |

先在同一片海岸形成晴天、阴天、黄昏三个完整状态，再选择雾、雨或强风浪。天气不能仅用全屏换色表示，也不能让深海海床瞬间获得与海面一样的摇摆、浪花或亮度变化。

## 物种和运动轨迹如何扩展

物种扩展按栖息地补齐生活层次：附着群落、近底居民、草间或洞隙居民、中层鱼群、开放水域访客、大型动物与深海功能代表。每批确认分类层级、尺寸、出现环境、活动水层和素材许可；更多数量不能替代正确身份或合理共现。

运动与行为可从巡游、停留、滑行、转弯、避障、庇护、摄食、受扰、呼吸逐步发展到群体协调、捕食与躲避，以及更长时间尺度的昼夜垂直运动或季节迁移。后两类需要物种资料与适合的时间尺度，不把预设路径称为已实现的自然迁移。

| 轨迹用途 | 如何产生 | 适合做什么 |
| --- | --- | --- |
| 导览展示 | 编排观察重点，动物在有限行为模型内响应 | 复播、讲解、电影式观察；当前主要方式 |
| 实时互动 | 个体依据地形、邻居、资源、刺激与内部状态作出决策 | 小范围可操作栖息地、鱼群试验和生态沙盒；后续扩展 |
| 观测数据回放 | 使用有许可、采样和误差信息的真实记录 | 科普对照、研究观察和自然轨迹专题；后续扩展 |

现有浅海协同鱼群以30Hz求解并预备240秒回放，超过240秒保持末帧；鲸豚也使用有限准备状态。未来若需要长时运行，应将实时决策、动物状态与显示姿态分开，保留同一身份和历史，而不是循环重置鱼群后称为持续生态。

## 后续重构与应用方向

后续底座可以逐步划分为八层：**场景与环境配置 → 资产与物种目录 → 实体状态 → 轨迹与决策 → 群体与生态关系 → 流式世界与保存 → 呈现镜头与旁白 → 应用层**。这些边界是重构思路，当前并非已经形成统一的八层接口。每次先服务一个完整片段，保留旧模块与可恢复版本，避免一次重写所有能力。

| 可扩展的应用 | 可复用的基础 | 需要单独交付的能力 |
| --- | --- | --- |
| 潜水探索游戏 | 海域、栖息地、动物与观察镜头 | 移动碰撞、玩法规则、装备或行动条件、任务与进度保存 |
| 摄影与物种图鉴 | 动物资料、镜头与截图 | 观察和识别条件、照片保存、图鉴和评价反馈 |
| 科普任务 | 场景、讲解、字幕与行为事件 | 问题、互动、反馈与理解验收 |
| 生态沙盒 | 有限行为、资源与区域记录 | 可控实验、状态解释、重放对比与模型适用范围 |
| 导演和内容制作 | 章节、镜头、语音与场景配置 | 可复现拍摄、编辑、导出、字幕及来源信息 |
| 海洋资源组件 | 环境、物种、轨迹及呈现模块 | 稳定接口、示例、版本、资源预算与逐项许可 |

当前导览还不是完整游戏。选择一个应用后，应先形成用户行动、目标、规则、反馈和可保存结果，再扩大内容量。例如“找到三类动物、观察一次鱼群受扰并保存照片”，可以作为一个有限试验。

## 每一阶段如何完成并归档

下一阶段建议从“海岸入水”“同一海域的三种环境状态”“一个完整栖息地的互动”中选择一个；新增海域、物种批次和游戏玩法分别安排。每次提前定义入口、时长或范围、观察重点、目标设备、主要验收标准和停止条件。

整批实现后先看整体空间与动物联系，再完整检查加载、播放、必要交互和旧能力保留。集中修正一轮、展示实际效果、记录剩余瓶颈并固定版本；达不到范围内目标就明确说明原因，不自动转入无限修补。

单图概览可以按“目标 → 当前成果与入口 → 空间场景 → 天气和物种行为 → 可复用底座 → 应用方向”阅读。图中的项目实景只表示对应的已实现模块；未来候选场景用文字和状态标记说明，不能用效果背景将它们误呈现为已完成内容。
