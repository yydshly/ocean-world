# 浅海宏观元素组合 · 2026-10-05

本轮按用户“先整体效果”的要求，把岩礁、草床、沙地、既有动物与稀疏探索物件组合成普通探索可见的场景。新增不规则石簇、草床边缘草簇、灌水玻璃瓶和漂木；保留已有大岩体、珊瑚、海草及动物生活型。此次不增加物种，不展开单株、动物形态、材质或镜头细调。画面仍是程序化雏形，元素数量不能替代视觉验收。

## 有限生成范围

仅浅海 `reef` 显式启用；海带林与深海保持原实现。每个64米区域围绕独立种子选定的真实草床邻域形成一个约12米半径的组合，缺乏合适草源时采用区域内部的浅海底质候选。安全筛选可以留下稀疏或空组合，不为凑数放入冲突物件。

| 元素 | 每区上限 | 展示尺寸与规则 |
| --- | ---: | --- |
| 不规则石簇 `stone` | 8 | 两种角形轮廓，宽0.4～2米、高0.1～0.5米 |
| 草簇 `plant-clump` | 6 | 宽1.1～2米、高0.55～0.95米；必须引用至少两株7米内真实生成海草，根位于合适沉积物 |
| 玻璃瓶 `bottle` | 1 | 长0.35米、直径0.085米；稀疏、未封口、灌水、沉底，不作水面漂浮瓶 |
| 漂木 `driftwood` | 2 | 长1～2米、高0.1～0.2米；已落底的景观物件 |

每区合计最多17件，九区窗口最多153件。尺寸、概率和密度均为未校准的展示选择；漂木与瓶子没有持续漂移、浮力或刚体动力学。草簇是既有草床的景观补充，不宣称新物种、生物量或生产量。

## 真实支撑与旧场景保护

新物件完整水平包络距区域边缘至少4米，避开原40米局部样景，以及实际岩体、地貌、珊瑚和海草的既有包络。原地形、岩石三角面、珊瑚附着和草根不移动。

石簇、瓶子和漂木的渲染与支持查询共用冻结的Float32三角网格。放置高度取所有实际网格顶点在真实海床三角面上需要的最大Y：刚体顶点不进入海床，至少一个顶点接触海床。植物全部叶片共用一个真实落底的根；其静态完整冠层仅作为游泳动物的有限避让代理，未模拟逐叶碰撞或流体受力。

初次分配避开旧动物的位置、home、target、refuge以及有限学校／巡游包络；非海龟使用同时考虑高度的保守三维排斥，高水层动物不会让整片海床因二维投影而空缺。海龟全部16条闭合巡游段按完整水平身体包络保护。有限食物位置与原生路径也保留。刚体进入实际支持查询；草簇只影响游泳支持，蝠鲼、海龟和邻区移动沿原有检查读取新支持。

恢复检查对该条已保存景观使用局部支持回调，正式激活后才注册公共支持；待激活几何不进入运行中的物理帧。异常恢复、失败提交、卸载、重置和释放清理支持注册，避免隐形障碍残留。此实现不构成全部动物的连续扫掠碰撞或完整物理世界证明。

## 保存与模型边界

新增三个独立持久字段：`sceneElementsVersion=1`、`sceneElementsInitializedAtSec`、`sceneElements`。独立坐标种子和稳定ID不消耗旧生物RNG；完整区域记录成功提交后才公开。已有标记的空数组也保持一次分配，不补填物件、不重生旧群落。损坏或部分新字段、非法身份、尺寸、草源、归属和落底几何拒绝恢复。

新景观不占用动物容量，没有食物库存、能量、氧气、摄食、代谢、繁殖或生产。保留原动物身份、死亡记录、资源、账本、时钟、RNG及扩展字段。旧生态默认关闭路径保持原行为；合法历史景观恢复时不因动物之后移动而重新执行出生排斥、重新生成布置。
