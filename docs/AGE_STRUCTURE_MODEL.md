# 独立生命周期教学实验

实现：`src/ecology/AgeStructuredExperiment.js`。它与旧 `PopulationExperiment` 七池实验、实时 `ReefSimulation`、`KelpSimulation` 及其 3D 个体互不导入。当前只包含一个匿名消费者功能群、通用有机碳食物和碎屑；没有把完整食物网或全部海底生物扩展为生命周期模型。

本版可以解释：摄食供碳、储备支付维持、食物依赖的身体增长、带年龄下限的阶段转移、成体付碳产生新生队列、死亡回流，以及阶段采收。参数是未校准教学选择，连续预期数密度不是野外丰度预测，也不是 3D 场景的出生条数。

## 公共接口

```js
import { AgeStructuredExperiment, runPairedAgeExperiment } from './src/ecology/AgeStructuredExperiment.js';

const sim = new AgeStructuredExperiment({
  seed: 42, parameters: {}, initial: {}, environment: {},
  sampleEveryDays: 1, timeStepDays: 0.05
});
sim.stepDays(90);
sim.setEnvironment({ foodInputMultiplier: 0 });
sim.stepDays(275);
const current = sim.snapshot();
const curves = sim.exportCurve();
const bundle = sim.exportData();
const pair = runPairedAgeExperiment(42, 365, 90, { foodInputMultiplier: 0 });
```

`runDays` 是 `stepDays` 的明确单位别名；`runMonths(1)` 恰为 30 个模拟天。固定步长默认 0.05 天，调用批次可以更小，不足一个步长的时间保留在 `pendingDays`；单次最多推进 3650 天。允许 0.01–0.1 天的显式步长用于敏感性检查，采样间隔和出生窗口须为步长的正整数倍。对照干预日须与该步长对齐。没有秒到天的暗中倍速转换。

`reset(seed)` 保留构造参数、初始覆盖值和构造环境，恢复该 seed 的状态。seed 仅使未明确覆盖的初始食物和两阶段密度在默认值周围 ±5% 变化，运行过程中不再随机抽样。相同 seed／参数／环境改变序列与总天数可在不同调用批次下重放。

`runPairedAgeExperiment` 也接受一个含 `seed / durationDays / interventionDay / intervention` 和构造选项的对象。返回 `baseline / perturbed` 的完整导出、干预定义和 `preInterventionEqual`。环境变更先整体校验，成功后才修改和记录。

## 两种量，两个账本

每个队列有 `densityM2 / structureC / reserveC / stage`、最早／最晚／加权平均出生天，以及 `maturedAtDay`。结构碳与储备碳均为 `g 有机 C/m²`；`densityM2` 为**连续预期模型个体/m²**。平均结构质量为 `structureC/densityM2`，单位 `g 有机 C/模型个体`，不等于总生物量除以固定鱼体重。

`snapshot` 提供食物、碎屑、两阶段结构／储备／总生物量、两阶段密度、平均体型和年龄、队列数、完整累计账本，以及有机碳和两阶段人口平衡误差。没有个体时平均值为 `null`。每日采样仅保存汇总状态；当前导出额外保存完整队列，不在每一天重复保存所有队列。

有机碳闭合检查：

`food + detritus + Σ(structure+reserve) = initial + externalInput - respirationOutput - exchangeOutput - harvestOutput`

人口平衡分别检查：

- `juvenile density = initial juvenile + births - maturation - juvenile natural deaths - juvenile harvest`
- `adult density = initial adult + maturation - adult natural deaths - adult harvest`

同化、增长、出生和死亡回流是内部转移。成熟仅改阶段；`maturationC` 是转过阶段的碳的累计诊断，不能再次添加到总碳。`maintenanceUnpaidC` 是累计需求缺额，不能当成实际呼吸碳或新的状态池。

## 默认参数与单位

| 类别 | 默认选择 | 含义 |
| --- | --- | --- |
| 新生结构碳 | 0.01 g C/模型个体 | 明确的出生碳到连续密度转换参数 |
| 成熟条件 | 最晚出生后 ≥20 天，平均结构质量 ≥0.10 g C/个体 | 两个条件都满足才转成体 |
| 成体结构增长参考上限 | 0.30 g C/个体 | 只限制进一步增长，不删除超过上限的现有碳 |
| 出生窗口 | 0.5 天 | 同窗口出生可合并；初始幼体队列不混入新生队列 |
| 最大摄食 | 幼体0.50、成体0.35，单位 g食物C/g结构C/天 | 乘食物饱和函数和阶段可获得倍率 |
| 食物半饱和量 | 2 g C/m² | `F/(half+F)` 中的资源尺度 |
| 同化／排出 | 0.35 / 0.20 | 摄取碳其余部分为明确的摄食呼吸输出 |
| 维持 | 幼体0.022、成体0.018 /天 | 实际需求为比例×结构碳，先由储备支付 |
| 储备动员 | 0.50 /天 | 每步动员份额 `1-exp(-rate×dt)`，不超支 |
| 结构增长产率 | 0.80 | 动员到增长的碳中80%进结构，20%为增长成本输出 |
| 成体繁殖分配／出生结构产率 | 0.70 / 0.80 | 繁殖实际耗储备；损失部分记繁殖成本输出 |
| 储备容量 | 结构碳的0.50倍 | 多余储备回碎屑，禁止无账裁剪 |
| 自然死亡 | 两阶段均0.008 /天 | 只为教学选择，不代表海鱼寿命 |
| 维持不足死亡代理 | 最大附加0.18 /天 | 乘上一步未满足维持比例，没有标定耐饥阈值 |
| 拥挤反馈 | `0.018×liveC/4` /天 | 4 g C/m²是反馈尺度，不是目标均衡值 |
| 外部食物／碎屑输入 | 0.20 / 0，g C/m²/天 | 食物输入另乘环境倍率 |
| 食物／碎屑交换 | 0.005 / 0.015 /天 | 实际导出的有机碳；没有自动补回 |
| 食物衰变到碎屑 | 0.005 /天 | 内部有机碳转移 |

完整数值及单位随 `exportData.parameters / parameterUnits` 保存。数值和比例先验证，未知键拒绝；同化加排出不能超过1，新生质量必须小于成熟质量，成熟质量不大于成体增长参考上限。支持范围用于防错误输入，不是经过验证的自然范围。

默认初值为食物4、碎屑0.5 g C/m²；幼体、成体各4个体/m²；结构质量分别0.05与0.20 g C/个体；年龄分别10与60天；储备为结构的0.20倍。初始数量和平均质量分别存储；没有根据一个生物量总数暗中猜出物种条数。

环境有 `foodInputMultiplier`（0–3）、`juvenileFoodAccessMultiplier / adultFoodAccessMultiplier`（0–2）及两个阶段的 `*HarvestPerDay`（0–1 /天）。食物可获得倍率影响同一资源池上的实际摄取，不宣称复现论文的不同生境、固定总量食物再分配实验。

## 每步发生什么

先加入真实外部食物碳，并记录资源交换和衰变；再对每队列计算背景死亡、拥挤、上一步维持缺额和阶段采收的合并风险。按同一个生存份额同时减少密度、结构和储备。自然死亡的完整身体碳入碎屑，采收的完整身体碳出边界；本版没有捕食者，因此不把采收叫捕食或重复把采收碳回碎屑。

存活队列共同申请食物，食物不足统一缩放请求；只分配实际移出的碳。同化先入储备，先支付维持后才能动员增长或繁殖。维持不够时不虚构已支付碳，缺额影响下一步死亡。本版暂未让身体结构分解支付维持。

幼体动员储备只用于生长。成体动员储备按参数分给增长和繁殖。若花费繁殖碳 `C_cost`，新生结构为 `η×C_cost`，预期出生密度为新生结构除以0.01 g C/模型个体，其余碳作为繁殖成本输出。无成人、无储备或零出生产率都不会添加新生队列；没有最低出生数或灭绝重置。

成熟在消费和生长之后判断，新生队列在步末加入，不能同一步成熟／再繁殖。成熟年龄取窗口中最晚生日保证年龄下限；仅年龄判断可比最早出生的个体保守延后最多一个窗口。窗口内采用平均体型，不能断言每一个真实幼体都达到成熟体型，也没有完整的年龄—体型联合分布。

## 科学依据及限制

原始论文与核验日期见 [实施方案](AGE_STRUCTURE_PLAN.md)。[De Roos等2008](https://pubmed.ncbi.nlm.nih.gov/18006030/) 支持把食物依赖体型增长与阶段转移连接到种群；[Lika与Nisbet2000](https://link.springer.com/article/10.1007/s002850000049) 支持维持、储备、增长与繁殖分配的收支关系。本模型不是完整 DEB 实现，也不借论文给默认速率背书。

[Reichstein等2015](https://pmc.ncbi.nlm.nih.gov/articles/PMC4366502/) 的两阶段实验表明资源分配可改变阶段响应；其对象为淡水小型胎生鱼。当前模块没有复现该实验，也没有将其数值移植成珊瑚礁鱼参数。教学生态干预后各阶段不必同向变化，批量报告按实际差值统计方向。

没有卵／胚胎池、孕期、性别配对、繁殖季、温度依赖、幼体扩散／定居、具名物种体长—碳量换算、完整食物链、分解者和营养盐循环。碎屑仅接收内部回流并与边界交换，不会在这一最小模型里重新成为食物。未来连接七池必须把死亡回流和实际同化碳逐笔接入，不能叠加两个模型的整份同化／死亡账本。

## 验证入口

`node --test tests/age-structured-experiment.test.mjs`：11项全部通过，实际运行约31秒。覆盖分步重放、质量与数量分离、成熟双门槛、实际储备付出生、空储备／灭绝、自然死亡回流、阶段采收、停食配对、5 seed逐日365天预算／队列界、半步长和半出生窗口敏感性及原子输入校验。

`node scripts/run-age-experiments.mjs`：保存5 seed、20个365模拟天场景和15个第90天干预的配对差值，以及半步长／半窗口敏感性到 `output/validation/age-experiments.json`。程序每个生态步长检查数值、年龄、碳与阶段密度账本；原始每日曲线、当前队列、全部参数和源码SHA-256随报告保留。结果与具体最大误差以该报告为准；这是直接模型模拟时间，不是实际浏览器运行365天或3D出生动画验收。

## 本次实际批量结果

种子为 `1 / 7 / 42 / 2026 / age-five`，3个干预分别是停止外部食物、幼体可获得倍率从1降至0.25、成体采收率改为0.03/天。第0–90天的完整队列／账本状态及采样历史SHA均相同，15个配对全部确认干预前一致。

| --- | --- |
| 默认场景／配对数量 | 20 / 15，另有2次数值敏感性运行 |
| 逐步检查次数 | 167900 |
| 有限且非负 | 全部运行符合 |
| 最大有机碳账本误差 | 2.69214×10⁻¹¹ g C/m² |
| 最大阶段人口平衡误差 | 1.06922×10⁻¹⁰ 预期个体/m² |

| 新生队列最早观察到的成熟年龄 | 85.6天，满足20天年龄下限；食物增长条件进一步延迟成熟 |

| 干预 | 与同 seed 基线相比，5个种子一致的方向 |
| --- | --- |
| 停止外部输入 | 两阶段第365天生物量与密度、累计出生、累计成熟、最后60天出生均较低 |
| 减少幼体可获得食物 | 幼体第365天生物量／密度较高，成体较低；累计成熟较低，累计出生及最后60天出生较高 |
| 成体采收 | 两阶段第365天生物量／密度、出生较低；累计成熟反而较高；有机碳采收输出明确增加 |

停食对照保留了已有食物和储备，因此不会在第90天立即关闭出生。seed42在第365天总预期密度约9.23×10⁻²¹ 个体/m²，接近零但没有被强制裁成零；累计账本差分的最后60天出生为0，在浮点分辨率内。不能把连续密度曲线称为若干只动物死亡后自动补齐的动画。

减少幼体供给的反直觉终态不能改写为“所有阶段都下降”。阶段竞争、储备分配和成熟滞后会改变这一教学配置的结果；累计成熟与某一天成体密度也不是同一个量。源报告包含原始曲线及两本账目，可追溯上述方向，没有调整模型强迫同向。

seed42在第365天的敏感性对照：步长从0.05减半到0.025天，总密度相对差为−0.028506%，成体生物量为+0.011342%；出生窗口从0.5减半到0.25天，相对差分别为−0.001709%和+0.003441%，队列数增长到1463。小差异仅说明这个参数配置和观察时刻对这两种离散分辨率较稳定，不是所有参数的收敛证明或野外校准。

## 工作台接口与导出范围

`src/AgeWorkbench.jsx` 通过模块 Web Worker `src/ecology/ageExperimentWorker.js` 调用同一个 `runPairedAgeExperiment` 对象接口。界面提供180、365、730个模拟天，统一在第90天干预；四个选项分别为停止外部食物输入、幼体食物可获得倍率0.5、成体食物可获得倍率0.5、成体移除风险0.02/天。后两类幅度与上面多种子科学批量报告的0.25／0.03不相同，应读取当前导出中的实际 `intervention`，不能复用旧报告的数值结论。

界面八项曲线列来自模型导出的逐日汇总：两阶段预期密度、累计出生／成熟／自然死亡密度、两阶段有机碳及食物有机碳。累计自然死亡不包含采收；采收碳有独立账目。图表横轴为模拟天，数密度为预期模型个体/m²，有机碳为g C/m²。曲线和表格均应解释为匿名教学模型的对照，不能当作三维场景的个体计数。

`output/validation/age-ui-data-smoke.json` 保存一次seed字符串`42`、四种界面选项×三种时长的12例源 worker 消息处理接口检查。所有返回请求ID、实际选项、干预前逐日曲线、8个列名、曲线行数和账本数据均通过检查。180／365／730天各有181／366／731个采样行，保留第0天。带缩进且加末尾换行的JSON最大为1,729,684字节，小于本地捕获插件的2,097,152字节上限；当前界面范围的这12例不需要截断队列或曲线才能保存。此项检查没有实际点击浏览器或上传网络请求，也不是任意种子／自定义参数的导出大小保证。

这组界面配置的实际响应同样并非全阶段同向：seed42在三个时长下，幼体食物可获得倍率减半均使幼体终态密度较高、成体较低；成体倍率减半均使幼体终态密度较低、成体较高。730天成体倍率减半时，成体密度约9.6585，对照约5.7976个体/m²，但累计出生更低。这些是曲线与账本记录的结果，不能把摄食倍率变化直接等同于阶段数量的相同比例变化，也不能仅凭终态曲线唯一归因于某一个反馈。

该接口检查在同一Node进程中逐例计算，记录每例CPU时间、前后RSS和进程峰值RSS；峰值约100.55MiB，最长一例墙钟约32.77秒。数值包含本机并行负载及跨案例垃圾回收影响，只用于识别长任务和内存量级，不能当成浏览器渲染性能或隔离的Web Worker内存测量。工作台使用worker保持界面线程可响应，关闭工作台会终止worker；进行三维性能基准时应关闭尚在计算的工作台。
