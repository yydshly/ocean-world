# 礁谷生境群落：已有动物按真实候选条件共同选择

这一阶段不增加目录条目或资产，浅海目录仍为75个代表条目，不等于75个野外物种。已有32个具名礁谷居民代表模型共用 v7 出生队列，优先改善裸沙、硬礁缘、礁脚与近礁水层的宏观动物组合；不是把32类强制放进同一个 owner 或一条路线。

## 选择规则

仅 v8 `reef-valley-region` 的十二个 owner 严格全无存档时启用，原子保存成功后公开；没有延伸到 v9 海草草甸。v7 直接运行自己的初始化，不先运行旧层级出生、不预留位置，也不嵌套预留。每 owner 使用原动物后的自然剩余空间，居民至多十条、全部动物记录至多二十条，包含死亡记录与海龟。

排序依据来自既有候选位置：实际最高支撑面、真实床面高度和法线、珊瑚冠层障碍、当地沙或岩底质，以及实际深度。先按中心点条件对软底、硬底、礁脚与水层角色交错排序；再逐个尝试出生。`habitatEvidence` 的中心数量和深度范围仅是可重算的排序证据，不能批准动物放置。场景名称、主导facies或宿主类别都不能替代实地支撑检查；水层角色也不表示已经求解水动力遮蔽或远洋生境。

真正出生仍逐个执行既有门槛：物种完整身体与附肢包络、所有真实触点、支撑坡度与高差、整形深度、珊瑚与植物净空、owner 边界和实际占位。软底动物不能因“沙区”标签而站上岩石；硬底动物不能因宿主名为岩石而落在邻近沙面；参考皮肤、肉足或管足采样仍保持各自含义。珊瑚食者还需真实近邻珊瑚，不能穿进珊瑚。角色排序不放宽物理门槛，条件不足时允许少生或某类不出现。

v7 使用独立随机盐、个体ID、元数据及食物范围。摄食仅扣除当地已有的动物、藻类、浮游、珊瑚有机或碎屑代理，保留实际扣款记录；不产生新食物，不捕杀具体可见动物，速率、密度与完整天然食谱仍未校准。既有模型只读个体时钟显示有界活动，原生控制器负责实际根移动。

## 历史与新世界

旧 v1–v6 存档不升级、不补发，死亡、库存、时钟与后续行为按旧版继续。全新 v7 的居民选择、个体ID、尺寸与出生分布会与独立旧版新生世界不同；不能把旧历史保持解释为全新世界也复刻旧配方。原地形、植物、路线和原非居民出生不因这一选择策略而重新塑形。

具体已有形态、尺寸与作者资料沿用：[两种原居民](REEF_RESIDENTS.md)、[礁谷多样性](REEF_DIVERSITY.md)、[礁谷社区](REEF_COMMUNITY.md)、[礁谷生活](REEF_LIFE.md)、[礁谷动物](REEF_FAUNA.md)、[浅礁新组合](REEF_ASSEMBLAGE.md)。本阶段没有新生物学分类或模型尺寸扩张。

## 有限核验范围

固定新种子 `?demo=reef-valley-region&seed=55`、`reef-valley-region:204,4`，实际十二 owner 共 **238条动物记录、53类目录动物**；其中 v7 居民 **79只、27类代表模型**，这27类各在主路某处进入 CPU 十四米近邻。相同种子独立 v6 基线也有79只居民、29类，因此本轮是**组成调整，不能称物种丰富度增加**，也没有保证32类全部出生。

出生后沿路线每十米采样、半径十四米的全动物近邻空站由基线7个降为6个，仍为空的路程站点为80、150、160、340、350、360米。居民十四米近邻空站数量仍为14个，70米站有新增覆盖而310米站失去覆盖。不能由一处距离证据推广为全路连续群落或画面完整可见。新55实际有3只集物海胆，入口最近9.06米；既有54没有海胆的历史结果保持，不补发，也不代表所有种子都会有海胆。

三个普通九区窗口合计 **9模型秒**：79只居民中75只实际移动、74只摄食并扣除当地已有库存。三只夜行龙虾均为休息状态，0移动、0摄食；唯一蝙蝠鱼0移动、1摄食；狮子鱼2移动、1摄食，镰鱼3移动、2摄食。这些未移动或未摄食结果保留，不能把模型存在视为所有动物均在活动。食物来自五个现有代理库存：`reefGuild.preyOrganicUnits`、`resources.algae`、`resources.plankton`、`basicNetwork.coralOrganicUnits`、`resources.detritus`。

四个原生生态case首轮通过：完整活区和磁盘冷恢复相等，原非居民出生与地形相等，旧 v6 完整死亡、资源、时钟和后续输出保持；旧 v1–v6 全部32步完整记录的冻结输出也保持相等。原子保存失败不公开，混合版本、伪造候选顺序或生境证据、错误食物和穿底记录拒绝再生。原生证据与检查计数见[本批冻结收据](../output/validation/reef-habitat-community-delivery.json)中的 `native` 和 `logs`。

另一次独立完整生产入口首窗1秒：全活区121个动物移动、42个摄食，居民46个移动、12个摄食；包含目标十二 owner 以外的活区，不与上述九秒结果累加。详情见[冻结收据](../output/validation/reef-habitat-community-delivery.json)中的 `productionEntry`。

本批72个唯一定向检查成功：原生4、v7控制器8、旧控制器48、世界接入9、显示接入3。显示接入初轮只有入口种子namespace fixture错误，修正该case后单独复验，另两项显示case成功结果复用，生产未为fixture改动；初轮失败日志保留。生产构建6.12秒通过，本地结果见[冻结收据](../output/validation/reef-habitat-community-delivery.json)；线上完整检查与发布状态以新提交的Actions运行结果为准。

CPU 几何、沿路距离和运动证据不等于 GPU 镜头可见度、遮挡、整体观感或帧率验收。食物代理也不等于已经构建完整自然生态循环、繁殖、迁移或离线演化。
