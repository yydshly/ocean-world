## 海洋扩展的六个维度

| 维度 | 扩展内容 | 组织原则 |
| --- | --- | --- |
| 空间与栖息地 | 沙滩、潮间带、浪区、浅海、开阔海域、中层水体、深海海床 | 地形、水深、底质和邻接关系共同决定场景 |
| 天气海况与昼夜 | 晴天、阴天、黄昏，后续增加海雾、降雨及较强风浪 | 天空、光照、海面和水下表现联动；按深度区别影响 |
| 物种与个体 | 分类身份、实际尺寸、形态、年龄阶段及活动水层 | 生物按适合的海域与栖息地出现，避免以数量替代合理性 |
| 行为与轨迹 | 巡游、停留、摄食、避障、受扰、呼吸和群体运动 | 动作与位置、速度、环境及内部状态相互对应 |
| 群落与生态 | 群体协调、捕食与躲避、资源利用、庇护空间 | 先做可观察的小范围联系，再增加生态复杂度 |
| 观察与讲解 | 岸上远望、贴近海面、潜水、观察器、自由探索和专题解释 | 先让观众看见，再解释眼前现象及其原因 |

画风继续保持纪录片式写实。热带、温带岩岸、开阔大洋和深海可以有不同气质，但材质、比例、运动和光照需要采用一致的呈现规则。

## 从沙滩到深海的空间组织

主线可以逐步扩展为：

**海岸与潮间带 → 浪区与入水 → 浅海栖息地 → 开阔水域 → 中层水体 → 深海海床**

每一段都需要可辨认的空间结构、代表性生命和到达下一段的理由。自然相邻的环境可以连续行进；跨海域或长距离转移使用明确的航行、换乘或时间压缩说明。

| 场景 | 首先补齐的整体特征 | 观众应该看懂的内容 |
| --- | --- | --- |
| 海岸与潮间带 | 沙滩或岩岸、潮线、岸边浪、陆海尺度关系 | 海岸受海水周期性影响，岸上与水下有联系 |
| 入水与浪区 | 水线、透视、折射、近岸底质、由空气进入水体的视听变化 | 海面只是边界，下方仍有立体空间 |
| 浅海 | 活礁结构、沙道、草床及上下远近的动物群落 | 不同底质和庇护空间支撑不同动物生活 |
| 开阔水域 | 大尺度水体、远近参照、不同水层的移动动物 | 大海并非每处都铺满珊瑚，动物也生活在水柱中 |
| 中层水体 | 光照减弱、稀疏海雪、适合深度的动物 | 离开浅海后，光照和食物条件发生变化 |
| 深海海床 | 无太阳光的环境、观察灯、软泥或岩缘及贴底群落 | 深海仍有生命，主要生活条件与浅海不同 |

| 中层水体 | 沿用总览及研究模块扩展 | 光照梯度、开放立体空间、适深动物与海雪 |

| 水下洞穴 | 条件候选 | 入口、遮蔽、壁面、净空与特定栖息地群落 |

| 热液区 | 条件候选 | 独立的地质和环境条件、资料支持的群落与观察说明 |
| 冷泉区 | 条件候选 | 独立的底质、环境与群落，避免复用热液场景解释 |

“条件候选”需要先获得足够的地形、物种和环境依据，以及允许使用与再分发的素材。河口、红树林、潮沟与外海岛岸也可按需要另设专题，避免为了列举丰富而在同一阶段扩展所有空间。

持续探索需要让新区域按位置、种子和区域规则生成，保持返回时的地形与历史一致。活动范围可以随探索继续扩展，实际运行只保留必要的邻近区域；卸载区域不能清空原动物、资源或生态记录。

物种共现、密度和生态联系按具体海域与生境检查。分类范围或水深范围重叠只能作为候选条件，不能单独证明它们在同一调查站点共同出现。

## 天气海况与昼夜

第一批可以在同一段海岸形成晴天、阴天、黄昏三个完整状态，让观众直接比较同一片海的变化。后续再按需要增加雾、雨、强风浪和月夜，每次只扩展一个可验收的环境组合。

环境配置需要包含天空、太阳或月亮位置、云量、风、波浪、浪花、海面反射与可见距离。水下光照、水色和近岸浑浊由各自有依据的环境参数控制，不能仅用全屏换色表示天气。

潮汐、涌浪、局部海流和风浪应有独立状态。海面变化不应让深海海床瞬间获得同样的亮度、摇摆或浪花；天气与水深的关系先做清楚的有限表现，再考虑更严格的物理模型。

## 整体真实感的分层标准

真实感先从整段体验判断，再确定需要处理的主要问题。高精细模型与更多装饰不能单独解决空间单一、动物无生活联系或转场突兀。

| 层次 | 验收内容 | 结果如何说明 |
| --- | --- | --- |
| 视觉与空间 | 地形自然、比例可信、水体有尺度，主体与远景协调 | 使用完整实景和连续片段说明改善及剩余差距 |
| 运动与形态 | 身体与推进联动、动作范围合理，全身接触与净空可信 | 保留完整身体和真实运动检查，避免靠裁切或隐藏解决 |
| 生境与生态 | 出现地点、活动水层、共现及行为原因有依据 | 区分具名物种、属或科代理、作者编排和实际事件 |
| 科学校准 | 模型在明确条件下与测量资料比较 | 记录资料范围、单位、误差与适用条件，不从外观推断校准完成 |

## 物种行为与运动轨迹

### 按栖息地补齐物种层次

物种丰富度应按生活空间形成群落：附着动物与植物、近底居民、草间或洞隙居民、中层鱼群、开放水域访客、大型动物，以及深海软底、硬底和水层代表。先确定海域、底质、水深、分类层级与活动范围，再选择对应动物，不能把模型目录总数当作同一场景的真实共现或野外密度。

每批可以围绕一个栖息地增加一组主角和配套群落，同时补齐尺寸、形态、身份、许可、活动水层及行为解释。例如为已有礁谷补完整的避障和庇护联系，为草床补草间居民与水层访客的空间关系，为深海补软底、附着和离底活动的不同生活层，而不只在空处增加数量。

### 区分三种轨迹用途

轨迹需要区分三种用途，并在界面和资料中说明：

| 用途 | 轨迹如何产生 | 合适的交付方式 |
| --- | --- | --- |
| 导览展示 | 作者安排观察重点，动物在有限行为模型内响应 | 可复播、可选章的完整片段 |
| 实时互动 | 动物根据邻居、地形、资源、刺激及自身状态作出决策 | 可操作、可保存的有限栖息地 |
| 观测数据回放 | 使用有许可和测量信息的实际记录 | 明确数据来源、采样间隔、范围和误差的回放 |

持续模拟首先统一个体的位置、速度、朝向、活动水层和行为状态，再让鳍、尾、身体及呼吸动作响应这些状态。转弯、滑行和停留需要对应实际路径，避免只让模型沿轨迹平移。

轨迹范围可以逐步从局部巡游、停留、避障与受扰，扩展到群体交会、庇护与摄食，再选择物种资料支持的昼夜垂直运动或季节迁移。长时间尺度行为需要明确海域、时钟、观测依据和迁移目的，不能通过循环路径或重新生成个体声明自然迁移已经实现。

鱼群扩展可以依次加入不同速度和密度、多群体交会、动态障碍、持续局部刺激，以及恢复后的队形变化。每一阶段观察分流原因、邻居响应、全身净空和群体重新组织；仅使用聚群、分离与对齐规则不能证明物种行为已经得到科学校准。

捕食与摄食需要实际的目标、接近过程、可达性、资源变化和结果状态。生态讲解应对应已经发生的事件，景观痕迹、预设姿态或字幕不能被计作真实摄入、死亡、繁殖或资源补充。

## 后续重构的模块边界

后续重构可以围绕以下八层逐步进行。每层先为一个完整片段服务，再迁入其它能力，避免一次重写所有世界模块。

| 模块 | 负责的内容 | 与其它模块的边界 |
| --- | --- | --- |
| 场景与环境配置 | 海域、栖息地、地形、天气、海况、昼夜和水体参数 | 提供空间与环境条件，不直接生成生态结果 |
| 资产与物种目录 | 分类层级、形态、尺寸轴、许可、活动环境与资产版本 | 生物规则与具体模型分开，替换资产不改变个体身份 |
| 实体状态 | 个体身份、位置、速度、年龄或阶段、行为及必要生理状态 | 用同一状态供显示、决策、记录和恢复 |
| 轨迹与决策 | 导览路径、物种运动约束、目标选择、避障和姿态联动 | 镜头路径与动物决策分开；展示编排明确标记 |
| 群体与生态关系 | 邻居协调、刺激传播、资源、摄食和捕食关系 | 事件有原因与结果，有限演示不冒充完整食物网 |
| 流式世界与保存 | 按需加载、区域所有权、随机序列、时间、历史与恢复 | 区域显示变化不能重生种群或跳过历史校验 |
| 呈现镜头与旁白 | 相机、观察器、光照、字幕、语音和专题导览 | 从实际状态提取观察重点，不写入或伪造生态事件 |
| 应用层 | 科普导览、探索、摄影、任务、沙盒和内容输出 | 应用复用底座，并各自定义交互、规则及验收 |

开始重构前固定现有版本、入口、来源说明和验证结果。新模块先在独立入口中验证，迁入时保留兼容层和可恢复基线；总览进度、模拟时间与保存时间分别处理。

旧记录中的个体身份、死亡、资源、随机序列和时钟应保留原含义。恢复失败时停止推进、说明原因并允许导出原记录；不能通过清空、补种、忽略不一致或放宽物理校验把错误变成“恢复成功”。需要迁移时另设明确范围，验证迁移前后状态及后续未来一致。

## 阶段交付与验收

后续优先级可以按以下顺序组织，具体范围在每阶段开始时确认。

| 候选阶段 | 有限交付目标 | 核心验收 |
| --- | --- | --- |
| 海岸入水 | 一段90–120秒的海岸、浪区和浅水体验，接入既有浅海 | 空间连续，入水变化清楚，原浅海入口和记录保持 |
| 环境变化 | 同一海岸的晴天、阴天和黄昏三个完整状态 | 天空、海面及浅水光照一致，切换和加载流畅 |
| 栖息地互动 | 一个完整浅海栖息地、一组主鱼群、两三种可观察互动 | 行为原因与结果可读，动物不明显穿模，状态可解释 |
| 海洋范围扩展 | 选择一种新海域或深度环境，补齐结构与代表性群落 | 场景特征明确，海域和共现关系合理，过渡可理解 |
| 应用试验 | 选择一种观察或游戏玩法，形成完整目标与结果 | 用户能完成任务、保存进度并理解反馈 |

每阶段先确定整体目标、入口、时长或活动范围、目标设备及完成条件，再成批实现。整体审查后集中修正一轮，完整验证、展示效果并归档；未达标则记录主要瓶颈，作为下一次是否继续的依据。

验收分别记录四项结果：画面与空间是否自然，动物与环境联系是否合理，加载及持续播放是否可用，首次观众是否看懂。构建、检查数量、配置物种数量和平均帧率不能替代这四项结果。

性能目标按设备、分辨率、冷或缓存加载、网络条件和场景规模记录。新阶段必须说明是否维持已有体验，不能用降画质、缩小视口、减少动物或更换测量条件而不披露的方式声明性能提升。

## 游戏与其它应用方向

同一海洋底座可以服务科普、游戏和内容制作。游戏需要额外形成用户行动、规则、目标、反馈和可保存结果；现有导览还不能视为完整游戏。

| 方向 | 可复用的底座 | 需要新增的能力 |
| --- | --- | --- |
| 潜水探索 | 海域、栖息地、动物、水体和观察镜头 | 自由移动与碰撞、装备或行动规则、目标地点、进度保存 |
| 物种观察与摄影 | 分类资料、动物状态、镜头和截图 | 识别与观察条件、图鉴、照片记录及明确评价规则 |
| 科普任务 | 场景、旁白、字幕和生态事件 | 问题、互动、解释与反馈；检验用户是否理解 |
| 生态沙盒 | 有限实时行为、资源及区域保存 | 可控实验条件、状态可视化、重放和对比；区分模型与真实结论 |
| 导演与内容制作 | 章节、镜头、语音和场景配置 | 镜头编辑、可复现拍摄配置、导出、字幕与来源信息 |
| 可复用海洋资源 | 环境、物种目录、轨迹和呈现模块 | 稳定接口、版本、示例、资源预算及逐项许可说明 |

先选择一个应用试验更容易验证价值。例如在一个既有浅海栖息地完成“找到三类动物、观察一次鱼群受扰、拍摄并保存结果”，可以复用既有素材，又能检验探索、行为、讲解和保存是否形成完整体验。

商业化应用、教育资源包和公开导出需要保留逐项来源与原许可。已有素材包含CC0、CC BY、CC BY-NC及CC BY-NC-SA；免费且允许按条件再分发不等于所有素材都可商用。商用游戏应先审查涉及的资产及组合，按条件取得许可或替换受限素材，不能因代码或新增原创模块使用不同许可而消除原条件。

许可依据：[CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/)的非商业条件、[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)的署名与改作共享条件；具体以各资产来源及其许可版本为准。
