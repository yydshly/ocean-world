# 热带礁谷海区

本阶段把已有浅海元素与实际持久生命组织成整片连续海区。它是宏观场景交付，未新增具名物种，也不代表完整海洋模拟或纪录片画面已经验收。

## 探索与导演

- 自由探索：`?demo=reef-valley-region`，使用热带浅海原生生态、普通九区活跃窗口与五乘五公开支撑窗口。
- 导演：`?demo=director`，第一章沿204,4、210,4、216,4、222,4四片相邻已提交海区逐段移动，每片200秒，总计800秒。支持已有0.5×、1×、1.5×、2×、4×速度和暂停；加载停镜头、停观察时钟。
- 新海区按坐标与种子生成。6×2个64米owner共享384×128米组成，固定的1.696公里路段是本轮验收样本，不是世界边界。中部既有示范区域维持旧版，新的宏区在对齐cx≥204或cx≤−12范围自然准入。
- 相邻区域共享真实世界坐标端口。导演只读取已经持久提交且公开就绪的当前区域路径，逐步取得下一片，避免提前曝光未来地形或生物。旧历史或实际物理条件无法接续时如实停下，允许自由探索，不跳换另一个锚点。

## 场景内容

四片固定相邻海区的实际主线约1695.667米，8条沙沟分叉可走通并接回主线。新增29处具有实际网格与支撑的大礁墙／台地岩体、57簇岩面珊瑚和1953簇海草，另含藻斑、碎石与少量落底木料／进水瓶。数字只计实际通过物理与预算检查的新增实例；不把资产数量当作观感验收。

礁群—裸沙—草床—外坡使用连续世界坐标组成。新增大岩体使用原有不规则网格，珊瑚与藻斑根附着真实宿主岩面，草根接实际软海床。保留原生附着支撑、法线和外侧16米旧床面带，路径与分叉检查真实一米身体通行带及相机净空。植物是持久景观，还没有生物量、光合与增长模型。

生命复用原有原生鱼、礁群、水层游弋、底栖、草缘及群游类别，按当地支撑、完整身体净空和每区自然余量决定组合。每条动物独立保存、移动、摄食与记账。没有强制补齐海龟或任何目录物种，也不将空类别反复补货。实际出现的种类与数量以原生模型收据为准。

## 历史与边界

整组12个owner严格返回null才可出生，新地形和全部生命先一次原子保存，再公开当前窗口。undefined、读错、保存失败、缺组、损坏组或任何旧记录都不能冒充未访问海域。旧v1–v7存档不迁移为v8，不重置时钟、死亡、RNG或食物账。

保持9个活区、25个公开来源、每区20条全部动物记录（含死亡）。完整历史私有预读上限97个owner，覆盖最多6组完整12区加当前25区并去重；它不扩大渲染或生态活区。规范生成模型缓存最多6组；只缓存不可变预期模型与预期签名，外部可变存档每次仍完整比较并做原生历史校验。

## 验证与当前局限

几何检查覆盖四片实际海区、真实共享端口、8条分叉、一米通行净空、原有宿主支撑与预算。原生Three CPU检查覆盖48份海床网格、70条组内及跨组接缝，并在主线每60米采样记录完整源包围盒与相交源包围盒；动物覆盖由原生World专项记录。包围盒数据不能证明遮挡、光照、GPU画面或观看体验。

生态检查包括普通窗口生成、跨区保存、冷恢复、死亡和空类别不补、失败与损坏历史隔离、食物收支、时钟与加载耗时。World与入口检查包括实际四片连续运动、加载保持、暂停与变速、手动接管及异步取消。

发布结果写入 `output/validation/reef-valley-region-delivery.json`；最终本机与云端执行同一工作流检查清单，数量不相加。初始诊断保留，不能冒充最终通过。

整体浏览器/GPU效果仍未验收。当前不是全物种普查、完整自然食物网、真实水动力或跨所有气候海域的地理模型。后续先以整片生境与可见群落差异为单位扩展：海草床根际与植物层次、巨藻林宏区、深海垂向水层；再推进真实生态过程。每个有限阶段交付普通探索、持久恢复与移动观察，不进入无尽单体细调。
