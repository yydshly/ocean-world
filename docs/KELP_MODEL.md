# 独立海带林模型

实现文件：`src/kelpSimulation.js`、`src/kelpHabitat.js`，渲染接入 `src/world/kelpOrganisms.js` 与 `src/world/ReefWorld.js`。研究目录取自 `src/biomes.js` 的 `kelp-forest`。海带林与浅热带珊瑚礁分别实例化自己的模型、目录、地形和镜位。自然史来源和六个候选的尺寸依据见 `BIOMES.md`；没有测量校准的速率在本文件明确记录。

## 接口与单位

`new KelpSimulation(seed)`、`reset(seed)`、`setEnvironment(patch)`、`step(simSeconds)` 与浅礁的调用方式一致。`step` 接收模拟秒，单次最多 86400 秒；固定生态步长为 0.1 秒，保留不足一个步长的余量。同一 seed、环境改变序列及总模拟时长，在不同渲染帧批次下得到完全相同的状态。`reset` 还会恢复默认环境、资源和事件。

`agents` 使用标准 `id / speciesId / position / velocity / heading / sizeM / energy / state / alive` 字段，还提供 `lastFeedAt`、`stateSince`、`hunger` 和 `stress`。位置及尺寸是米，速度是米/秒，`heading` 是水平弧度，时间戳是模拟秒。植物和底面动物的 `position` 是支持面原点，渲染模型应以接触点为原点；鱼使用身体中心。`energy` 是 0.02–1 的相对状态代理，不是焦耳。未建立真实耐饥、繁殖或死亡模型，因此不会以几分钟的演示耗能判定真实死亡；`alive` 保留为兼容字段。

环境接口仅接收下列四个有限数值，并先验证整个 patch，再修改状态。未知键、非数值和数组会被拒绝；前三项截断到范围，`hour` 按 24 小时取模。

| 参数 | 初值 | 可操作范围 | 当前含义与限制 |
| --- | --- | --- | --- |
| `currentMps` | 0.18 m/s | 0–1.2 m/s | 沿 x 的流速控制；改变藻柄形变、鱼的残余漂移及维持位置成本，未解流体动力学 |
| `turbidity` | 0.35 | 0–1 | 相对浑浊指数，没有标定 NTU 或颗粒浓度；影响视觉与光合代理 |
| `foodSupply` | 1 | 0–3 | 外部小型动物食物和有机材料输入倍率，先加入局部资源，不直接加体能 |
| `hour` | 10 | 0–24，循环 | 模拟时刻；随 `step` 的秒数推进，没有隐藏时间倍率 |

`environment.deformationCurrentMps` 是内部形变响应字段，不是第五个用户控制项。它从 0.18 m/s 开始，在固定 0.1 秒模型步长上以 4 秒时间常数指数接近 `currentMps`（4 秒约完成 63% 响应），仅供共享藻柄和叶片显示曲线。4 秒未经过组织力学或现场校准。流动成本、鱼的残余漂移和水体交换仍使用用户设定的目标水流。

## 六类机制

初始化含 12 个巨藻代表藻体、8 个紫海胆、5 个胶靴石鳖、5 个蝙蝠海星、12 个褐色钟螺和 4 条巨型海藻鱼，共 46 个显示单位。数量是开发选择。每个巨藻单位共用一个固定根部，绘制 4 根代表性叶柄、每柄 54 个代表叶位；没有因此把生态植物数变成 48，也没有按绘制叶片数扩大资源或光合输入。钟螺和当前局部资源附着于默认第 0 根叶柄。

| 生物 | 位置约束 | 实际取食与状态 |
| --- | --- | --- |
| 巨藻 | 根部固定在共享岩面锚点；`velocity=0`，柔柄通过共享函数摆动 | 光合进入 `kelpTissue` 代理池；藻柄延伸单独按模拟天计算，少量脱落转入局部有机材料 |
| 紫海胆 | 仅在初始化的连通岩面慢爬，不由水流平移 | 接近本岩面的 `algae` 斑块后刮食；食物耗尽则在同一支持面寻找 |
| 胶靴石鳖 | 同样贴在所属岩面，速度比海胆更低 | 本地附着藻代理供能，夜间活动较强；未完整区分红藻等自然食物，活动比例未校准 |
| 蝙蝠海星 | 林底面慢爬，遇高度场断边不会瞬移跳上岩石 | 接近本地 `detritus` 斑块后摄食，作为可食有机材料与清道夫功能的简化；不是把自然杂食者定为纯沉积摄食者 |
| 褐色钟螺 | `attachment.hostId / leafIndex / along` 固定到冠层叶面；随藻柄和叶片运动 | 小尺度沿叶爬向局部 `biofilm`，实际移出食物后才记摄食；该池不是本种完整自然食谱 |
| 巨型海藻鱼 | 藻间悬停，维持与海床的身体间隙；分散个体，不使用群游规则 | 在视距内发现近藻柄的 `smallPrey` 功能池后接近并摄食；强流且状态降低时转入局部庇护；这是一条未校准的行为规则 |

`smallPrey` 包含模型功能性小型动物食物，未新增具名猎物物种，也未模拟完整猎物繁殖和捕食链。所有摄食须接近对应斑块。`lastFeedAt` 只在移出正量食物时更新，没有资源的行为动作不会伪造摄食。

## 共享空间与附叶同步

`kelpHabitat.js` 导出 `KELP_ROCKS`、`KELP_ANCHORS`、`KELP_SURFACE_Y`、`KELP_FROND_COUNT`、`KELP_LEAF_COUNT`、`KELP_MORPHOLOGY`，以及 `floorHeight`、`habitatHeight`、`rockSurfaceHeight`、`habitatNormal`。

- 场域 x 为 -9–9 m，z 为 -8–8 m。水面 y=12 m，砂质底面约 y=-0.16 m；局部水深须用水面减支持面高程，不能读成相机高度。
- 岩表采用 `[cx, cy, cz, sx, sy, sz]` 椭球参数，支持面与渲染应读取同一表。高度场边界不是完整可爬网格，模型禁止底面动物跨越突变或离开所属岩面。`supportNormal` 和 `habitatNormal` 可用于让渲染腹面贴合坡度。
- 锚点为 `{id,x,y,z,lengthM,phase,rockIndex}`。`getKelpAnchor(giantKelpAgent.id)` 返回当前生长长度；原始表保持不变。`kelpStipePosition(anchor,fraction,timeSec,environment,frondIndex=0)` 返回世界米坐标，所有叶柄的 `fraction=0` 恰为同一固定根部。另三柄有不同扇形偏移和 0.982/0.96/0.94 的显示长度比例，顶端保持水面以下；比例与扇形都是展示参数。
- 每柄共 54 个代表叶位，用 `kelpLeafFraction(i)` 读取位置。其余叶位的非均匀网格为 `0.12 + 0.865*(1-(1-i/53)^2.65)`，从根部向冠层逐渐密集。已有钟螺叶 ID 12/15/17 保留旧冠层 fraction 0.7753/0.8741/0.9400，叶 ID 因此不等同于高度排序。不得在模型或渲染中另算旧的 `i/17`。
- `kelpLeafLength(i)` 名义叶基至尖距离为 0.45–0.70 m；`kelpLeafWidth(i)` 为 0.075–0.105 m。`kelpLeafPosition(anchor,leafIndex,along,timeSec,environment,frondIndex=0)` 返回共同叶中线世界坐标，along=0–1 表示叶基到尖。流动方向先归一化，不因沿流偏移拉长或压缩叶尖距离；弯曲中线弧长略长，t=10 秒、12 锚点×4 柄×54 叶×四种水流的抽查为 0.451–0.742 m。该抽查不是自然测量或全时间证明。
- `leafAttachmentPosition(anchor,attachment,timeSec,environment)` 在同一中线上加 0.003 m 接触间隙。渲染钟螺时必须使用模型提供的位置，渲染叶面时必须使用相同 host、模拟时钟及环境；禁止另起动画时钟或独立弯曲曲线。
- `kelpLeafNormal` 提供同一中线的上表面法向，世界用它贴合附叶钟螺腹面；地面动物使用共享坡面法向。巨藻几何直接使用米制尺寸，root scale=1；动物网格按 `sizeM` 缩放，钟螺世界挂点不会二次缩放。

藻柄相位、0.43/0.31 s⁻¹ 摆动角频率、0.67 s⁻¹ 叶片角频率、偏移和弯曲都是展示参数。共享函数优先读取 `deformationCurrentMps`，外部若没有该字段则回退到 `currentMps`；因此强流输入在模型运行中经过上述 4 秒响应。没有真实组织惯性、断裂或脱落力学。附叶钟螺的世界速度包含随叶片的被动运动，不能把它全部解释为腹足爬行速度。

## 林冠形态证据与展示边界

2026-10-03 核验： [FAO 的 North 巨藻形态综述](https://www.fao.org/4/x5819e/x5819e0a.htm) 描述同一根部的多柄结构，成熟单柄可有 100–200 片以上叶片，到达水面后继续延伸林冠。 [Reed 等 2009 年南加州原始研究](https://link.springer.com/article/10.1007/s00227-009-1238-6) 说明叶片节点间距向水面逐渐减小。因此 4 柄×54 叶是为实时展示选取的结构抽样，不是完整成人株、真实密度或精确节间距；当前扇形冠层仍在水面下，不声称复现完整漂浮表层冠盖。

[Leal 等 2021 年原始研究](https://sembrandoelmar.cl/web/wp-content/uploads/2021/09/PAPER-FENOLOGIA-REPRODUCTIVA-MACROCYSTIS-PABLO-2021.pdf) 在南新西兰四个站点记录营养叶长 39–93 cm、宽 4.6–12 cm，气囊长 3.2–6.3 cm、宽 1.1–2 cm（正文第 9 页及图 12）。当前气囊取长 0.032–0.062 m、宽 0.011–0.020 m，实例球体缩放使用半尺寸，避免把研究直径误作半径。研究地区与 Monterey 不同，参数只作跨区域形态范围参考，不能标作本场实测；柄半径 0.005 m、叶片倾斜和波动也未校准。`KELP_MORPHOLOGY.measuredAtSite=false` 保留在截图 metadata。

## 光照、生长和速率

太阳光代理为 `max(0, sin((hour-6)*π/12)) * exp(-2.2*turbidity)`；夜间为零。视距代理为 `11*exp(-2.3*turbidity)+0.8` 米。林下光采用高度比例 `0.20+0.80*clamp(y/12,0,1)`，是冠层遮光的粗略代理，没有计算每片叶的光线遮挡，也没有基于光谱和营养盐计算生产。

| 项目 | 实际实现参数 | 校准状态 |
| --- | --- | --- |
| 巨藻显示延伸 | 0.06 m/模拟天，再乘光照与相对状态；`dt/86400` 换算 | 未校准，不是对巨藻真实生长速度的断言 |
| 紫海胆、海星、石鳖主动爬行 | 0.0006、0.0008、0.0004 m/s | 未校准，摄食时降为 10% |
| 钟螺主动沿叶爬行 | 0.00015 m/s，经叶长换算 along 改变量 | 未校准；另有叶片被动位移 |
| 海藻鱼接近/悬停 | 0.065 / 0.025 m/s | 未校准；残余流动为 current 的 1.8%，庇护为 0.6% |
| 岩面藻 / 叶面食物 / 巨藻组织输入 | 每斑块上限趋势 0.20 / 0.08 / 0.24 相对单位/模拟天，乘光照及容量代理 | 未校准，不是碳通量 |
| 外部小型动物食物 / 有机材料输入 | 每斑块 0.00005 / 0.000004 相对单位/秒，再乘 foodSupply | 未校准，开放区域的外部供给代理 |
| 海胆和石鳖摄食 | 每 8 秒最多 0.0009 相对单位 | 未校准，要求本地食物存在 |
| 海星 / 钟螺 / 鱼摄食 | 每 12 / 10 / 15 秒最多 0.0012 / 0.00018 / 0.003 相对单位 | 未校准，要求到达食物附近 |

五分钟内每株巨藻最多增加 `0.06*300/86400 ≈ 0.000208 m`，不会凭空生成新藻柄或完整森林。温度、盐度、溶氧、营养盐、真实流场和生态参数仍未校准。林退化、海胆荒漠、风暴、补充和种群增长尚未实现。

## 资源账本与事件

初始化相对资源总量为 8.492：岩面藻 1.53、叶面食物 1.26、有机材料 1.214、小型动物食物 0.288、巨藻组织 4.2。`resources` 是各局部斑块的汇总快照；修改返回对象不会修改实际食物池。测试若有意编辑局部斑块，应同时重建 `ledger.initial`，避免把测试输入漏记。

`ledger` 记录 `initial / input / ingested / exported`。脱落和内部转移只改变资源所在池；光合与外部供给计入 input；实际摄食计入 ingested；离开展示区域计入 exported。`resourceBudgetError` 检查如下数值关系：

`剩余相对资源 = initial + input - ingested - exported`

这仅证明程序中五个资源池的加减一致，不能称为生态能量、质量或碳守恒。相对体能未并入同一守恒单位，摄食后的真实代谢、排泄、分解、繁殖和营养回路没有完全建立。事件含模拟时间、类型、可读标签和因果说明；保留最近 60 条。初始、环境改变、首次资源支持的摄食，以及每 30 秒的资源说明分别留有记录。

`metrics` 提供可见度、太阳与林下光、资源汇总、行为及物种计数、光合输入、体能代理、巨藻延伸、流动成本和账本误差。行为计数记录当前状态，`grazingCount / approachCount` 等记录状态进入次数，不是已发生的所有摄食量。

## 已运行验证

命令：`node --test tests/kelp-simulation.test.mjs`。10 项通过，涵盖固定种子及帧批次重放、时钟余数和输入原子验证、岩面与叶面附着、强流、浑浊、外部供给、远处食物不能供能、多个 seed 的有限与边界状态、资源账本、夜间及分钟尺度生长限制。该验证只证明当前模型规则和数值执行，不代替真实海带林的现场校准或画面验收。

自然史边界参考 [NOAA 海带林](https://montereybay.noaa.gov/science/characterization/kelp-forests.html)、[NOAA 光与营养条件](https://oceanservice.noaa.gov/facts/kelp.html)；形态与物种食性见 `BIOMES.md` 的 Monterey Bay Aquarium 六个物种条目。
