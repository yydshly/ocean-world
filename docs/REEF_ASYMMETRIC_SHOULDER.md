# 不等断面外肩：一次有界几何修订

本轮针对实际 07:19 广角图中的统一圆肩、斜坡底座与整圈转换带。中心保护区之外的上表面改为由既有足迹边界限定的不等倾斜断裂面，加一个偏置浅鞍部；固定的径向 `1-r^4` 坡面与 `.38→.58` 转换带已移除。新的 quintic 过渡从 canonical 半径 `.38` 开始，结束半径随方向与岩石变化，范围约 `.70–.92`。倾斜面之间保留断面折线；不能把整片地形描述为全局 C2 曲面。

几何仍用共享的米制高度场。公共足迹 API、XZ 映射、20 次二分逆映射、下壳、桥盖和辅助石原形不变。主礁岩 `r<=.38` 仍提前返回原始上表面，48 个既有珊瑚根位点与尺寸、rock5 中心扫描冠部保持。`reefTerrain.js` 沿用既有网格采样、共享上下映射和缝法线处理。

辅助硬底的唯一追加范围是 `habitatHeight`：导入 root 新增的 `reefScenery.js`，将原本已经渲染的 19 块辅助石加入共享地形高度。它们不是新增生态物种、个体或生物量。此项会改变动物的高度、位点或轨迹，旧版长期生态实验不能直接用于当前版本。

不可覆盖的新证据见 [reef-asymmetric-shoulder-v1.json](../output/validation/reef-asymmetric-shoulder-v1.json)，SHA-256 为 `643ac823b1e72fca87c57d71f807b531a9f6c5e37b08b56b0bf520d5887c454e`。报告绑定的 `habitat.js` SHA-256 为 `bc5fdbb2c2dc7c26f19496887ec5d55e060375ba21b7952dba5ce5a02a7751cf`，运行前后相同。

旧版基线源码保存为 [reef-fractured-habitat-v1.mjs](../output/validation/sources/reef-fractured-habitat-v1.mjs)。它的字节 SHA-256 精确等于历史 [fractured 检查报告](../output/validation/reef-fractured-terrain-inspection-v1.json) 的 `1a0effc90b1f896ef4c79342d5627baa7458e678861f2010057600c45fe83cb6`。本轮不是通过复制新实现公式来推断保留效果。
