# 深海软底群落续包

本有限续包增加四类东北太平洋深海泥底代表，使用原生生成地形、原有有限食物库存和已有探索、观察、存档入口。四类不保证在每一区域同时出现，也不把参考深度重叠解释成3500米同地共现调查。

| 代表 | 身份与显示度量 | 本版营养组件 |
| --- | --- | --- |
| 深渊长臂蛇尾 | Ophiosphalma glabrum，物种；全臂跨距10–18厘米 | 原有表面有机碎屑，仅代表机会型杂食中的部分 |
| 深海金字塔海胆 | Echinocrepis rostrata，物种；壳体前后长4.5–7.5厘米 | 原有表面有机碎屑；没有完整微生物、肠道过程 |
| 深海肠鳃类 | Tergivelum spp.，属代表；体长12–24厘米 | 原有表面有机碎屑；没有模拟真实排泄痕迹及离底漂移 |
| 深海端足类 | Eurythenes spp.，属代表；体长4–7.5厘米 | 原有底栖动物营养代理；没有制造腐肉或杀死已渲染猎物 |

尺寸是展示选择，不是已测当地尺寸区间；蛇尾盘径不等于完整臂跨距，海胆短棘和管足不算进壳长。显示准入深度为3400–3600米，各来源自然范围、分类层级及形态参照分别保存于[物种目录](../src/deepBenthicLifeSpecies.js)和[来源说明](DEEP_BENTHIC_LIFE_SOURCES.md)。两类属代表不能标成已确定物种。

## 原生生境与身体支撑

新动物只在实际原生泥底及合适深度出生。根部、旋转后的完整脚底半径、臂、棘、吻部、足与上部体积使用原来的Float32地形查询；岩石、混合底质、过陡或无法容纳身体的地点拒绝准入。新渲染对象沿原生支撑法线定向，前三类深海动物及海蜘蛛保留原来的支撑和几何约定。

独立的种子、坐标哈希提供稀疏配置，不使用或改变原模拟随机状态。优先选择可接近原有食物点的生境，受阻时在本区有限范围安全探寻。转向和每一步的沿途参考同时检查完整身体及原有活动物包络；完整跨距不能当作口部取食半径。有限参考不构成刚体求解或全局成对碰撞证明：原有动物控制器仍可能走近新动物。

## 时钟、摄入与两个库存层次

新群落仅在本区真实模拟时钟前进0.1秒后更新一次。重复、跳过或非0.1秒调用不能增加活动、食物或体况；卸载的区域冻结。新动物死亡后保留原身份、身体、死亡状态与冻结时间，不提供补生、繁殖、迁移或离线增长。

摄食必须发生在实际局部食物点距对应口部参考不超过2.5厘米、且身体支撑与占位检查通过时。实际摄入通过原有`sim._remove(..., 'ingested')`扣除`surfaceDetritus`或`benthicAnimalFood`，同时进入原有有机食物总账与分池账；没有额外的悬浮猎物通道、光合作用或新食物输入。真实来源食谱比这些有限组件丰富。

原有动物的`sim.energyLedger`及海蜘蛛账保持独立。新动物体况在`deepBenthicEnergyLedger`中记载初始值、摄入收益、维持和移动扣款、上限修正，满足：

`现有新动物体况总和 = initial + feedingGain − maintenanceAndMotionDebit + clampCorrection`

体况可以减到零；没有维持体况的免费下限。它是无量纲体况指数，不是生物量、食物库存或实测代谢率。观察灯与时间显示不为任何生态库存供能。

## 保存与原生入口

只有存储读取严格返回`null`的全新区域可以初始化标记。每区最多增加四个新代表，原有、新增、海蜘蛛及死亡个体合计仍不超过20。保留九个活跃区、25个公共来源owner的有限窗口，不引入世界边界。

五份新保存字段为`deepBenthicLifeVersion`、`deepBenthicLifeInitializedAtSec`、`deepBenthicLife`、`deepBenthicAgents`与`deepBenthicEnergyLedger`。提交成功后才公开新群落；未完成或被拒绝的原子保存不能泄露新记录。恢复时核对出生点、尺寸、口部与食物见证、完整原生支撑、体况平衡和总容量；不完整标记，包括预读但尚未加载区域中的保留标记，均拒绝。旧记录、死亡记录及检查过的空类别不补货，也不重新随机生成历史。

普通“软底新群落”入口与`?demo=deep-life`进入普通owner140,8；默认字符串种子`42`的原生配置在此包含四个代表，但其他种子和既有存档不保证相同。入口等待真实群落读取成功，镜头朝实际活动物观察，不用临时展示物冒充保存群落。导演模式使用同一个原生停靠点；巡游为56章节、50个不同动作，1倍速观察时长670秒，实际加载与转场另计。

## 有限证据与收口

[原生模型检查](../tests/deep-benthic-life.test.mjs)覆盖八项有限用例：确定性和原库存不变、严格新生及总容量、真实0.1秒活动与分池/体况守恒、非中心身体阻挡、真实口部接触、空食物与重复时钟、损坏保存拒绝，以及死亡冻结。默认字符串种子`42`的139–141,8–9六个普通owner用于固定准入样本；其中139/140/141,8各24秒真实生态步长的联合样本覆盖四类的实际移动和摄入。它们不是野外密度或长期生态稳定性的证明。

来源、原生存档、资产、入口及云端核验由对应检查和交付记录汇总；CPU/Three、构建、发布证据不能替代浏览器/GPU整体观感、帧率或完整导演巡游验收。完成这个四类包后继续宏观生境群落，不重开单体形态、材质、镜头或性能细调循环。

本轮实际两个九区窗口合计47条新增记录；停止外部食物补给的24秒普通模拟中46个新增动物移动、24个成功摄食，四类均覆盖。食物总账／分池及三套体况账最大误差约4.09e-14。92文件／653项最终本机检查全部通过、一次生产构建通过；云端发布结果见[交付记录](../output/validation/deep-benthic-life-delivery.json)。以上是有限CPU/native证据。
