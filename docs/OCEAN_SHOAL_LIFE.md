# 浅礁水层群游包

普通菜单入口为“水层鱼群”，URL参数为 `?demo=shoal-life`；导演新增“水层鱼群与巡游鲨”16秒镜头。观察点位于原生206,21区域（x13216、z1376）的真实群体平均水深，镜头不沿海床假设动物高度。该区域自然生成7条六带鲹与1条黑鳍礁鲨，共19个含既有类别的动物记录；出生时旧游泳动物营养库存为.018相对单位。此数值是确定性软件结果，不是自然密度或实测食物量。

本批为浅礁上方补充三个尺度的群游鱼，以及较大的单体黑鳍礁鲨：黄蓝背乌尾鮗 *Caesio teres*、六带鲹 *Caranx sexfasciatus*、日本银带鲱 *Spratelloides gracilis*、黑鳍礁鲨 *Carcharhinus melanopterus*。其来源、全长与深度选择、完整形态和局限见 [来源说明](OCEAN_SHOAL_LIFE_SOURCES.md)。

鱼群由5–7个同种独立动物组成，每条有自己的ID、位置、全長、organic库存、区域时钟和摄食收据；可另有一条独立礁鲨。鱼群保存完整成员名单，成员死亡后仍保留历史ID，不补出生替代成员。展示数目不是自然群体数量或密度。群游包括有界缓转、前进、同群间距及遇障停留；礁鲨独立游弋，不强制组成鲨群。

浮游食物鱼逐条消费当前owner的 `resources.plankton`；鲹和鲨逐条消费旧 `openWaterLife.preyOrganicUnits`。后者是未分辨游泳动物营养代理，未实现可见鱼类捕杀。原库存为零时允许搜索和缺食，不另建食物池。每次摄食均把实际扣减写入该动物的 `lastShoalIntake`，使用已有物质网络转移与守恒账。

动物按完整身体的真实水深准入，区别于海床深度：日本银带鲱使用海面下1–3米，乌尾鮗5–15米，鲹和鲨3–15米。尾尖、胸鳍、背鳍和有界动作全部进入净空包络，俯仰后的全身也须通过原生地形和水深检查。该包不修改海床以保证动物出现。

仅严格读取到`null`的从未访问原生区域可以初始化。角色选择、同种选择和尺寸使用确定性原生随机输入；没有角色或没有合适水层的区域保存完整空标记。角色区域为新动物预留最多8个名额，总动物记录预算仍不超过每owner20个；既有类别保留自己的占位和原库存规则。已访问历史记录、暂停时钟和下一原生步骤不因打开此功能而改变。

卸载区域冻结完整记录与生态时钟，重访或冷启动精确恢复。存储未定义返回、读取异常、原子写拒绝，以及水层包或整个历史群落的前缀/成员名单/库存/旧类别损坏均拒绝准入，不修补成全新动物。出生的原子写成功前不公开动物或配套场景。

有限CPU生产案例使用自然浅礁九区窗口205,20与188,14，每窗观察4秒：18个owner实际出生45个新动物（17乌尾鮗、13鲹、13银带鲱、2礁鲨），45个均有独立时钟与运动，记录43次真实原库存摄食写入。四类各有成功摄食个体；其中6条鲹的owner原动物库存为0，正常搜索而未补食物。含既有类别的最大记录数为19，最大物质平衡误差约5.33e-15。这些是确定性软件结果，不是浏览器/GPU效果、自然群体密度或全海域碰撞的证明。运动速度、摄食系数、年龄、繁殖、自然密度及环境耐受均未校准；未知源字段保留`null`。总目录43条命名代表记录，不以此表述经身份核定的43种自然物种。

验证入口：`tests/ocean-shoal-life.test.mjs`覆盖原生纯模型，`tests/ocean-shoal-life-render.test.mjs`覆盖独立完整形态和有界动作，`tests/ocean-shoal-life-ecology.test.mjs`覆盖6项生产生态与持久化案例。生产收据通过环境变量 `OCEAN_SHOAL_LIFE_RECEIPT` 指定输出文件；最终构建与整库验收由主任务完成。
