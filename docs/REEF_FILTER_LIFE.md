# 浅礁贝类与固定滤食生活层

本批新增鳞砗磲 Tridacna squamosa 和黑蝶贝 Pinctada margaritifera，浅海目录83→85，v13共享居民候选40→42。两类都有独立的两瓣壳、外套膜、有界开合、当地摄食、死亡及完整保存恢复，已接入实际动物渲染调度和资源释放。固定附着的贝类不使用鱼类巡游或贴底爬行规则。

鳞砗磲选取24–36厘米壳长、完整身体3–15米水深，参考马尔代夫浅礁调查；厚壳宽肋、鳞片和斑驳外套膜参考FAO物种图鉴。真实砗磲有共生藻供能，本版未实现该能量路径，不将浮游代理摄食称为完整食谱。[FAO浅礁调查](https://www.fao.org/4/ae451e/ae451e00.pdf)、[FAO物种形态](https://openknowledge.fao.org/server/api/core/bitstreams/f32d004b-6358-44f3-8242-b9d23e5346d0/content)、[JCU鳞砗磲研究](https://researchonline.jcu.edu.au/76364/1/76364.pdf)。

黑蝶贝选取7.5–9.5厘米壳长和3–18米完整身体水深，作为小型浅礁附着代表；水深为模型选择，引用的图鉴未给出完整物种深度范围。近圆鳞壳、暗色内缘及浅水附着参考FAO，悬浮颗粒滤食参考原始研究；未模拟珍珠、生长、繁殖、足丝力学或粒径选择。[FAO肯尼亚图鉴](https://www.fao.org/4/i2741e/i2741e.pdf)、[Pouvreau等1999滤食研究](https://agris.fao.org/search/en/providers/122535/records/65df4a077c7033e84bed4cf3)。

候选仍经真实稳定礁面、六处壳体支撑采样、完整壳与开合外套膜、水深、坡度及占位检查；六处是几何支撑采样而非生物足。松散沙床不能作为这两类的附着面。位置、目标、朝向和速度固定，开合只读所属生态时钟；实际摄食扣原 resources.plankton，并写原能量与食物账。没有新造库存或校准滤水量。
