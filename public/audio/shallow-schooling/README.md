# 乌尾鮗鱼群协同中文旁白

本项目自编的五段观察文案，使用用户配置的 MiniMax 语音服务生成于 2026-10-13。沿用四分钟浅海体验的 `speech-2.8-hd` 模型、`Chinese (Mandarin)_Gentleman` 系统音色及 1.05 语速。属于 AI 合成旁白，没有真人声音克隆，也没有新增或更换动物与礁体资产。

这里保存可随网页发布的静态 MP3 和不含凭据的生成元数据。合成调用只在本地生成脚本中发生；网站只播放已保存的音频。外部 `.env.minimax`、密钥、鉴权头和临时字幕下载地址不进入此目录或前端。

讲解引导观察同伴间距、礁两侧分流、汇合、局部扰动和重新群聚。旁白明确将扰动和整段内容称为行为演示，不把这一次编排当作生物定律，也不宣称实现完整生态模拟。
