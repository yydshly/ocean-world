# 阶段06大型动物来源

阶段07新增原创表现版本 `pelagic-natural-body-skin-v2`，记录见 [provenance-v2.json](./provenance-v2.json)。保留1只13.8 m座头鲸、6只2.65 m宽吻海豚与相同动物面数；更新连续头背轮廓、尾柄弯曲、尾叶俯仰、胸鳍控制及变形法线。鲸的姿态来自实际路径切线，呼气检查鼻孔是否露出共用波面；豚群采用固定30 Hz有限跟随、近邻避让和一次队形变化。活动仍为有研究参考的确定性编排，不是校准流体或自然群体模拟。阶段06本地标签与旧记录保持当时含义。

本章展示加勒比海代表性座头鲸（13.8 m，1只）和宽吻海豚（2.65 m，6只）。身体、胸鳍、尾叶、嘴吻、头部鲸瘤、眼部和表面颜色均为项目原创。没有下载、复制或改造第三方鲸豚网格、照片或动画；原创内容随项目再分发，没有新增第三方素材限制。完整记录见同目录 `provenance.json`。

尺寸与大轮廓参考 [NOAA 座头鲸](https://www.fisheries.noaa.gov/species/humpback-whale) 和 [NOAA 宽吻海豚](https://www.fisheries.noaa.gov/species/common-bottlenose-dolphin)。显示尺寸位于公开成体长度范围内；这不是扫描、已测量个体或校准解剖。海面换气、尾叶与胸鳍运动、豚群路线均为科普编排，鲸与海豚的同屏构图不表示自然共同群体。

曾核对 CARI’MAM/Weeteam 同作者的免费写实座头鲸和宽吻海豚模型。[Agoa 官方页面](https://sanctuaire-agoa.fr/documentation/les-cetaces-du-sanctuaire-agoa-en-3d) 明确许可为 CC BY-NC-SA 4.0，允许署名、非商业、同许可再分发。正常下载接口返回401，未登录、未绕过加密viewer资源，也未将候选文件打包。因此本章没有应用这些第三方模型的许可或署名要求，也不声称使用了这些模型。

本章与旧浅海、深海、巨藻林的持久生态分离。场景只依赖本地确定性的时间编排，暂停、定位、重播不改写存档。
