# 潮汐 · 海底观察站

以海洋纪录片式写实为目标的 3D 海底探索与生态模拟原型。按种子和世界坐标随探索持续生成海域，将地貌、植物、真实动物、生境与食物库存组织在同一场景中，并保存已访问区域。

当前默认进入“浅海生态海域”；原浅礁、蒙特雷巨藻林和东北太平洋深海软底也可独立切换。项目仍在开发，纪录片式整体画面尚未验收。

在线体验：[海底观察站](https://yydshly.github.io/ocean-world/)。公开源码：[yydshly/ocean-world](https://github.com/yydshly/ocean-world)。发布记录见 [部署说明](docs/DEPLOYMENT.md)。

## 快速运行

使用 Node.js 22 或更新的受支持版本，安装锁定依赖后启动：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

打开 <http://127.0.0.1:4173/>。生产构建与本机预览：

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 4173 --strictPort
```

普通生产版的截图、录像与实验导出使用浏览器下载；开发验证记录可写入本机项目目录。

## 操作

- 左键拖动转向，右键拖动平移，滚轮靠近或远离。
- W/A/S/D 移动，Q/E 下潜或上浮，Shift 加速。
- 点击生物或从图鉴选择，查看资料并跟随；拖动视角退出跟随。
- 切换海域、水层和观察路线；“探索手记”保存观察点，最多保留 12 个。
- 暂停及倍速控制模拟；环境面板可调整水流、浑浊度、食物输入和时刻。
- 新浅海的“连续海床”“相邻生境”路线可查看最新跨区起伏。路线是观察入口，海域仍会随探索继续生成。

## 已有功能

- **连续探索**：64 米区块、九区活动窗口与浮动原点；适宜的新浅海四区可生成共享的 128 米海床，内部接缝一致。
- **生活空间**：不规则岩礁、岩脊与砂道、缓坡与砂盆、草床、珊瑚与附着群落，稀疏沉木及灌水沉底瓶。
- **实际生命**：鱼群、底栖动物、海龟、蝠鲼、章鱼、蟹、海绵、礁鱿和水母等代表，按适宜生境准入；新浅海目录有 23 个条目，包含群体、复合体和分类代理，不等于 23 个严格物种。
- **生态与保存**：摄食、捕食/避敌、碎屑与分解回流，以及相对物质收支；保留个体身份、历史死亡、库存、时钟和已保存地形。
- **观察与实验**：图鉴、跟随、观察手记、截图/录像、环境实验及独立生态演化工作台。

## 当前进展与限制

2026-10-06 的最新交付完成四区连续海床：实际示例起伏高差约 4.65 米，已沿普通路线跨区、离开回访并冷刷新验证。**19 项不同的相关检查与一次生产构建通过**；这不是全项目历史测试全部通过，也不继承旧冻结版本的性能结论。详见 [当前状态与有限开发步骤](docs/CURRENT_STATUS.md)、[最新交付证据](output/validation/seascape-delivery.json) 和 [手记观察](output/validation/seascape-notes-observation.json)。

真实整景已能看到连接沙坡，但草床与小动物在普通远景仍难辨认，岩体和生物形体仍有程序化感。128 米组合外围保留原地床支撑带，尚非统一的无界地质地表。生态使用未校准的相对库存和群体代理；未加载区域冻结，未实现完整流体、沉积输运或生命周期。

**存档保存在当前浏览器、当前站点来源的 IndexedDB 中。** 本机与线上站点、不同域名、浏览器或设备各有独立存档；上线不会自动带入本机的动物、地形或手记。当前没有云端同步，清除站点数据会清除本地存档。

下一批优先交付普通探索中可读的完整“礁体—砂道—草床—水层动物”生活带，以整片效果收口，再深化细节。阶段路线图见 [PLAN.md](PLAN.md)，开发记录见 [PROGRESS.md](PROGRESS.md)。
